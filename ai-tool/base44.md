# Base44는 백엔드와 인증과 호스팅을 내장한 채 자연어로 앱, 웹사이트, AI 에이전트를 만들게 하는 바이브 코딩 플랫폼이다

<https://base44.com/>

## 소개

Base44는 자연어로 설명하면 앱, 웹사이트, AI 에이전트를 만들어 주는 AI
플랫폼이다.
홈페이지의 문구는 모든 빌더에게 기반(base)이 필요하다는 것이고,
설명은 서버를 만지거나 결제 서비스를 연결하거나 데이터베이스를 설정하지 않고
바이브 코딩(vibe coding)으로 실제로 쓸 수 있는 것을 낼 수 있다는 것이다.
푸터의 저작권 표기는 Wix.com Ltd.이다.

회사가 내세우는 내장 기능은 백엔드와 저장소, 원클릭 통합(integration), 사용자
지정 도메인,
분석(analytics), Base44를 통한 직접 결제 수령, 기업 수준의 보안이다.
홈페이지의 질의응답은 Base44를 코딩이 필요 없는 노코드 AI 플랫폼이라고 설명한다.
아이디어를 대략적인 생각이든 상세한 명세든 평이한 말로 쓰면 코드, 구조, 디자인,
로직을 생성하고,
이후 AI와 대화하며 원하는 대로 될 때까지 고쳐 나간다는 것이다.
앱은 만들면 곧바로 내장 호스팅으로 공개되고 공유할 수 있으며 배포 절차가
없다고 한다.

### 만들 수 있는 것

홈페이지는 세 갈래를 소개한다.
앱은 백엔드, 인증, 결제, 호스팅이 이미 들어 있는 완전한 기능의 앱이다.
웹사이트는 AI가 만든 디자인, 사용자 지정 도메인, 내장 SEO 도구가 있는
사이트이다.
AI 에이전트는 도구에 연결되어 실제 행동을 하고 사용자가 자는 동안에도 일하는
24시간 에이전트이다.
예로 든 용도는 내부 도구와 대시보드, 개발자 생산성 앱, 고객 포털과 CRM,
교육과 훈련 플랫폼, 건강 추적기, 온라인 상점, 모바일 앱이다.

디자인 쪽 기능으로는 보드에서 모든 페이지를 한꺼번에 보며 메모와 지시를 AI에
보내는 협업,
설명하면 영상을 만들어 페이지에 넣는 영상 생성,
AI가 변경 전에 미리보기를 보여 주는 재디자인 추천,
앱 전체의 색상과 글꼴을 한곳에서 바꾸는 디자인 제어를 든다.

출시 뒤를 위한 마케팅 도구도 있다.
SEO와 GEO 대시보드는 Google, ChatGPT, Gemini에서 발견되도록 스캔해 우선순위가
매겨진 수정 목록을 주고 AI가 수정을 적용한다.
소셜 프레즌스 기능은 만든 것을 읽고 알맞은 소셜 플랫폼을 골라 사용자의 어투로
게시물을 만든다.
앱 분석은 트래픽과 판매를 추적한다.
Superagents는 받은 편지함, 일정, 도구에 연결해 업무를 처리하고 워크플로를
자동화하는 AI 에이전트이고,
앱이 만드는 제품이라면 Superagent는 곁에서 도는 비서라고 설명한다.

통합은 Google Calendar, Gmail, Slack, Notion, HubSpot, Salesforce 등이고 API로
외부 서비스에 연결할 수도 있다.
이메일 발송, 데이터 관리, AI 콘텐츠 같은 흔한 기능은 추가 설정 없이 내장되어
있다고 한다.

## 요금

홈페이지는 무료 플랜과 월 $16부터의 유료 플랜(연 결제 기준)을 안내한다.
요금 페이지는 다섯 플랜을 보여 준다.[^pricing]

| ------- | ---------------- | ---------------- | -------------- | ----------------------------------------------------------- |
| Free    | $0               | 25               | 100            | 앱 최대 5개, 인증, 데이터베이스, 분석                       |
| Starter | $16              | 100              | 2,000          | 앱 수 무제한, 앱 내 코드 편집, 도메인 연결, 1년 무료 도메인 |
| Builder | $40              | 250              | 10,000         | AI 모델 선택, GitHub 통합, 친구에게 25 크레딧 공유          |

크레딧은 AI 메시지와 통합 동작에 쓰는 월간 사용량이고 정확한 사용량은 동작과
선택한 AI 모델에 따라 달라진다고 한다.[^pricing]
연 결제는 모든 유료 플랜에서 20%를 깎아 주고,
외부 서비스(Stripe, SendGrid, OpenAI 등)는 사용자에게 직접 청구된다고
한다.[^pricing]
기업용은 맞춤 크레딧, 전담 아키텍트, SSO, 고급 보안 제어를 내세운다.[^pricing]
요금 페이지의 질의응답은 사용자가 만든 코드, 데이터, 사용자를 소유하며
양방향 GitHub 동기화로 전체 소스를 언제든 자기 저장소로 내보낼 수 있다고
쓴다.[^pricing]

## 보안과 데이터

보안 페이지는 AES-256 암호화, 내장 보안 스캔과 AI 수정, SOC 2 Type II와 ISO
27001 인증을 내세운다.[^security]
데이터 거주 지역(region) 선택, 워크스페이스 데이터를 AI 모델 학습에서 빼는
옵션(기업용), GDPR 삭제 흐름을 제공한다고 한다.[^security]
전송은 TLS 1.2 이상, 저장은 AES-256이며 비밀값은 클라우드 키 관리
서비스(KMS)에서 관리한다고 한다.[^security]
하위 처리자(subprocessor) 목록에는 Mongo(데이터 저장과 호스팅), Render(서버),
Google Cloud(분석),
OpenAI와 Anthropic(LLM API 호출), Wix.com Ltd., SendGrid, Datadog, Langfuse,
Logfire가 들어 있다.[^security]

## 분석

### 이 제품의 핵심 주장은 만들기에서 운영까지의 전 과정을 한 플랫폼에 넣는다는 것이다

홈페이지의 서술은 UI만이 아니라 백엔드, 인증, 결제, 호스팅, 분석, 마케팅까지
한곳에 있다는 데 모인다.
FAQ가 좋은 AI 노코드 플랫폼의 기준으로 전체 스택 생성, 반복 속도, 내장 호스팅,
통합, 확장성을 꼽고
Base44가 모두 갖췄다고 쓰는 것도 같은 주장이다.
이 기준은 회사가 정한 것이므로 다른 제품과의 비교는 아니다.

### 속도의 증거는 한 사용자의 후기이다

홈페이지가 보여 주는 사례는 Gift My Book의 창업자 Yoav Hornung의 말이다.
끝에서 끝까지 동작하는 제품이 나오는 데 약 1주일이 걸렸고,
수치로 출시까지 1주일, 3개월에 연 매출 $1M, 전환율 6~8%를 보여 준다.
이 문서는 이 수치를 검증하지 못했고 회사가 고른 사례로 읽는다.

## 비평

### 공유 인프라 위에서 도는 모델의 위험이 실제로 드러난 적이 있다

Wiz Research는 2025년에 Base44의 임계 취약점을 공개했다.
공개되지 않은 app_id 값만으로 등록과 이메일 인증 엔드포인트에 요청해
비공개 앱에 검증된 계정을 만들 수 있었고, SSO를 포함한 인증 통제를 우회해
기업의 비공개 앱과 민감 데이터에 접근할 수 있었다고 한다.[^wiz]
Wiz는 즉시 Base44와 Wix에 알렸고 24시간 안에 고쳐졌으며 Wix는 과거 악용 증거가
없다고 확인했다고 쓴다.[^wiz]
Wiz는 이 사건을 모든 고객이 벤더의 보안 수준을 물려받는 공유 위험 모델의 단일
장애점으로 설명한다.[^wiz]
이 문서는 이 취약점이 이후에 다른 문제로 이어졌는지 확인하지 못했다.
홈페이지와 보안 페이지는 이 사건을 언급하지 않는다.

### 보안 주장은 인증서와 선언이고 이 문서가 확인한 것은 아니다

보안 페이지의 인증과 암호화 서술은 회사가 쓴 것이다.
SOC 2 보고서는 요청해야 받을 수 있다고 안내되어 있고,
학습 데이터 제외 옵션은 기업용에만 있다고 적혀 있다.
무료와 낮은 요금제 사용자의 데이터가 모델 학습에 어떻게 쓰이는지는 이 문서가
읽은 페이지에서 확인하지 못했다.
하위 처리자 목록에 LLM 제공자 두 곳이 있어 입력이 외부 LLM으로 전송됨이
드러난다.

### 요금은 크레딧 구조라 실제 비용을 예측하기 어렵다

크레딧의 소모량이 동작과 모델에 따라 달라지고,
FAQ는 복잡한 빌드와 긴 반복은 크레딧을 더 쓰므로 단계로 나누어 계획하라고
안내한다.
어떤 앱을 만드는 데 몇 크레딧이 드는지는 홈페이지와 요금 페이지에 없다.
무료 플랜은 월 25 메시지 크레딧이므로 한 달에 얼마나 만들 수 있는지도 직접
시험해야 안다.

### 마케팅 기능의 약속이 넓다

SEO와 GEO 대시보드가 AI 검색에서 발견되게 해 준다는 서술과
소셜 게시물을 사용자의 어투로 만들어 준다는 서술은 효과의 근거가 없다.
외부 플랫폼의 노출 알고리즘에 달린 결과를 플랫폼이 보증할 수는 없다는 점도 쓰여
있지 않다.

## 인사이트

### 이 플랫폼을 평가하는 순서는 내보내기, 데이터, 비용이다

요금 페이지가 소유와 코드 내보내기를 명시하므로,
쓰기 전에 가장 먼저 확인할 것은 GitHub 동기화로 내보낸 코드가 플랫폼 밖에서
실제로 실행되는지이다.
둘째는 민감 데이터를 넣는다면 하위 처리자와 학습 제외 조건이다.
셋째는 작은 앱 하나를 만들며 쓴 크레딧이다.
이 순서는 이 문서의 제안이다.

### 비공개 앱에는 플랫폼의 인증에 더해 자체 확인을 둔다

Wiz가 설명한 구조(플랫폼의 인증 흐름의 결함이 모든 앱에 영향)에서 보면,
민감한 데이터를 다루는 내부 도구는 플랫폼의 로그인에만 의존하지 않고
접근 로그를 확인하고 최소한의 권한만 주는 구성이 안전하다.
이것도 이 문서의 제안이며 Wiz가 직접 권고한 내용은 아니다.

### 이 플랫폼의 방향은 자체 모델과 파트너 모델의 병행이다

TechCrunch는 Base44가 자체 모델 Base1을 내놓기 시작했다고 보도한다.
회사는 첫 모델이 플랫폼에서 일어난 수천만 건의 실제 사용자 상호작용으로 만든
데이터로 학습했다고 하고,
창업자 Maor Shlomo는 모델을 자체 스택의 일부로 학습하고 소유하면 지연, 비용,
효율의 최적화 여지가 크다고 말한다.[^techcrunch-base1]
이 보도는 Base44가 2025년에 Wix에 현금 8,000만 달러에 팔렸다는 배경도 밝히고,
TechCrunch는 당시 직원 8명이었고 그중 2,500만 달러가 유지(retention)
보너스였다고 쓴다.[^techcrunch-wix]
보안 페이지의 하위 처리자 목록에 OpenAI와 Anthropic이 있는 점은
이 문서가 읽은 시점에 외부 모델도 쓰고 있음을 보여 준다.[^security]

### 이 제품의 주장을 확인할 관찰

같은 앱 설명을 무료 플랜에서 만들어 보고 쓴 크레딧, 수정 횟수, 내보낸 코드의
실행 가능 여부를 기록하면
홈페이지의 “몇 분 만에 완전한 앱”이라는 주장을 직접 판단할 수 있다.
수정이 길어져 크레딧이 한 달 한도를 넘는다면 플랫폼의 비용 구조가 그 용도에 맞지
않는 것이다.
