# 카페24 AI SPACE: AI가 만든 코드를 대화 한 마디로 배포하는 호스팅

<https://hosting.cafe24.com/?controller=new_product_page&page=ai-space>

## 소개

AI SPACE는 카페24가 “AI 서비스 배포·호스팅 플랫폼”으로 내놓은 상품이다.
상품 페이지의 첫 문장은 ChatGPT나 Claude에서 만든 코드를 서버 설정 없이 바로
배포한다는 약속이다.
대상은 둘로 그려진다.
개발팀을 기다리지 않고 이벤트 페이지를 직접 올리려는 마케터,
그리고 서버·도메인·SSL 세팅이 귀찮은 개발자다.

페이지가 내세우는 조건은 다음과 같다.
월 4,900원부터 시작하고, 카드 등록 없이 14일 무료 체험을 주며,
체험이 끝나도 자동 결제되지 않는다.
모든 앱에 `mycafe24.ai` 하위 도메인이 바로 발급되고,
전송량 기반 과금이 없는 “트래픽 무제한”을 내건다.
지원 환경은 HTML/CSS/JS 정적 사이트, PHP, Python, Node.js,
React·Vue 빌드 결과물이고, MySQL과 PostgreSQL 연동도 된다.
배포 예시로는 포트폴리오, 이벤트 랜딩 페이지, 미니 게임과 웹앱,
사이드 프로젝트, API 서버, 그리고 워드프레스 블로그나 그누보드 커뮤니티 같은
오픈소스 앱이 나온다.

카페24 상단 메뉴에서 AI SPACE는 같은 회사의
[LLM Router](cafe24-llm-router.md), AI 홈페이지 빌더,
OpenClaw·Hermes Agent VPS 호스팅과 함께 “AI” 묶음에 들어 있다.

## 배포 방식

페이지는 배포 경로를 세 가지로 나눈다.

| 경로             | 연결 방법                                              | 페이지가 내세우는 점                           |
| ---------------- | ------------------------------------------------------ | ---------------------------------------------- |
| AI 에이전트(MCP) | ChatGPT·Claude Desktop에 앱 추가, Claude Code 플러그인 | “이거 배포해줘” 한 마디로 서버 생성과 URL 발급 |
| Git Push         | GitHub 저장소 연결                                     | 푸시할 때마다 증분 빌드, 이전 버전으로 롤백    |
| 웹 콘솔          | 브라우저에서 ZIP 업로드 또는 GitHub 저장소 선택        | 터미널 없이 배포 과정을 화면에서 확인          |

MCP 경로가 상품의 중심이다.
FAQ는 MCP를 AI와 외부 서비스를 잇는 표준 규격으로 설명하고,
처음 한 번만 설정하면 이후 배포가 대화 한 마디로 끝나며 가이드대로 하면
3분이면 된다고 말한다.
Claude Code에서는 다음 순서로 플러그인을 설치한 뒤 `/mcp`에서 카페24 계정을
연결한다.

```text
/plugin marketplace add cafe24-aispace/aispace-claude-plugin
/plugin install cafe24-aispace
/mcp
```

연결 뒤에는 “배포해줘”, “상태 보여줘”, “백업해줘” 같은 대화로 배포, 상태 조회,
환경변수 관리, 백업을 할 수 있고,
별도 API 키 없이 OAuth로 인증한다고 한다.
페이지 상단의 범용 설치 예시는 이와 다른 명령을 보여 준다.

```bash
npx plugins add cafe24-aispace/aispace-plugins
```

배포 단계에서 플랫폼이 대신 해 주는 일로는 실행 환경 자동 감지,
서버 생성, `mycafe24.ai` 도메인 발급, SSL 인증서 발급과 자동 갱신,
배포 전 “AI 기반 코드 보안 검수”를 든다.
페이지는 이를 직접 배포의 고생, 즉 서버 신청, 방화벽과 포트 설정,
최대 48시간 걸리는 DNS 연결, SSL 갱신 스크립트 작성과 나란히 놓고 비교한다.

## 요금과 사양

기본 요금제는 “출시 기념 특가” 월 4,900원에 앱 1개가 포함된다.
상세 사양은 네 단계다.

| 항목     | 1단계   | 2단계   | 3단계    | 4단계    |
| -------- | ------- | ------- | -------- | -------- |
| RAM      | 256MB   | 512MB   | 1GB      | 2GB      |
| 스토리지 | 1GB     | 2GB     | 5GB      | 10GB     |
| 동시접속 | 50      | 100     | 200      | 500      |
| 트래픽   | 무제한  | 무제한  | 무제한   | 무제한   |
| 월 요금  | 4,900원 | 8,900원 | 14,900원 | 29,900원 |

FAQ와 하단 이용 안내에는 표에 드러나지 않는 조건이 붙어 있다.

- “트래픽 무제한”은 전송량 과금이 없다는 뜻이고, 품질은 동시접속 수로
  관리한다. 한꺼번에 사람이 몰리면 잠시 대기 화면이 뜰 수 있지만 추가 비용은
  없다.
- MySQL·PostgreSQL 용량은 컨테이너 스토리지에 포함되며 따로 주지 않는다.
- 무료 SSL 자동 발급은 기본 도메인 `mycafe24.ai`에만 적용된다.
  커스텀 도메인 연결은 되지만 자동 발급 대상은 아니다.
- 외부 링크 전용 목적으로 쓰면 이용이 제한될 수 있다.
- 해지 후 “일정 기간” 데이터를 보관하고, 그 기간이 지나면 사이트와 데이터를
  삭제한다.
- 사양과 요금은 사전 공지 후 바뀔 수 있다.

책임 범위도 분명히 적는다.
AI SPACE는 배포 인프라만 제공하며,
AI로 만든 코드와 콘텐츠의 정확성·적법성·저작권 책임은 이용자에게 있다.

## 분석

### 배포를 에이전트의 도구 하나로 바꾸는 상품이다

이 페이지가 파는 것은 서버 자원보다 배포라는 행위의 접점이다.
4,900원짜리 256MB 컨테이너는 그 자체로 새롭지 않다.
새로운 점은 그 컨테이너를 만드는 주체가 사람의 콘솔 클릭이 아니라
에이전트의 MCP 도구 호출이라는 데 있다.
“코딩은 LLM, 배포는 AI SPACE”라는 문구가 이 분업을 그대로 요약한다.

이 구도에서 호스팅 회사의 경쟁 상대는 다른 호스팅 회사가 아니라
에이전트 안에서 호출될 기본 배포 도구의 자리다.
에이전트가 코드를 다 쓴 뒤 “어디에 올릴까”를 물을 때
가장 먼저 연결돼 있는 도구가 고객을 가져간다.
Claude Code 플러그인, ChatGPT 앱, Claude Desktop 연동을 모두 첫 화면에 둔 것도
이 자리를 선점하려는 움직임으로 읽힌다.

같은 메뉴의 LLM Router, OpenClaw·Hermes Agent VPS와 함께 보면 방향이 더
분명하다.
카페24는 모델 호출, 에이전트 실행, 결과물 배포라는 세 구간에 모두 상품을 두고
있다.
쇼핑몰과 웹호스팅으로 쌓은 국내 고객 기반을 AI 작업 흐름의 끝단으로 옮기려는
시도다.

### 동시접속 과금은 바이브 코딩 결과물의 트래픽 모양에 맞춘 선택이다

전송량 대신 동시접속으로 요금을 나눈 것은 대상 고객을 반영한다.
포트폴리오, 이벤트 페이지, 미니 게임은 평소 방문자가 거의 없다가
공유된 순간 짧게 몰리는 모양을 가진다.
전송량 과금이면 그 순간이 요금 폭탄이 되고,
동시접속 상한이면 대기 화면으로 끝난다.
비개발자에게 “예상치 못한 청구서”보다 “잠깐 기다리는 방문자”가
훨씬 받아들이기 쉬운 실패다.

다만 이 선택은 성공의 상한을 정한다.
1단계 50명, 4단계 500명의 동시접속은 실제 서비스로 자랄 앱에게는 낮은
천장이다.
페이지가 API 서버와 팀 업무용 ERP까지 예시로 드는 것과 비교하면,
요금 구조는 분명히 “공개해 보는” 단계에 맞춰져 있다.

### 책임 조항이 상품 설명만큼 길다

FAQ와 이용 안내에는 같은 문장이 두 번 나온다.
AI SPACE는 배포 인프라만 제공하고,
AI로 만든 코드의 정확성·적법성·저작권 책임은 이용자에게 있다는 것이다.
“코딩 지식은 전혀 필요 없다”는 약속과 나란히 놓으면,
코드를 읽을 수 없는 사람에게 코드의 책임을 지우는 구조가 된다.

그 공백을 메우는 장치로 페이지가 내놓는 것은 “AI 기반 코드 보안 검수”다.
배포 전에 악성 코드와 보안 취약점을 자동으로 찾는다고 하지만,
무엇을 어떤 기준으로 검사하고 탐지되면 무엇이 막히는지는 설명하지 않는다.
사람이 한 줄도 읽지 않은 코드가 공개되는 경로에서,
이 검수가 사실상 유일한 검토자가 된다.

## 비평

### “트래픽 무제한”과 “숨은 비용 없음”은 표현이 조건보다 크다

요금 섹션의 제목은 “심플한 요금, 숨은 비용 없음”이다.
그런데 실제 제약은 FAQ와 하단 안내에 흩어져 있다.
트래픽 무제한은 동시접속 상한 아래에서만 성립하고,
1단계의 상한은 50명이다.
데이터베이스는 1GB 컨테이너 스토리지 안에서 코드·업로드 파일과 나눠 써야 한다.

비용이 숨어 있지는 않지만 한계는 숨어 있다.
비개발자 고객은 “트래픽 무제한”을 방문자 수에 제한이 없다는 뜻으로 읽기
쉽고,
SNS에 링크가 퍼진 날 대기 화면을 보고 나서야 그 의미를 알게 된다.
FAQ가 정직하게 설명하는 내용을 첫 화면의 문구가 덮고 있는 셈이다.

### 커스텀 도메인에서는 “SSL 자동”이 성립하지 않는다

직접 배포와 비교하는 표에서 페이지는 SSL 발급·설치·갱신 스크립트 작성을
직접 배포의 고생으로 꼽는다.
그러나 자동 발급은 `mycafe24.ai`에만 적용된다고 하단에 적혀 있다.
자기 도메인으로 서비스를 공개하려는 순간,
비교표가 없애 준다고 한 일 가운데 하나가 다시 돌아온다.

커스텀 도메인의 인증서를 어떻게 처리하는지는 페이지에 나오지 않는다.
별도 상품으로 사야 하는지, 직접 올려야 하는지, 갱신은 누가 하는지가 빠져 있다.
“서버·도메인·SSL 전부 알아서”라는 개발자 대상 문구는
기본 도메인에 머무는 경우에만 사실이다.

### 플러그인 설치 안내가 서로 다른 저장소를 가리킨다

페이지 상단의 범용 설치 예시는 `cafe24-aispace/aispace-plugins`를,
FAQ의 Claude Code 설치 안내는 `cafe24-aispace/aispace-claude-plugin`을 쓴다.
범용 플러그인과 Claude Code 전용 플러그인이 따로 있는 것일 수 있지만,
페이지는 둘의 관계를 설명하지 않는다.

이 상품의 핵심 약속은 “처음 한 번만 설정하면 된다”는 것이다.
그 한 번의 설정에서 어느 명령을 써야 하는지 헷갈린다면,
코딩을 모르는 대상 고객에게는 첫 단계부터 막히는 지점이 된다.
에이전트를 위한 상품일수록 설치 안내는 에이전트가 그대로 따라 할 수 있을 만큼
하나로 정리되어 있어야 한다.

### 검증할 수 없는 주장이 차별점의 무게를 진다

FAQ는 AI SPACE를 AI 에이전트에서 MCP로 직접 배포할 수 있는
“유일한 국내 서비스”라고 소개한다.
“유일”은 시점과 범위를 특정하지 않으면 확인할 수 없는 주장이고,
MCP 서버는 누구나 만들 수 있는 열린 규격이라 오래 유지되기도 어렵다.

“AI 코드 보안 검수”와 “24시간 모니터링”도 같은 문제를 가진다.
탐지 범위, 오탐 시 처리, 차단 기준이 공개되지 않은 보안 기능은
고객이 의존할 근거가 되기 어렵다.
해지 후 데이터 보관 기간도 “일정 기간”으로만 적혀 있어,
구독을 끊기 전에 무엇을 언제까지 백업해야 하는지 판단할 수 없다.

## 인사이트

### 배포 도구가 에이전트 안으로 들어오면 코드 리뷰는 배포 경로에서 사라진다

“이거 배포해줘” 한 마디로 끝나는 흐름에는 사람이 코드를 보는 단계가 없다.
깃 기반 배포에서는 커밋과 푸시 사이에 적어도 diff를 볼 기회가 있었지만,
MCP 배포에서는 생성과 공개가 한 대화 안에서 이어진다.
이 상품이 겨냥하는 비개발자 고객이라면 diff가 있어도 읽지 않을 것이다.

그 결과 검토 책임은 두 곳으로 흩어진다.
법적 책임은 약관에 따라 이용자에게,
기술적 검토는 플랫폼의 자동 보안 검수에 간다.
둘 다 실제 코드를 이해하는 사람이 아니다.
호스팅 업계가 오랫동안 공유 호스팅의 취약한 워드프레스 플러그인 문제를
떠안아 왔듯,
AI가 생성한 앱을 대량으로 받는 플랫폼은 같은 문제를 더 빠른 속도로 겪게 된다.

### 국내 호스팅 사업자의 해자는 데이터센터에서 에이전트 연결로 옮겨 간다

페이지는 20년 이상의 운영 경력, 수십만 사이트, 국내 데이터센터를 신뢰의 근거로
든다.
이것들은 웹호스팅 시대의 해자였다.
하지만 에이전트가 배포 대상을 고르는 시대에는
“에이전트가 이미 연결된 곳”이 먼저 선택된다.

이 경쟁에서 국내 사업자의 장점은 한국어 지원과 국내 결제, 국내 데이터센터다.
약점은 글로벌 배포 플랫폼이 이미 같은 MCP 통합을 제공할 수 있다는 점이다.
카페24가 모델 호출부터 배포까지 묶어 파는 것은,
한 구간에서 밀려도 다른 구간에서 고객을 붙잡기 위한 포트폴리오 전략으로 볼 수
있다.

### 공개해 보는 단계와 운영하는 단계 사이에 이 상품이 다루지 않는 틈이 있다

이 상품의 언어는 일관되게 “공개”다.
“세상에 공개하세요”, “지금 바로 공개해 보세요”가 반복되고,
요금과 사양도 공개 직후의 작은 트래픽에 맞춰져 있다.
그러나 공개한 앱이 실제로 쓰이기 시작하면
동시접속 상한, 1~10GB 스토리지 안의 데이터베이스, 커스텀 도메인 인증서,
백업과 데이터 보관이 차례로 문제가 된다.

바이브 코딩 도구들이 “만드는 것”의 장벽을 없앴다면,
AI SPACE는 “올리는 것”의 장벽을 없앤다.
남는 장벽은 “운영하는 것”이다.
장애 대응, 데이터 이전, 보안 사고 처리는 여전히 코드를 이해하는 사람을
필요로 하고,
그 단계에서 고객은 4단계 요금제 위의 다른 카페24 상품이나
다른 회사로 옮겨 가야 한다.
배포를 대화 한 마디로 만든 상품일수록,
그다음 단계로 넘어가는 경로를 얼마나 잘 설계했는지가 장기 고객을 가른다.
