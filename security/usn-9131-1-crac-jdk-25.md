# Ubuntu CRaC JDK 보안 공지

원문: [USN-9131-1: CRaC JDK 25 vulnerabilities](https://ubuntu.com/security/notices/USN-9131-1)

GN 토론: <https://news.hada.io/topic?id=37395>

## 요약

2026년 11월 17일 Ubuntu가 낸 보안 공지이다. 공지의 요약문은 CRaC JDK 25에서 여러 보안 문제를 고쳤다는 것이다.
대상 패키지는 `openjdk-25-crac`(Coordinated Restore at Checkpoints를 지원하는 오픈소스 Java 구현)이고 대상 릴리스는 Ubuntu 26.10과 26.04 LTS이다.
이 문서는 공지 페이지 전문을 읽었다. CVE 개별 페이지, 공지가 가리키는 OpenJDK 권고 세 건, 점수와 우선순위는 열지 못했다.

## 조치

고친 버전은 두 릴리스에서 같은 상류 버전이고 접미사만 다르다.

| Ubuntu    | 고친 버전                       |
| --------- | ------------------------------- |
| 26.10     | `25.0.5.0.3+1-0ubuntu2~26.10.1` |
| 26.04 LTS | `25.0.5.0.3+1-0ubuntu2~26.04.1` |

고친 바이너리 패키지는 `openjdk-25-crac-jdk`, `openjdk-25-crac-jdk-headless`, `openjdk-25-crac-jre`, `openjdk-25-crac-jre-headless`, `openjdk-25-crac-jre-zero`이다.
공지에 따르면 이 갱신은 새 상류 릴리스를 쓰며 추가 버그 수정을 포함한다. 일반 시스템 갱신을 한 뒤에 실행 중인 Java 애플리케이션을 모두 다시 시작해야 필요한 변경이 적용된다. 공지에는 `apt` 명령이 적혀 있지 않고 수정 받는 방법은 Ubuntu의 CVE 안내 링크로 연결된다. 새 기능과 호환되지 않을 수 있는 변경이 포함될 수 있다고도 적는다.
공지는 2026년 10월 20일, 21일, 24일자 OpenJDK 취약점 권고 세 건을 가리킨다.

## 취약점 내역

공지는 고유한 CVE 40개를 나열하며 각 항목에 구성 요소, 공격자 유형(원격, 인증 없는 원격, 로컬), 영향(읽기, 수정, 서비스 거부)을 적는다. 구성 요소별 개수는 다음과 같다.

| 구성 요소      | 개수 | 구성 요소                                                               | 개수 |
| -------------- | ---- | ----------------------------------------------------------------------- | ---- |
| Networking     | 8    | JAXP                                                                    | 3    |
| Security       | 5    | JGSS                                                                    | 3    |
| JSSE           | 3    | Libraries                                                               | 3    |
| Compiler       | 3    | ImageIO                                                                 | 2    |
| Serviceability | 2    | JAAS, JDBC, AWT, JDK tools, Utility, Sound, 2D, Lightweight HTTP Server | 각 1 |

대표적으로 보안 구성 요소의 CVE-2026-91333은 인증 없는 원격 공격자가 읽기나 수정을 할 수 있다는 항목이고, 컴파일러의 CVE-2026-83378과 라이브러리의 CVE-2026-101516도 인증 없는 원격 공격자가 읽기나 수정을 할 수 있다는 항목이다. 서비스 거부 항목은 JSSE의 CVE-2026-91373, JAXP의 CVE-2026-83400, ImageIO의 CVE-2026-91418 등이다.
공지 페이지는 세부 항목 일부가 중복으로 렌더링되고 「더 보기」 단추가 있으며, 점수나 Ubuntu 우선순위는 이 페이지에 없다.

## 비평

### 공지만으로는 위험 순서를 정하기 어렵다

공지가 40개를 구성 요소와 공격자 유형으로만 나열해 CVSS 점수나 우선순위를 알 수 없다. 어느 항목을 먼저 막아야 하는지는 개별 CVE 페이지나 OpenJDK 권고를 봐야 한다.
이 문서는 그 페이지를 읽지 못했다.

### CRaC 빌드라는 범위가 좁다

대상은 일반 OpenJDK 25가 아니라 체크포인트 복원(CRaC)을 지원하는 `openjdk-25-crac` 패키지이다.
같은 CVE가 일반 `openjdk-25` 패키지에서 어떻게 처리되는지는 이 공지에 없다. 일반 JDK 사용자는 해당 패키지의 공지를 따로 확인해야 한다.

### 갱신이 새 상류 릴리스이다

수정이 개별 패치가 아니라 새 상류 릴리스로 들어가 추가 버그 수정과 호환되지 않을 수 있는 변경이 함께 온다고 공지가 직접 경고한다. 운영 환경에서는 갱신 전에 시험이 필요하다.

### 외부 반응

HN에는 이 공지 주소로 올라온 글이 없었다(대조 쿼리는 정상이었다).
Lobste.rs의 `ubuntu.com` 도메인 첫 페이지에서는 이 공지를 찾지 못했고 `crac` 검색 결과 5건은 다른 글이었다. 둘째 페이지는 확인하지 못했다.
GeekNews 토픽은 공지를 옮긴 것이고 댓글이 없었다.

## 기억할 원칙

- 갱신한 뒤 Java 프로세스를 모두 다시 시작해야 고쳐진 코드가 쓰인다.
- 보안 공지의 CVE 목록은 점수와 우선순위가 따로 있는 곳(CVE 페이지, 상류 권고)에서 보충해 우선순위를 정한다.
- 갱신이 새 상류 릴리스를 포함하면 호환성 변경 가능성을 보고 스테이징에서 먼저 시험한다.
- 일반 JDK와 CRaC 빌드처럼 같은 소프트웨어의 변형은 패키지 이름이 다르므로 대상 패키지를 확인한다.
