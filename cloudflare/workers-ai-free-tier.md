# Cloudflare Workers AI 무료 사용량: 하루 1만 뉴런은 소개 글이 말하는 것보다 훨씬 많다

원문: [Cloudflare Workers AI Free: 82 Models, 10,000 Neurons a Day](https://toolfreebie.com/cloudflare-workers-ai/)

## 소개

무료 개발 도구를 소개하는 사이트 toolfreebie.com의 Max Lee가 2026년 4월 17일에 쓰고 9월 8일에 갱신한 Cloudflare Workers AI 무료 사용 안내다.
글은 Workers AI를 텍스트, 이미지, 음성, 임베딩의 82개 공개 모델을 300개가 넘는 도시의 엣지에서 돌리는 서버리스 추론 플랫폼으로 소개한다.
무료 등급은 신용카드 없이 하루 10,000 뉴런을 주며, 네 가지 모달리티를 키 하나로 다루는 유일한 무료 AI API라고 주장한다.

원문이 내세우는 핵심 숫자는 하루 10,000 뉴런이 Llama 3.1 8B 텍스트 호출 약 15~25회에 해당한다는 것이다.
그러나 Cloudflare의 공식 가격표로 다시 계산하면 이 숫자는 한 자릿수 정도 작게 잡혀 있다.
이 문서는 원문의 안내를 따라가되, 숫자와 제약은 공식 문서(가격표는 2026년 9월 17일 갱신판, 한도와 모델 카탈로그는 9월 26일 조회)로 바로잡는다.

## 동작 방식

### 뉴런은 모델별 단가로 환산되는 계량 단위다

Workers AI는 연산량을 뉴런(Neuron)으로 잰다.
공식 문서는 뉴런을 요청을 처리하는 데 드는 GPU 연산을 나타내는 단위라고 설명하며, 가격표에는 모델마다 토큰 단위 가격과 뉴런 단위 가격이 같은 값을 다른 단위로 나란히 적혀 있다.
과금 단가는 1,000 뉴런당 0.011달러이고, Workers Free와 Workers Paid 모두 하루 10,000 뉴런을 무료로 쓴다.

무료 한도는 매일 00:00 UTC에 초기화되고, 이월되지 않는다.
Workers Free 계정은 10,000 뉴런을 넘기면 요청이 실패하며, 더 쓰려면 Workers Paid로 올려야 한다.
Workers Paid에서는 무료 할당을 넘긴 사용량에 1,000 뉴런당 0.011달러가 붙는다.
원문은 유료 플랜이 월 5달러에 5달러어치 연산 크레딧을 포함한다고 적었지만, Workers AI 가격 페이지에는 그런 크레딧이 언급되지 않고 무료 할당 초과분 과금만 적혀 있다.

### 하루 10,000 뉴런으로 실제로 할 수 있는 일

공식 단가로 계산한 하루 무료 사용량은 다음과 같다.
텍스트는 입력 100토큰, 출력 500토큰의 요청 하나를 기준으로 했다.

| 모델                                       | 요청당 뉴런 | 하루 무료 요청 수 |
| ------------------------------------------ | ----------- | ----------------- |
| `@cf/meta/llama-3.1-8b-instruct`           | 약 40       | 약 249회          |
| `@cf/meta/llama-3.1-8b-instruct-fp8-fast`  | 약 18       | 약 560회          |
| `@cf/meta/llama-3.1-8b-instruct-fp8`       | 약 14       | 약 690회          |
| `@cf/openai/gpt-oss-20b`                   | 약 16       | 약 640회          |
| `@cf/meta/llama-3.3-70b-instruct-fp8-fast` | 약 105      | 약 95회           |

계산은 단순하다.
`llama-3.1-8b-instruct`는 입력 100만 토큰당 25,608 뉴런, 출력 100만 토큰당 75,147 뉴런이므로, 입력 100토큰은 약 2.6 뉴런, 출력 500토큰은 약 37.6 뉴런이다.
원문이 말한 “500토큰 응답 하나에 400~600 뉴런”은 이 값의 10배가 넘고, 그래서 “하루 15~25회”라는 결론도 실제의 10분의 1 수준이다.

텍스트 밖의 모델도 넉넉하다.
임베딩 `@cf/baai/bge-base-en-v1.5`는 입력 100만 토큰당 6,058 뉴런이라, 하루 무료 한도로 약 165만 토큰을 임베딩할 수 있다.
음성 인식 `@cf/openai/whisper-large-v3-turbo`는 오디오 1분당 46.63 뉴런이라, 하루 약 214분을 받아 적을 수 있다.
이미지 생성은 가격표에 FLUX와 Leonardo 모델이 올라 있고, 원문이 예로 든 Stable Diffusion XL은 모델 카탈로그에는 있지만 가격표 이미지 절에는 없다.

### 요청 속도 한도는 뉴런과 별개다

뉴런 한도와 별개로 작업 종류별 분당 요청 한도가 있다.
텍스트 생성은 분당 300회이고, 유료 결제가 필요한 모델은 표준 결제에서 분당 20회, 선불 AI Gateway 크레딧으로는 분당 50회다.
음성 인식, 이미지 생성, 번역은 분당 720회, 임베딩과 이미지 분류는 분당 3,000회다.
유료 결제가 필요한 모델은 Kimi K2.6, Kimi K2.7 Code, GLM 5.2, GLM 5.3, GLM 5.3 Flash, DeepSeek V4 Flash와 Pro이며, 무료 계정으로는 쓸 수 없다.

## 설정하기

Cloudflare 계정을 만들고, My Profile의 API Tokens에서 `Workers AI: Run` 권한을 가진 토큰을 만든 뒤, 대시보드 옆 막대의 Account ID를 복사해 환경 변수로 둔다.

```bash
export CLOUDFLARE_API_TOKEN="..."   # Workers AI: Run 권한만 준다
export CLOUDFLARE_ACCOUNT_ID="..."

# 카탈로그에 페이지가 있는 fp8 모델을 쓴다
curl "https://api.cloudflare.com/client/v4/accounts/${CLOUDFLARE_ACCOUNT_ID}/ai/run/@cf/meta/llama-3.1-8b-instruct-fp8" \
  -H "Authorization: Bearer ${CLOUDFLARE_API_TOKEN}" \
  -d '{"messages":[{"role":"user","content":"Explain edge computing in one paragraph."}]}'
```

Worker 안에서 부를 때는 `wrangler.toml`에 AI 바인딩을 추가하고 `env.AI.run()`을 쓴다.

```toml
# wrangler.toml
[ai]
binding = "AI"
```

```javascript
export default {
  async fetch(request, env) {
    const result = await env.AI.run("@cf/meta/llama-3.1-8b-instruct-fp8", {
      messages: [{ role: "user", content: "Summarize the concept of edge AI." }],
      max_tokens: 256, // 출력 토큰이 뉴런 대부분을 차지하므로 상한을 둔다
    });
    return Response.json(result);
  },
};
```

원문은 바인딩을 `[[ai]]`로 적었지만, 이 바인딩은 배열이 아닌 표이므로 `[ai]`로 쓴다.

## 함정

### 출력 토큰이 비용의 대부분이다

텍스트 모델의 뉴런 단가는 출력이 입력보다 3~10배 비싸다.
같은 질문이라도 답을 길게 쓰게 하면 무료 한도가 빨리 줄어든다.
`max_tokens`를 정해 두는 것이 무료 한도를 지키는 가장 쉬운 방법이다.

### 모델 이름이 같아 보여도 단가가 다르다

같은 Llama 3.1 8B라도 `llama-3.1-8b-instruct`, `-fp8`, `-fp8-fast`, `-awq`의 출력 단가는 100만 토큰당 75,147에서 24,215 뉴런까지 세 배 넘게 차이 난다.
원문의 예제 코드가 쓰는 `llama-3.1-8b-instruct`는 가격표에는 남아 있지만 현재 모델 카탈로그에는 페이지가 없고, 가장 비싼 변형이기도 하다.
새로 시작한다면 카탈로그에 있는 양자화 변형을 고르는 편이 싸다.

### 원문의 모델 목록과 제약은 낡았다

원문은 82개 모델이라고 했지만, 공식 문서는 “50개가 넘는 공개 모델”이라고 적고, 모델 카탈로그에는 63개 모델 페이지가 있다.
원문이 텍스트 모델로 든 Phi-2와 Qwen 1.5는 카탈로그에서 찾을 수 없고, 대신 Llama 4 Scout, Gemma 3, gpt-oss, Qwen3 계열이 올라 있다.
원문은 Llama 3.1 70B가 비싼 유료 등급 모델이라고 했지만, 유료 결제가 필요한 모델 목록에는 없고, 가격표에는 70B의 fp8-fast 변형이 무료 할당 안에서 쓸 수 있는 단가로 올라 있다.

원문이 “미세 조정 불가, 자체 가중치 불가”라고 한 것도 정확하지 않다.
공식 문서에 따르면 Workers AI는 LoRA로 학습한 어댑터를 쓰는 미세 조정 추론을 지원하며, 이 기능은 오픈 베타 동안 무료다.
카탈로그에는 Gemma 2B와 7B, Llama 2 7B, Mistral 7B의 LoRA 전용 기본 모델이 있다.
전체 가중치를 올릴 수는 없지만, 어댑터 수준의 맞춤은 가능하다.

### 모든 모달리티가 한 예산을 나눠 쓴다

원문이 짚은 것 가운데 정확한 제약은, 텍스트, 이미지, 음성, 임베딩 호출이 모두 같은 10,000 뉴런을 나눠 쓴다는 점이다.
RAG 파이프라인을 만든다면 문서를 임베딩하는 일괄 작업이 사용자의 대화 요청과 같은 예산을 먹는다.
큰 일괄 임베딩은 하루를 넘겨 나눠 돌리거나, 한 번 만든 벡터를 Vectorize 같은 저장소에 두고 다시 만들지 않아야 한다.

## 비평

### 핵심 숫자가 틀리면 비교 전체가 기울어진다

원문의 비교표는 Workers AI의 무료 텍스트를 “하루 10k 뉴런”, Groq을 “하루 1,000 요청”으로 적는다.
원문의 환산대로라면 Workers AI는 하루 15~25회로 Groq보다 훨씬 적어 보이지만, 공식 단가로는 8B 모델 기준 하루 250~700회다.
무료 AI API를 고르는 독자에게 가장 중요한 숫자가 한 자릿수 틀리면, 그 위에 세운 “프로덕션에는 부족하다”, “100명 넘는 사용자면 한도에 걸린다”는 조언도 함께 과장된다.

글은 9월 8일에 갱신됐다고 표시하지만, 가격 페이지에 모델별 단가가 공개된 뒤에도 뉴런 환산은 바뀌지 않았다.
갱신 날짜가 내용의 최신성을 보장하지 않는다는 점은, 무료 도구 소개 사이트를 읽을 때 늘 염두에 둬야 한다.

### “네 모달리티를 다루는 유일한 무료 API”라는 주장은 확인되지 않는다

원문은 Workers AI가 텍스트, 이미지, 음성, 임베딩을 모두 무료로 다루는 유일한 API라고 결론짓는다.
그러나 비교 대상은 Groq, Gemini, OpenRouter 세 곳뿐이고, Gemini의 무료 텍스트 한도는 “공개되지 않음”으로 비워 두었다.
비교 범위를 좁게 잡고 그 안에서 “유일하다”고 말하는 것은, 넓은 주장을 좁은 근거로 떠받치는 구성이다.

엣지 배포에 대한 강조도 조심해서 읽어야 한다.
Workers AI 공식 문서는 “Cloudflare 네트워크의 서버리스 GPU”에서 모델을 돌린다고 설명하지, 모든 요청이 사용자와 가장 가까운 300여 개 도시 중 한 곳에서 추론된다고 약속하지는 않는다.
GPU가 모든 지점에 있다는 것과 네트워크가 300여 개 도시에 있다는 것은 다른 사실이며, 지연 시간이 중요한 앱이라면 실제 응답 시간을 재 봐야 한다.

## 체크리스트

- 쓸 모델이 현재 모델 카탈로그에 페이지가 있는가?
- 가격표에서 그 모델의 입력과 출력 단가를 확인했는가?
- `max_tokens`로 출력 길이에 상한을 두었는가?
- 일괄 임베딩이 대화 요청과 같은 뉴런 예산을 먹는다는 것을 계산에 넣었는가?
- 무료 계정에서 유료 결제가 필요한 모델을 부르지 않는가?
- 한도가 00:00 UTC에 초기화된다는 것을 운영 시간대와 맞춰 봤는가?
- API 토큰에 `Workers AI: Run` 권한만 주었는가?

## 기억할 원칙

### 무료 등급의 크기는 단가표로 직접 계산한다

무료 도구 소개 글은 무료 한도를 “하루 몇 회” 같은 직관적인 숫자로 바꿔 주지만, 그 환산이 틀리면 선택이 틀어진다.
뉴런, 크레딧, 토큰처럼 추상화된 단위를 쓰는 서비스일수록, 공식 단가표에서 자기 요청의 입력과 출력 크기를 넣어 직접 계산하는 것이 가장 확실하다.
이 문서의 계산도 가격표가 바뀌면 다시 해야 하는 계산이다.

### 추론 단가는 모델 이름보다 변형 이름이 정한다

같은 모델의 정밀도와 양자화 변형이 세 배 넘는 단가 차이를 만든다.
품질 차이가 과제에 중요하지 않다면, 가장 싼 양자화 변형부터 시험하고 품질이 부족할 때만 올리는 편이 무료 한도를 가장 오래 쓰는 방법이다.
