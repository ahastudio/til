# Writing Guidelines

Every rule in the reference files is authoritative and has no exception.
Read each reference file whose topic the task touches before writing, and
run its mandatory check before finishing.

## Which file to read

- Any Korean prose, including a chat message: `references/korean-translation.md`
  and `references/korean-clarity.md`
- Any `.md` file written or edited: `references/markdown-format.md`
- A document that reports what outside pages say, or one built from a social
  post: `references/source-footnotes.md`
- A mention of Twitter or a tweet, or an analytical document:
  `references/twitter-and-argument.md`

## What each file covers

- `references/korean-translation.md`: no literal translation, collocation, never
  force an English term into Korean, translation is understanding first,
  explanatory footnotes for ambiguous terms
- `references/korean-clarity.md`: every sentence must make sense, the banned verb
  stem `박-`, forbidden figurative metaphors, English alongside any ambiguous
  Korean word, standard full terminology
- `references/markdown-format.md`: headings instead of bold, heading and
  footnote spacing, one table row is one record, table alignment, inline code,
  fenced code languages, note document structure, line breaks in body text
- `references/source-footnotes.md`: titled footnotes per sentence for outside
  pages, the analyzed source never takes a footnote, social posts as a
  starting point
- `references/twitter-and-argument.md`: Twitter never X, tweet terminology,
  separating fact, inference and judgment
