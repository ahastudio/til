# Voxvion: 장면 카드에서 타임라인까지, 구독 없는 Windows 영상 제작 도구

<https://voxvion.com/>

<https://apps.microsoft.com/detail/9PFL95FQMZK6>

Show GN: [Voxvion - 이미지·내레이션·자막을 조합해 PC에서 출력하는 Windows 영상 제작 도구](https://news.hada.io/topic?id=36108)

## 소개

Voxvion은 csopera가 혼자 만든 Windows PC용 영상 제작 도구로, Microsoft Store에서 받는다.
홈페이지는 대본, 음성, 사진, 영상을 장면으로 엮고 MP4로 내보내는 흐름을 내세우며, AI는 선택 사항이라고 적는다.
개발자는 2026-10-27에 GeekNews의 Show GN에 이 도구를 소개했다.[^show-gn]
그 글은 이미지와 내레이션으로 설명형 영상을 만들고, 장면별 구성과 자막과 소리를 직접 조정하는 데스크톱 앱이라고 설명한다.

개발자는 전문 편집기를 모두 대체하려는 것이 아니라고 밝힌다.
이미지, 음성, 자막을 조합하는 설명형 영상에 집중한다는 것이다.[^show-gn]
이 범위가 이 도구를 읽는 기준선이다.
다른 영상 편집기와 같은 척도로 재면 빠진 것이 많아 보이고, 설명형 영상이라는 용도 안에서 재면 군더더기가 적다.

## 주요 기능

### 장면 중심 편집과 타임라인

Easy 모드는 장면 카드로 영상을 짜고, Expert 모드는 타임라인으로 세부를 조정한다.
홈페이지는 같은 프로젝트를 두 모드 사이에서 오갈 수 있다고 적는다.
자막, 레이어, 화면 속 화면(PIP)을 더할 수 있고, 이미지 팬과 줌, 텍스트, 그리기 레이어도 지원한다고 Show GN 글이 열거한다.[^show-gn]
내레이션과 배경음악의 볼륨을 따로 조절하고 오디오 비주얼라이저를 쓸 수 있으며, 가로와 세로 영상을 모두 만든다고 한다.[^show-gn]

### 녹화와 발표자 설정

홈페이지는 화면 녹화와 카메라 녹화, 발표자 설정, 그리기 도구를 따로 소개한다.
설명 영상에서 사람이 직접 말하고 화면에 표시하는 쓰임새를 겨냥한 구성이다.

### AI는 직접 키를 연결하는 선택 기능이다

AI 없이도 장면, 자막, 레이어를 자기 자료로 편집할 수 있고, 설치된 Windows 음성은 오프라인으로 쓸 수 있다고 홈페이지는 적는다.
지원되는 AI 공급자로 내레이션, 이미지, 음악을 만들려면 자신의 API 키를 연결하는 BYOK 방식이며, 공급자 요금은 따로 든다.
ElevenLabs 음성 복제는 자신의 음성 표본을 쓰고 자격이 되는 공급자 요금제가 필요하다.
Show GN 글은 외부 AI를 쓸 때 AI 요청에 필요한 자료가 선택한 제공업체로 전송된다고 밝힌다.[^show-gn]

### 사양

C#, WPF, .NET 기반이고 한국어를 포함한 13개 언어 UI를 준비했다고 Show GN 글은 적는다.[^show-gn]
홈페이지의 언어 선택기는 한국어, 영어, 일본어, 독일어, 스페인어, 프랑스어, 포르투갈어, 러시아어, 튀르키예어, 인도네시아어, 베트남어, 번체 중국어, 힌디어를 나열한다.
프로젝트와 미디어는 PC의 로컬 라이브러리에 저장된다.
Show GN 글은 현재 Windows x64 환경만 지원하고, 출력 속도와 처리 가능한 미디어는 PC 환경과 코덱의 영향을 받는다고 덧붙인다.[^show-gn]

## 사용하기

Show GN 글과 홈페이지가 말하는 사용 흐름은 세 단계다.
먼저 대본, 음성, 사진, 영상을 가져온다.
다음에 장면을 만들어 음성과 자막을 맞추고 레이어로 표현을 더한다.
마지막으로 미리 보기를 확인하고 MP4로 내보낸다.

가격 구조는 홈페이지 설명 기준으로 다음과 같다.

| 구분          | 내용                                                                                    |
| ------------- | --------------------------------------------------------------------------------------- |
| 무료 기본 앱  | 편집, 자막, 레이어, 녹화, 내보내기. 출력 영상에 워터마크가 들어간다                     |
| 워터마크 제거 | 한 번 구매하면 새로 렌더링하는 영상에서 영구히 제거된다. 기본 앱 업데이트는 계속 무료다 |
| 전문 기능     | 일부는 별도 선택 구매다                                                                 |
| AI            | 공급자 요금이 따로 들고 자신의 API 키가 필요하다                                        |
| 구독          | 구독이나 업데이트 갱신 요금은 계획하지 않는다고 적는다                                  |

현재 가격은 이 노트에서 확인하지 못했다.
홈페이지와 Show GN 글 모두 최신 가격과 구매 가능 여부는 Store와 앱 안내에서 확인하라고 한다.
Microsoft Store 목록은 페이지 본문이 막혀 있어 읽지 못했고, 화면에서 앱 이름, 게시자(csopera), 분류(사진 및 동영상), 연령 등급 3+, AI 기능 사용 표시만 확인했다.

### 안드로이드 Voxvion M

홈페이지는 Android용 Voxvion M을 따로 소개한다.
공개 출시, 가격, 제공 여부는 준비 중이고, Windows 구매에는 Android 권리가 포함되지 않으며, iOS는 지원하지 않는다.
휴대전화에서 장면을 만들고 720p 가로나 세로 MP4를 내보낼 수 있고, 현재 한도는 3분, 30장면, 자막과 핵심 항목 합계 15개다.
PC로 넘기는 ZIP은 파일 전달이지 타임라인 자동 동기화가 아니며, 영상 장면은 대표 정지 이미지로 바뀌므로 움직임을 보존하려면 MP4나 원본 영상을 따로 공유해야 한다.

## 분석

### 영상 편집기를 설명 영상의 조립 공정으로 다시 자른다

Voxvion의 제안은 영상 편집기의 기능 수를 줄이는 것이 아니라 단위를 바꾸는 것이다.
전통적인 편집기는 클립과 트랙이 단위이고, Easy 모드는 장면이 단위이며 장면 하나가 이미지, 내레이션, 자막을 묶는다.
설명형 영상은 말할 내용이 먼저 정해지고 화면은 그것을 받치는 구조라서, 장면 단위가 작업의 순서와 맞는다.
Expert 타임라인은 그 단위로 풀리지 않는 세부 조정을 맡는 출구로 읽힌다.
이것은 홈페이지 설명에서 읽은 이 노트의 해석이다.

### 같은 프로젝트로 두 모드를 오가게 한 것이 핵심 설계다

두 모드가 별개의 도구이면 쉬운 쪽에서 시작한 사람이 세부 조정이 필요해질 때 처음부터 다시 만들어야 한다.
홈페이지는 같은 프로젝트를 Easy에서 Expert로 옮길 수 있다고 적는다.
개발자가 Show GN 글에서 의견을 구한 지점도 장면 중심 편집과 타임라인 사이를 오가는 흐름이 이해하기 쉬운지다.[^show-gn]
이 설계의 성패는 모드를 오갈 때 장면 구조가 타임라인에서 어떻게 보이고, 타임라인에서 고친 것이 장면 카드로 돌아오는지에 달려 있으며, 이 노트는 앱을 설치해 보지 않아 그 동작을 확인하지 못했다.

### 수익 구조는 AI 비용을 사용자가 직접 내는 쪽으로 설계되어 있다

BYOK는 개발자가 AI 호출 비용을 떠안지 않는 구조다.
무료 기본 앱에 워터마크를 두고 일회 구매로 제거하게 한 것은 구독을 피하려는 선택이다.
세 요소를 합치면 개발자의 고정 비용이 낮고, 사용자는 쓴 만큼만 공급자에게 낸다.
혼자 개발하는 도구가 구독과 서버 비용 없이 버티는 한 가지 모양이다.

## 비평

### 가격이 없다는 점이 비교를 막는다

홈페이지와 Show GN 글 모두 현재 가격을 적지 않고 Store로 돌린다.
일회 구매 가격과 별도 선택 구매 기능의 목록을 모르면 무료 앱과 구매 후 앱의 차이를 계산할 수 없다.
구독이 없다는 약속도 별도 전문 기능의 구매가 계속 생길 수 있다는 문장과 같은 자리에 있어, 총비용이 열려 있다.
출력 영상에 워터마크가 들어가는 무료판은 시험용으로는 충분해도 결과물로 쓰기 어렵다는 점도 구매를 전제로 한 구조다.

### 설명형 영상에서의 완성도를 보여 주는 증거가 없다

두 글은 기능을 열거하지만 출력 영상의 예, 렌더링 속도, 처리 가능한 코덱이나 해상도의 범위를 적지 않는다.
출력 속도와 처리 가능한 미디어가 PC와 코덱에 좌우된다는 개발자의 말은 정직하지만, 읽는 사람에게는 어떤 PC에서 얼마나 걸리는지 알려 주지 않는다.
이 노트도 앱을 설치하지 않았으므로 어떤 품질의 결과가 나오는지 확인하지 못했다.

### 데이터가 나가는 경로가 사용자에게 넘어간다

AI를 쓰면 필요한 자료가 선택한 공급자에게 전송된다는 문장이 홈페이지와 Show GN 글에 모두 있다.
이 구조는 공급자의 정책과 요금을 사용자가 읽고 판단하라는 요구다.
편집 자체는 로컬에서 이뤄진다는 점은 장점이지만, AI 기능을 켜는 순간 어떤 자료가 얼마나 나가는지는 기능마다 안내를 읽어야 안다.
홈페이지는 방문 집계에 일별 식별자 해시를 최대 365일 보관하며 IP는 저장하지 않는다고도 적는다.

### 모바일과의 연결이 아직 끊어져 있다

Voxvion M은 출시와 가격이 준비 중이고, Windows 구매에 포함되지 않으며, PC로의 전달은 ZIP 파일 방식이다.
영상 장면이 정지 이미지로 바뀌는 점은 휴대전화로 찍은 영상을 중심에 두는 사용자에게 직접적인 손실이다.
모바일에서 시작해 PC에서 마무리하는 흐름을 홍보하지만, 현재 한도(3분, 30장면)와 파일 전달 방식은 그 흐름이 거칠다는 뜻이다.

## 인사이트

### 장면 단위 편집은 대본 중심 작업자에게 맞는 추상화다

강의, 소개, 쇼츠처럼 말할 내용이 먼저 있는 영상은 컷 편집보다 구성과 속도 조절이 어렵다.
홈페이지가 Voxvion의 예로 드는 것이 강의, 소개, 쇼츠다.
장면 카드가 대본과 화면을 묶는 단위가 되면 편집이 서사를 맞추는 일로 바뀐다.
이런 도구가 잘 작동하는 조건은 장면이 하나의 문장과 하나의 이미지로 정리되는 영상이며, 컷 사이의 리듬이 중요한 영상에서는 타임라인으로 내려가는 비용이 빨리 늘어난다.

### BYOK와 일회 구매의 조합은 개발자의 책임을 조용히 넘긴다

AI 비용, 공급자 정책, 데이터 전송의 책임이 사용자 쪽으로 가고, 개발자는 편집 경험에 집중한다.
이 분담은 개발자에게 합리적이지만, 사용자에게는 설정을 이해하는 비용으로 돌아온다.
공급자 API 키를 발급받고 요금제를 고르는 일은 설명 영상을 만들려는 비개발자에게 첫 설치 뒤 가장 먼저 막히는 지점이 될 수 있다.
개발자가 Show GN 글에서 처음 설치한 뒤 어디에서 막히는지를 묻는 것도 이 지점을 의식한 것으로 읽힌다.[^show-gn]
이것은 이 노트의 해석이며, 개발자가 이렇게 말한 것은 아니다.

### 로컬 우선 단일 개발자 도구는 작은 틈새에서 오래 가는 모양이다

구독, 서버, 계정 없이 PC의 로컬 라이브러리에 저장하고 일회 구매로 수익을 내는 구조는 유지 비용이 낮다.
대신 사용자 수가 늘어도 수익이 구매 건수에만 비례하고, 모바일 앱과 AI 기능 같은 확장은 별도 구매와 별도 출시로 쪼개져 나온다.
이 도구가 이 모양으로 얼마나 오래 갈지는 관찰해야 알 수 있다.
볼 것은 두 가지다.
하나는 Voxvion M이 실제로 출시되었을 때 Windows 구매와의 권리 분리가 사용자에게 어떻게 받아들여지는가이고,
다른 하나는 별도 구매 전문 기능이 얼마나 늘어나 총비용이 구독과 비슷해지는가다.
