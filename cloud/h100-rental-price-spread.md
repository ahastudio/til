# 같은 H100이 시간당 2.69달러에서 12.29달러까지: 4.57배 격차를 읽는 법

<https://github.com/datareceipts/data-receipts/tree/main/109-gpu-pricing>

HN 토론: <https://news.ycombinator.com/item?id=50427085> (167점, 84개 댓글)

GN 토론: <https://news.hada.io/topic?id=36893>

## 소개

Data Receipts 저장소의 109번 항목은 AWS, Azure, 네오클라우드(neocloud)에서
온디맨드로 빌리는 GPU 가격을 GPU 한 장의 시간당 달러로 환산하고,
같은 GPU끼리만 묶어 비교한다.
저장소 첫 문서는 이 프로젝트를 같은 이름의 채널에 나오는 모든 숫자와 그것을 만든
스크립트를 모은 곳이라고 설명하며, 영상을 믿지 말고 스크립트를 돌려 보라는
방침을 내세운다.
저장소는 2026년 10월 26일에 만들어졌고 2026년 11월 10일에 확인한 별은 16개다.
숫자는 모두 판매자의 API나 공개 자료에서 가져오고, 모든 수치에 출처 URL과
조회 날짜를 붙이며, 판단이 필요한 비교는 그 판단을 적는다는 규칙을 둔다.

### 결과

H100 SXM 80GB의 시간당 값은 다음과 같다.

| 업체                    | GPU 한 장 시간당 | 한 달(730시간) |
| ----------------------- | ---------------- | -------------- |
| RunPod Community        | $2.69            | $1,964         |
| RunPod Secure           | $3.99            | $2,913         |
| AWS `p5.48xlarge`       | $6.88            | $5,022         |
| Azure `ND96isr_H100_v5` | $12.29           | $8,972         |

최저가와 최고가의 차이는 4.57배이고, 한 장을 한 달 내내 돌리면 1,964달러와
8,972달러 사이가 된다.
README는 비교를 같은 모델과 같은 메모리끼리(SXM 80GB, PCIe 80GB, NVL 94GB는
서로 다른 제품) 묶어서 하며, 같은 업체 안에서도 가장 싼 경로를 쓴다고 밝힌다.
Azure가 같은 A100 PCIe 80GB를 VM의 GPU 수 1개, 2개, 4개에서 GPU당 3.67, 4.78,
4.78달러로 내는 예처럼 같은 업체 안의 차이가 시장의 차이로 보이지 않게 하려는
처리다.

### 4.57배가 아닌 것

README는 이 차이가 순수한 이윤이 아니라고 스스로 적는다.
Azure ND 시리즈는 GPU당 400Gbps Quantum-2 인피니밴드와 GPU 다이렉트 RDMA를
갖추었고, 이것이 다중 노드 학습을 가능하게 하며 ND가 Azure 자체의 단일 H100
NC 상품(6.98달러)보다 비싼 이유다.
RunPod Community는 제3자 호스트가 자기 하드웨어를 빌려주는 것이라 데이터센터
서비스 수준 협약(SLA)이 없다.
한 노드에서 미세 조정을 하는 사람은 쓰지 않을 인터커넥트 값을 내는 것이고,
64노드에 걸쳐 학습하는 사람에게 싼 줄은 선택지가 아니다.

### 한계

README는 한계를 따로 적는다.
온디맨드 정가만 비교하고, 예약, 약정, 스팟(spot) 가격은 빠졌으며
특히 스팟은 격차를 크게 좁힐 것이라고 한다.
지역은 AWS `us-east-1`과 Azure `eastus` 하나씩이고,
GPU 수는 가격 라벨이 아니라 판매자 문서에서 읽었다.
Lambda는 게시된 요율이 2026년 11월 16일부터 적용되고 현재 요율은 로그인 뒤에
있어 헤드라인에서 제외하고 따로 보여 준다.
가용성은 값에 반영되지 않았으며, 구할 수 없는 싼 H100은 가격이 아니라고 적는다.
네오클라우드 가격은 API로 받을 수 없어 판매자 가격 페이지를 손으로 옮겨 적었고,
조회일은 2026년 11월 9일이다.

## 분석

### 격차의 대부분은 같은 칩에 붙은 서로 다른 상품에서 나온다

비교 표의 네 줄은 칩이 같을 뿐 상품이 다르다.
Community는 장애 보증이 없는 제3자 하드웨어이고, Secure는 업체가 운영하는
데이터센터이며, AWS와 Azure는 인피니밴드와 약정과 규정 준수를 갖춘 대형 SKU다.
README가 순서대로 설명하듯 4.57배의 상당 부분은 GPU 값이 아니라 네트워크와
보증의 값이다.
같은 칩이라는 말은 가격표를 읽는 출발점이고, 무엇을 같이 사는지를 확인하는
것이 다음 단계다.

### 비교를 투명하게 만든 방식이 신뢰의 근거다

저장소는 수집 스크립트(`collect.py`), 원자료(`hyperscalers.json`,
`vendors.json`), 계산(`compute.py`), 결과(`compare.json`)를 모두 싣는다.
`vendors.json`은 업체마다 출처 URL과 읽은 날짜, 유효 시점, 메모를 적는다.
AWS와 Azure는 인증이 필요 없는 가격 API에서 받고,
네오클라우드는 손으로 옮겼다고 파일 머리에 밝힌다.
이 구조는 숫자를 믿게 하는 대신 다시 만들 수 있게 한다는 저장소의 방침과
맞는다.

### 온디맨드 정가는 구매자가 실제로 내는 값이 아니다

README가 스스로 말하듯 약정이나 스팟을 쓰면 대형 업체의 값이 내려간다.
HN에서 한 사용자는 SkyPilot의 자료에서 8장 H100의 최저가가 시간당 1.90달러,
평균 7.08달러, 중앙값 7.91달러라고 알렸다.[^covi]
이 숫자는 댓글의 인용이며 이 문서가 확인하지 못했다.
다른 사용자는 스팟과 선점형 시장을 영리하게 쓰면 대형 업체 온디맨드
대비 10배 넘는 비용 이점이 위험 거의 없이 가능하다고 주장했다.[^itkovian]
정가 비교는 출발점이지 구매 결정의 근거로는 부족하다.

## 비평

### 헤드라인의 쌍은 가장 극단을 고른 것이다

제목은 최저가와 최고가를 짝지었다.
README의 표대로 같은 Secure 클라우드와 AWS만 견주면 3.99달러와 6.88달러로
약 1.7배이고, Secure와 Azure ND는 약 3.1배다.
제목의 4.57배는 제3자 호스트의 커뮤니티 클라우드와 인피니밴드 SKU의 비교여서
같은 조건의 상품 간 격차가 아니다.
README는 이를 숨기지 않으나 제목과 표지 숫자는 극단을 앞세운다.
HN의 한 사용자도 표의 칸 몇 줄과 사족이 어떻게 상단에 올랐느냐고
의아해했다.[^refulgentis]

### 싼 쪽의 위험은 가격표에 나타나지 않는다

HN 댓글의 가장 큰 가지는 싼 업체의 보안과 신뢰였다.
한 사용자는 RunPod Community나 Vast에서 가치 있는 작업을 돌리는 것은 미친 짓이며
호스트가 가상 머신 안을 들여다본다고 썼다.[^plantain]
다른 사용자는 가치 있는 작업이라도 기밀이 중요하지 않은 것이 많다며,
미세 조정 학습을 엿봐도 손해가 없는 사례를 들었다.[^gpm]
또 다른 사용자는 이 플랫폼이 사람들이 집 장비를 빌려주는 구조라 일관된
개인정보 정책이 있을 수 없다고 설명했다.[^epistasis]
반대편에서는 대형 업체가 오히려 더 많은 자원과 동기를 갖고 있다는 주장이
나왔고, 이에 대해 대형 업체는 은폐가 어렵고
잃을 것이 많다는 반박이 이어졌다.[^dv_dt][^crazygringo]
가격 비교는 업무의 기밀성에 따라 다른 상품 간의 비교라는 점을 이 논쟁이
보여 준다.

### 가용성과 성능 편차가 가격을 무의미하게 만들 수 있다

한 사용자는 RunPod가 훌륭하지만 20GB를 넘는 VRAM의 특정 GPU를 원할 때
구할 수 있는지는 별개이고, 그때 H100 가격은 대체로 무의미했다고 썼다.[^jdc0589]
다른 사용자는 Azure에서 크레딧이 수십만 달러 있어도 GPU 할당량을 받지 못했다고
썼다.[^noodlesUK]
Vast.ai에서는 클럭이 80%로 제한된 장비나 낮은 전력 상태의 GPU가 문제라는 증언도
있었다.[^m00x]
README는 가용성이 값에 반영되지 않았다고 적지만,
가용성과 같은 칩의 성능 편차가 실제 비용을 정하는 사례가 많음을 댓글이 보여
준다.
SemiAnalysis의 ClusterMax 같은 평가가 별도로 만들어진 이유도 같은 곳에 있다고
한 사용자가 지적했다.[^eitally]

### 손으로 옮긴 가격은 시간이 지나면 틀린다

네오클라우드 가격은 판매자 페이지를 사람이 옮겨 적었고,
README 규칙 3도 숫자가 조회일까지만 참이라고 말한다.
HN에서 한 사용자는 자신이 RunPod에서 B300을 시간당 8.99달러에 쓰고 있다고
했고,[^matt3210]
다른 사용자는 H100을 Modal에서 3.95달러로 쓴다고 했다.[^pwython]
가격은 변하고 업체도 많아서, 표는 한 시점의 표본이라는 한계를 가진다.

## 인사이트

### 가격표 비교는 상품이 같을 때만 의미가 있다는 원칙의 사례가 된다

이 항목의 가장 좋은 점은 비교를 같은 칩끼리로 한정하고 같은 업체 안의 차이를
시장의 차이로 세지 않은 것이다.
그런데도 4.57배가 헤드라인이 되는 순간 독자는 같은 상품의 가격 차이로 읽는다.
측정자가 아무리 엄밀해도 숫자가 요약되는 순간 조건이 떨어져 나간다는 것을
이 사례가 보여 준다.
이것은 이 문서의 해석이다.

### 차익거래가 없는 이유가 곧 격차의 설명이다

HN에서 한 사용자는 싸게 사서 비싸게 파는 차익거래가 없느냐고 물었고,[^gigatexal]
다른 사용자는 GPU 시장이 있으면 차익 기회를 활용할 수 있겠다고 했다.[^qoez]
격차가 지속된다는 사실 자체가 가격이 같은 상품의 값이 아니라는 증거다.
재판매가 어려운 것은 신뢰, 인피니밴드 같은 부속 사양, 가용성, 규정 준수가
상품의 일부이기 때문이다.
싼 업체를 사서 비싼 업체의 상품으로 되팔 수 없는 구조가 격차를 유지한다.

### 가격 지수 같은 중개 도구가 이 시장의 다음 단계다

HN에서 한 사용자는 가격 관측과 거래 데이터로 만드는 Silicon Index나 체결된
거래만 쓴다는 Ornn 지수 같은 새 지수를 소개했다.[^buredoranna]
다른 사용자는 이 지수의 업체와 거래해 봤더니 엉터리였다고 반박했다.[^blobbers]
GPU 시간이 상품(commodity)처럼 거래되려면 신뢰할 가격 기준이 필요하다는 점은
분명하고, 현재 기준을 누가 정하는지는 아직 정해지지 않았다.
