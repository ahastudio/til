# Claude를 대화창에서 질문하고 복사하는 용도로만 쓰면 기능의 10%만 쓰는 것이며, 스무 가지 기능 중 하나만 골라 오늘 설정하면 된다

트윗: [Claude hace todo esto (y casi nadie lo sabe)](https://twitter.com/angeldot_/status/2109284255939297357)

## 소개

angel(@angeldot_)이 2026-10-11에 올린 스페인어 Twitter Article이다.
프로필은 친구들이 기술 이야기에 질려서 이 계정을 만들었다고 적고 있다.
이 문서가 읽은 시점에 이 트윗은 조회 약 195만, 좋아요 1,343이었다.

글의 전제는 대부분의 사람이 Claude를 10%만 쓴다는 것이다.
채팅을 열고 묻고 답을 복사하고 닫는 것이 대다수의 사용 방식인데,
Claude에는 대다수가 써 보지 않은 기능이 있다고 한다.
기억(memory), 채팅 안에서 동작하는 앱, 자는 동안 스스로 실행되는 작업, 브라우저
제어 같은 것이다.
글은 기능이 어디 있는지, 어떻게 켜는지, 오늘 바로 복사해 시험할 프롬프트를 모두
준다고 약속하고,
각 기능은 몇 분이면 설정되고 그 뒤로 매일 시간을 아껴 준다고 한다.
마지막은 한꺼번에 하지 말고 목록에서 하나만 골라 지금 설정하라는 권유이다.

글은 20개 기능을 다섯 부분으로 나눈다.
이 문서는 글이 소개하는 기능의 서술을 옮기며, 어느 것도 직접 켜 보거나 최신 제품
문서와 대조하지 않았다.

| 번호 | 기능                          | 글의 설명                                                                                                                                                               |

| 1    | 프로젝트(Projects)            | 문서를 올리고 고정 지침을 쓰면 그 프로젝트의 모든 채팅에서 Claude가 맥락을 갖고 있어, 매번 자기소개를 반복하지 않는다                                                   |

통과시키지 않는 것이 달라진다고 한다.

| ---- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 17   | 프롬프트 캐싱(prompt caching) | API 호출이 큰 컨텍스트 블록(긴 시스템 프롬프트, 참고 문서, 코드베이스)을 반복하면 같은 토큰을 매번 처리하는 비용을 낸다. 해당 블록에 `"cache_control": {"type": "ephemeral"}`을 붙이면 서버가 저장해 다음 호출에서 재사용한다. 캐시된 토큰은 최대 90% 싸고 응답이 꽤 빠르다. 기본 캐시는 5분이며 쓸 때마다 갱신된다 |

| 번호 | 기능                  | 글의 설명                                                                                                                                                                                                                                                                                                          |
| ---- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 18   | 영상 편집             | 타임라인이 아니라 코드를 써서 실행한다(보통 ffmpeg). Claude Code와, 파일로 작업하는 앱에서 된다. 자르기, 이어 붙이기, 무음 제거, 가로 영상을 9:16 세로로 변환, 오디오 추출과 압축, 속도 조절과 GIF 변환, 영상 50개 일괄 처리가 예이다. 창의적 편집에서 Premiere를 대체하지 않지만 반복 작업의 시간을 아낀다고 한다 |
| 19   | 커넥터(connectors)    | 기본적으로 Claude는 메일과 일정을 보지 못한다. 설정에서 Gmail, Google Calendar, Drive, Notion 등을 연결하면 검색, 읽기, 교차 정리를 한다                                                                                                                                                                           |
| 20   | 사진에서 스프레드시트 | 영수증이나 청구서 사진을 항목, 금액, 부가세 표로, 오류 화면 캡처를 원인과 해결로, 화이트보드 사진을 정리된 요약으로, 마음에 드는 웹 화면 캡처를 HTML 시안으로 바꾼다                                                                                                                                               |

글이 기능마다 붙인 프롬프트는 이 문서가 본문 데이터에서 확인했다.
메모리 저장, 심리학자, 필터 없는 멘토, 트레이너, 어려운 대화 연습, 악마의 변호인
같은 역할 프롬프트는 대괄호 칸(이름, 목표, 제약)을 채워 쓰는 틀이다.
예를 들어 예약 작업의 예는 평일 오전 7시 30분마다 지난 24시간의 AI 뉴스에서
중요한 다섯 개를 골라
제목, 두 문장 요약, 중요한 이유를 `brief-[날짜]`로 저장하게 한다.
악마의 변호인 프롬프트는 결정, 자신의 근거, 이미 고려한 것을 입력받아
가장 강한 반대 논거, 틀릴 수 있는 가정, 가장 현실적인 실패 세 가지,
“이것이 정말 나쁜 생각이려면 무엇을 믿어야 하는지”를 묻는다.
Claude Code 예시 `CLAUDE.md`는 뉴스레터 프로젝트의 문체 규칙(짧은 문단,
형용사보다 숫자, 금지어), 내용 규칙, 파일 구조를 적는다.
API 예시는 모델 `claude-opus-5-5`와 `system` 블록에 `cache_control`을 붙이는
JSON이다.

## 비평

### 기능의 가용 범위와 요금제 조건이 글에 없다

글은 각 기능이 어디서나 쓸 수 있는 것처럼 쓰지만,
메모리, Claude in Chrome, 예약 작업, 커넥터, 디자인이 모든 요금제와 지역에서
켜지는지는 밝히지 않는다.
이 문서는 글이 소개한 기능이 지금 제품 문서에 있는지 확인하지 못했다.
기능 이름과 위치는 제품이 바뀌면 달라지는 정보이고, 글은 2026-10-11 시점의
서술이다.
따라서 이 목록은 시작점으로 읽고, 설정은 제품 화면과 공식 문서로 다시
확인해야 한다.

### 숫자와 단정은 근거 없이 쓰였다

“대부분이 Claude를 10%만 쓴다”와 “이걸 거의 아무도 모른다”는 수치나 조사 없이 쓴
수사이다.
Figma 3시간이 대화 10분이 된다는 비교도 한 사례의 어림이다.
프롬프트 캐싱의 “최대 90%”와 5분은 구체적 수치이지만 글은 근거 문서를 연결하지
않았다.
이 문서는 그 수치를 공식 문서와 대조하지 않았다.

### 개인 데이터와 권한에 대한 경고가 약하다

메모리는 하는 일과 프로젝트를 저장하고, 커넥터는 메일과 일정을, 데스크톱 앱은
컴퓨터의 폴더를, Claude in Chrome은 열린 탭에 접근한다.
글은 이 기능들을 “설정하면 편하다”로 설명하고 무엇이 어디에 저장되는지, 어떤
권한을 주는지, 어떻게 끄는지는 다루지 않는다.
예약 작업도 “자는 동안 일한다”고만 쓰고 실패했을 때나 의도치 않은 동작은 다루지
않는다.
예외는 심리학자 프롬프트에 붙인 전문가를 대체하지 않는다는 한 줄뿐이다.

### 역할 프롬프트의 효과는 근거가 글쓴이의 주장이다

필터 없는 멘토와 악마의 변호인은 Claude가 기본적으로 사용자 쪽에 서는 경향을
줄이려는 프롬프트이다.
“쓰리다, 그래서 효과가 있다”는 글쓴이의 평가이며 이 효과를 비교한 결과는
글에 없다.
반대 논거를 요구하는 프롬프트는 실제 약점이 아닌 억지 반론도 만들 수 있다는 점이
글에서 다뤄지지 않는다.
이것은 이 문서의 지적이다.

### 개발자 부분이 한 항목뿐이다

4부는 프롬프트 캐싱 하나이고, Claude Code, `CLAUDE.md`, 스킬 같은 개발자에게
중요한 기능은 3부에 섞여 있다.
독자가 일반 사용자인지 개발자인지에 따라 읽을 부분이 다른데, 글은 이를 구분해
안내하지 않는다.

## 적용하기

### 오늘 하나만 고르는 기준

글의 마지막 권유(하나만 골라 설정)를 따르려면 지금 가장 자주 반복하는 수고를
기준으로 고르는 것이 좋다.
매번 같은 배경을 설명하고 있다면 프로젝트나 메모리이고,
같은 형식의 작업을 반복한다면 스킬이나 예약 작업이며,
결정 전에 반박이 필요하다면 악마의 변호인 프롬프트이다.
이 선택 기준은 글의 목록을 이 문서가 정리한 제안이다.

### 설정 전 확인할 것과 실패 조건

권한을 주는 기능(메모리, 커넥터, 폴더 연결, 브라우저 확장)은 켜기 전에 무엇에
접근하는지와 끄는 방법을 먼저 확인한다.
한 주 써 보고 같은 수고가 실제로 줄지 않았다면 그 기능은 꺼도 된다.
예약 작업은 처음 한두 번 결과를 직접 읽어 보고, 틀린 내용이 반복되면 프롬프트를
고치거나 중단한다.
프롬프트 캐싱은 같은 큰 블록을 5분 안에 반복해서 부를 때만 이득이 있으므로,
호출 간격이 그보다 길다면 효과가 없다는 것이 글의 설명에서 나오는 조건이다.
