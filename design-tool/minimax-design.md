# MiniMax Design은 여러 생성 모델을 에이전트 팀으로 묶어 로컬 데스크톱에서 영상과 이미지 제작을 처리하려는 도구다

<https://design.minimax.io/>

## 소개

MiniMax Design은 MiniMax가 내놓은 데스크톱 앱이다.
회사는 이를 텍스트, 이미지, 영상 모델의 작업 흐름을 에이전트(agent)로 엮어 주는
AI 창작 플랫폼이라고 소개한다.
macOS 13 이상(M1부터 M5까지의 Apple Silicon과 구형 Intel Mac)과 Windows 10
이상(x64)용 설치 파일을 제공하며, 글로벌 버전과 중국 버전을 따로 내려받게 한다.
사이트는 영어, 중국어 간체와 번체, 일본어, 한국어를 포함한 14개 언어로 열린다.

회사가 내세우는 약속은 아이디어 한 줄이나 기획서(brief)를 넣으면 에이전트가
의도를 읽어 작업을 쪼개고, 알맞은 모델을 자동으로 골라 주며, 사용자는 요소마다
직접 고를 수도 있다는 것이다.
결과물은 이미지, 영상, 음성 해설(voiceover), 편집본이다.
대상으로 꼽은 용도는 숏드라마, 이커머스 콘텐츠, 브랜드 TVC, 광고 소재이다.

## 작업 방식

회사는 제작 과정을 다섯 단계로 설명한다.

| 단계 | 이름         | 회사의 설명                                                                       |
| ---- | ------------ | --------------------------------------------------------------------------------- |
| 1    | Idea Intake  | 메인 에이전트가 의도를 읽고 작업을 분해하며 모델을 맞춘다                         |
| 2    | Canvas Flow  | 대본, 스토리보드, 영상, 음악, 편집을 한 캔버스의 노드(node)로 두고 자동 연결      |
| 3    | Reuse Layer  | 대화로 Skills를 만들거나 Plaza의 검증된 워크플로를 한 번에 설치                   |
| 4    | Local Bridge | 캔버스 자산을 로컬에 저장하고, 에이전트가 로컬 파일에 접근하며 전문 도구로 내보냄 |
| 5    | Review Loop  | 주요 체크포인트에서 에이전트가 방향을 묻고, 여러 차례 품질 점검을 돌림            |

병렬 처리는 이 도구의 중심 설명이다.
회사에 따르면 복사(copy), 이미지, 영상, 오디오 에이전트 네 개가 동시에 시작해,
글을 쓰고 시각 자료를 만들고 타임라인을 조립하고 음성을 만든다.
마지막 단계에서 결과를 합쳐 편집하고 내보낸다.
여섯 가지 기능으로는 기획과 대본 생성, 이미지 자산 생성, 영상과 타임라인 처리,
오디오와 음성 처리, 자동 패키징과 규격 변환, 통합 출력과 관리를 든다.

### Skills

Skills는 반복되는 제작 방법을 묶어 둔 것이다.
회사는 업종별 작업자가 만든 Skills를 설치하거나 직접 만들 수 있고, 쓸수록 도구가
더 쓸모 있어진다고 말한다.
버전이 붙은 예시로는 Grammy Rap MV(`v0.1.5`), Promotional Video, E-commerce
Product Images, Audiobook, Animal Podcast, Character Scene
Storyboard(`v1.4.11`), Image Remix, MV Creator가 나온다.
Promotional Video는 제품 기획서를 마케팅 영상으로 바꾸고, E-commerce Product
Images는 원본 사진에서 플랫폼 규격에 맞는 제품 이미지 세트를 만든다.
전체 목록은 앱을 내려받아야 볼 수 있다고 안내한다.

## 모델과 도구

회사는 `/tools` 아래에 20개 항목의 도구 목록을 두었다.
앞쪽 항목은 AI 애니메이션 생성, 영상 생성, 디자인 생성, 이미지 생성, 사진 편집,
얼굴 교체(face swap), 이미지에서 영상 변환이다.[^tools]
목록은 외부 모델 이름을 직접 내세운다.
이미지 생성은 Seedream, Nano Banana, GPT Image 2를 쓴다고 하고, GPT Image 2.5,
Kling 3.0 Omni, Kling 4.0도 항목으로 있다.[^tools]
Kling 4.0 항목은 최대 30초 영상, 원음 오디오, 4K 출력을 내세우고, GPT-6 Astra
항목은 공식 API 가격의 10% 정도부터 쓸 수 있다고 적는다.[^tools]
MiniMax 자체 모델로는 H3가 ComfyUI에서 쓰는 방법을 다루는 항목이 있다.[^tools]
정리하면 이 도구는 자체 모델 하나가 아니라 여러 회사의 모델을 한 작업 화면에서
고르게 하는 구조이다.

## 로컬 우선 저장과 공개 범위

회사는 캔버스 자산이 로컬에 자동 저장되며 에이전트가 로컬 파일에 접근한다고
설명하고, 로컬 파일을 비공개로 유지한다고 말한다.
다만 생성 자체는 외부 모델을 호출하는 작업이므로, 어떤 입력이 서버로 나가는지는
사이트 본문이 설명하지 않는다.

## 커뮤니티와 기업용

회사는 세 갈래의 부가 프로그램을 안내한다.
크리에이터 프로그램은 MiniMax Design Director가 되어 Skills와 형식을 함께 만드는
모임이고, 선정된 창작자에게 신규 에이전트 조기 접근, Skills 수익 배분, 공동
마케팅을 약속한다.
기업용은 브랜드와 스튜디오를 대상으로 대규모 안정 출력, 전담 계정 지원, 맞춤
Skills, 온프레미스(on-prem) 배포를 내세운다.
튜토리얼은 안내된 프로젝트의 라이브러리이며 영구 무료라고 한다.

## 분석

### 이 제품의 구조는 모델 선택과 작업 조율을 앱이 맡는 것이다

기존 생성 도구는 이미지, 영상, 음성이 서로 다른 서비스에 흩어져 있어서 결과물을
사람이 옮겨 가며 이어 붙인다.
MiniMax Design이 파는 것은 이 이음매를 없애는 일이다.
메인 에이전트가 의도를 작업 단위로 쪼개고 모델을 고르며, 캔버스의 노드가 한
단계의 출력을 다음 단계의 입력으로 넘긴다.
외부 모델 이름을 그대로 노출하는 도구 목록은 이 점을 뒷받침한다.
앱의 가치는 모델 성능이 아니라 조율과 작업 이력의 재사용에 있다고 읽을 수 있다.

### Skills는 반복 작업을 재사용 가능한 단위로 만든다

Skills는 한 번 잘된 워크플로를 이름과 버전이 붙은 단위로 만들고, 다른 사람이
설치하게 한다.
버전 숫자(`v0.1.15`, `v1.4.11`)가 붙은 것은 Skills가 갱신되는 소프트웨어
패키지처럼 다뤄진다는 뜻이다.
크리에이터 프로그램이 Skills의 수익 배분을 약속하는 점은 Skills를 마켓플레이스의
상품으로 보는 설계를 드러낸다.

### 마케팅 문구의 틀은 감독의 의자이다

사이트는 사용자를 감독(director)으로, 에이전트를 제작진(crew)으로 부른다.
이 틀은 사용자의 역할이 프롬프트 작성이 아니라 체크포인트에서의 승인과 방향
지시라는 점을 강조한다.
Review Loop 단계가 “주요 체크포인트에서 에이전트가 방향을 묻는다”고 한 것과 짝을
이룬다.

## 비평

### 수치와 후기는 회사가 직접 올린 것이다

사이트의 후기 세 건은 “brief에서 첫 편집본까지 6배 빠르다”, “산출물 효율 3배”,
“프로젝트당 40시간 절약”이라고 한다.
인물은 Studio Director, Brand Concept Lead, 독립 영화감독으로 적혀 있고 회사
이름이나 사례 링크가 없다.
기준선이 무엇인지, 어떤 작업을 어떤 도구와 비교했는지도 나오지 않는다.
이 숫자는 검증된 측정값이 아니라 회사가 고른 홍보 문구로 읽어야 한다.

### 비교표는 회사가 정한 기준으로 경쟁을 정의한다

비교표는 “표준 AI 도구”를 일회성 생성, 단편적 파이프라인, 단일 모달로, “기존
창작 소프트웨어”를 수작업 중심, 느리고 배우기 어려운 것으로 규정하고 MiniMax
Design을 모든 항목에서 앞에 둔다.
어떤 제품과 비교했는지 이름이 없다.
이미 여러 모델을 한 화면에서 쓰게 하는 경쟁 도구가 있으므로, “표준 AI 도구가
단편적”이라는 전제는 검증할 수 없다.

### 가격과 사용 조건은 본문에 없다

도구 목록은 무료 크레딧이나 무료로 시작할 수 있다고 하지만, 크레딧 양과 이후
가격은 이 사이트에서 확인되지 않는다.
메뉴에 `Pricing`과 `Tutorial`이 있으나, 요청했을 때 `/pricing`과 `/tutorial`
경로는 404를 돌려주었다.
회사가 GPT-6 Astra를 공식 API 가격의 10%부터라고 한 것도, 무엇의 10%인지와
조건은 적혀 있지 않다.
외부 모델 제공사의 이용 약관과 이 앱을 통한 재판매가 어떻게 맞물리는지도
사이트에서는 알 수 없다.

### 로컬 우선과 비공개의 범위가 모호하다

“로컬 파일을 비공개로 유지한다”는 문구는 파일이 디스크에 남는다는 뜻이지, 생성
요청에 쓰인 자료가 서버로 가지 않는다는 뜻이 아니다.
외부 모델이 이미지나 영상을 만들려면 참조 자료를 모델 쪽으로 보내야 한다.
이 경로에서 데이터가 어디에 얼마나 남는지는 개인정보 처리방침을 따로 읽어야 알
수 있다.

## 인사이트

### 생성 모델 시장에서 경쟁의 축이 모델에서 작업 환경으로 옮겨 간다

이 제품은 자사 모델 H3만이 아니라 Kling과 GPT Image 같은 타사 모델을 같은 화면에
올린다.
모델 성능이 빠르게 바뀌는 시장에서 한 모델에 묶이지 않는 쪽이 사용자에게
유리하다는 판단이다.
반대로 모델 제공사에게는 자사 모델이 다른 회사 앱의 선택지 중 하나로 내려앉는
부담이 생긴다.
MiniMax가 자사 모델 회사이면서 타사 모델을 넣은 앱을 만드는 것은 이 둘 사이에서
앱 쪽 가치를 잡으려는 선택으로 보인다.

### Skills가 쌓일수록 이식성이 이탈 장벽이 된다

사용자가 만든 Skills와 캔버스 이력은 이 앱의 형식으로 쌓인다.
다른 도구로 옮길 수 있는지는 사이트가 말하지 않는다.
쓸수록 도구가 쓸모 있어진다는 회사의 문구는 사용자 쪽에서 보면 전환 비용이
늘어난다는 말이기도 하다.
도입을 결정한다면 Skills의 내보내기 형식과 라이선스를 먼저 확인할 일이다.

### 이 도구를 판단하려면 한 작업을 끝까지 돌려 봐야 한다

사이트는 숏드라마나 광고 같은 큰 완성품을 보여 주지만, 중간 단계에서 사람이
얼마나 고쳐야 하는지는 보여 주지 않는다.
판단 기준으로는 같은 기획서를 이 앱과 현재 쓰는 도구 조합에 넣고 첫 편집본까지의
시간과 수정 횟수를 비교하는 것이 가장 직접적이다.
무료 크레딧이 그 한 번을 돌리기에 충분한지, 결과물의 사용 권한이 상업 용도에
열려 있는지가 이 시험의 통과 조건이다.
이 조건이 사이트에서 확인되지 않으면 도입 근거로 삼기 어렵다.
