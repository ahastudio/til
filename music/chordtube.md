# ChordTube

<https://chordtube.net/>

## 소개

ChordTube는 YouTube 영상에 맞춰 곡의 코드 진행, 키, BPM을 보여 주는 일본어
웹 서비스다.
사이트 설명은 애니메이션 주제가, 게임, 버추얼 유튜버(VTuber)의 곡을 곡명이나
코드 진행, 멜로디로 찾을 수 있다고 소개한다.
영상은 YouTube 임베드로 재생하고, 코드와 키와 박은 AI의 자동 추정과 이용자의
편집으로 만든 것이며 정확하다고 보장하지 않는다고 모든 화면 하단에 적는다.
이 문서는 2026년 11월 26일에 메인, 이용약관, 개인정보 처리방침, AI 분석 모델,
코드 진행 검색, 랭킹, 곡 페이지 하나를 읽고 정리했다.
사이트가 말하는 내용은 모두 운영자의 설명이다.
운영자가 누구인지, 곡이 몇 개 실려 있는지는 읽은 페이지에 나오지 않았다.

### 기능

| 기능           | 사이트의 설명                                                    |
| -------------- | ---------------------------------------------------------------- |
| 곡 페이지      | 키, 박자, 템포, 전조 횟수와 구간별 소절 단위 코드 차트를 보여 줌 |
| 코드 진행 검색 | 도수(degree)로 진행을 짜면 그 진행이 쓰인 곡과 위치를 찾아 줌    |
| 멜로디 검색    | 메뉴에 있으나 이 문서는 사용해 보지 않음                         |
| 랭킹           | 7일, 30일, 전체, 장르별. 한 사람이 같은 날 여러 번 재생해도 1회  |
| 탐색           | 애니메이션 곡, 작품과 그룹, 장르, 신곡                           |
| 라이브러리     | 즐겨찾기, 플레이리스트, 열람 기록                                |
| AI 분석        | 사이트에 없는 YouTube 곡을 URL로 요청                            |

메인 화면의 장르는 J-POP, 보컬로이드, 게임, 록, 아이돌, 애니메이션, 서양 음악,
재즈다.
메인에는 최근 7일 인기곡과 새로 추가된 곡이 곡명과 키, BPM과 함께 나열된다.

### 코드 진행 검색

도수를 하나씩 더해 진행을 만든다.
단조나 모드의 곡도 조표가 같은 장조의 도수로 검색하라고 안내한다.
일치 조건은 코드 종류까지, 3화음, 근음만 가운데서 고르고,
키를 따지지 않는 옵션이 있다.
7th나 텐션은 무시하므로 IVM7도 IV로 찾는다.
베이스를 적은 코드는 베이스까지 일치시키고 적지 않으면 따지지 않는다.
탐색 범위는 곡 전체, 후렴, A멜로, B멜로, D멜로, 인트로, 간주, 아웃트로다.
이름이 붙은 진행이 미리 등록되어 있다.

| 이름               | 도수                             |
| ------------------ | -------------------------------- |
| 왕도 진행          | IV V IIIm VIm                    |
| 코무로 진행        | VIm IV V I                       |
| 카논 진행          | I V/VII VIm IIIm/V IV I/III IV V |
| 마루사 진행        | IVM7 III7 VIm7 Vm7 I7            |
| 투파이브           | IIm7 V7 IM7                      |
| 베이스의 반음 하강 | I ?/VII ?/bVII ?/VI              |

### AI 분석과 모델 버전

로그인한 이용자는 사이트에 아직 없는 YouTube 영상을 AI 분석으로 추가할 수
있다.
하루에 분석할 수 있는 곡 수와 영상 길이에 상한이 있고,
공개되어 있고 임베드가 허용된 영상만 대상이다.
결과는 사이트에 공개된다.

곡 페이지 아래에 어느 버전의 모델로 만든 차트인지 표시된다.
버전 이력은 다음과 같다.

| 버전 | 시기        | 사이트가 적은 변경                                            |
| ---- | ----------- | ------------------------------------------------------------- |
| v1.0 | 2026년 10월 | 첫 모델. 코드, 키, 박, 박자, 구간을 소리에서 읽음             |
| v2.0 | 2026년 11월 | 코드 인식 전용의 새 모델 도입. 인식 정밀도가 크게 올랐다고 함 |
| v2.1 | 2026년 11월 | 박 위치 추정과 키 판정 방식을 고치고 코드 인식을 개선         |

옛 곡도 새 모델로 다시 분석할 수 있다.
이용자가 고치지 않은 곡은 새 결과로 바뀌고,
고친 곡은 새 결과가 편집 이력에 후보로 추가되며 편집한 내용은 사라지지 않는다.
별도로 곡의 장르를 소리로 추정하는 실험적 모델이 있다.
v0.1이 2026년 11월 19일에 135개 장르로 시작했고,
v0.2가 11월 22일에 137개 장르로 늘었다.
추정이 약한 장르에는 경고 표시를 붙인다.

### 약관과 개인정보

약관의 최종 갱신일은 2026년 11월 20일이다.
서비스는 영리 목적이 아니며 광고와 유료 기능이 없다고 적는다.
Google 계정으로 로그인하고 로그인 없이도 곡을 볼 수 있다.
이용자가 고친 코드 악보와 플레이리스트 이름은 공개되고,
다른 이용자가 다시 고치거나 되돌릴 수 있으며,
운영자가 무상으로 이용하도록 허락하고 저작인격권을 행사하지 않는다는 조항이
있다.
금지 사항에는 자동 대량 접근, 멜로디 검색 결과를 모아 곡의 멜로디를 다시
조립하려는 행위, 서비스 정보의 영리 목적 이용이 들어 있다.
권리자는 연락처로 알리면 표시 중지 같은 조치를 받을 수 있다.

개인정보 처리방침에 따르면 Google 로그인에서 계정 구분용 ID만 받고
이메일, 이름, 프로필 사진은 받지 않는다.
랭킹 집계에는 곡을 30초 재생한 시점에 계정 ID나 게스트 쿠키의 무작위 ID를
비밀 키로 해시해 날마다 기록하고 30일 뒤 지운다.
추천 개선용 기록은 90일 뒤 지운다.
광고용 쿠키와 외부 분석 서비스는 쓰지 않으며,
통신은 Cloudflare를 거친다고 밝힌다.

## 분석

### 도수로 묻는 입력 방식

코드 진행 검색은 곡의 키와 무관하게 진행의 모양만으로 찾는다.
같은 진행이 다른 키로 쓰인 곡을 한 번에 모을 수 있다는 뜻이다.
검색 조건을 코드 종류, 근음, 범위로 단계적으로 풀어 두어
“정확히 같은 코드”와 “같은 기능의 코드” 사이를 이용자가 고르게 했다.
이 문서는 이 방식의 검색 품질을 직접 시험하지 않았다.

### 한 곡에 겹치는 두 층

곡의 차트는 모델이 만든 초안과 이용자의 편집이라는 두 층으로 이루어진다.
모델을 바꿔 다시 분석할 때 편집이 없는 곡은 새 결과로 갈아 끼우고,
편집이 있는 곡은 후보로만 남긴다는 정책은 두 층의 충돌을 푸는 규칙이다.
이용자가 들인 노력을 모델 교체가 덮어쓰지 않게 하려는 설계로 읽힌다.

### 금지 조항이 보여 주는 우려

멜로디 검색 결과를 모아 곡의 멜로디를 다시 조립하는 행위를 금지하는
조항은, 운영자가 이 검색이 곡 내용을 복원하는 통로가 될 수 있다고 보고 있음을
드러낸다.
자동 대량 접근과 영리 목적 이용의 금지도 같은 맥락이다.
권리자에게 연락 창구를 열어 두는 조항과 함께 읽으면,
저작권 문제에 대한 운영자의 방어선이 약관의 문구에 걸쳐 있다.

### 최소 수집의 설계

개인정보 처리방침은 받지 않는 정보(이메일, 이름, 사진)와
해시 방식, 보관 기간(30일, 90일), 쓰지 않는 기술(광고 쿠키, 외부 분석)을
항목마다 적는다.
수집을 줄이는 쪽으로 설계되었다는 서술이다.
다만 이 문서는 이 서술이 실제 동작과 같은지 확인하지 못했다.

## 비평

### 정확도의 근거가 없다

사이트는 정확하다고 보장하지 않는다고 하면서도,
v2.0에서 인식 정밀도가 크게 올랐다고만 쓸 뿐 수치나 평가 방법을 싣지 않는다.
어떤 곡에서 어느 정도 맞는지는 이용자가 직접 들어 보고 판단해야 한다.
이 문서가 연 곡 페이지에는 한 곡에 9번의 전조와 N.C.(무반주) 표기를 포함한
긴 차트가 나와 있었으나, 음원과 대조해 맞는지는 확인하지 않았다.

### 저작권 쟁점이 열려 있다

사이트는 상용 곡의 코드 차트와 진행 검색을 제공한다.
약관은 권리자가 연락하면 조치하겠다고 하는데, 이는 문제가 제기된 뒤에
대응하는 방식이다.
이 문서는 코드 진행이나 차트의 저작권 해석을 판단하지 않는다.
서비스가 이 부분을 어떻게 다루는지는 앞으로 권리자의 반응에 달려 있고,
이용자에게는 서비스가 갑자기 달라질 수 있다는 위험이 된다.

### 지속성이 약속되어 있지 않다

약관은 서비스를 사전 통보 없이 변경, 중단, 종료할 수 있다고 하고
영리 목적이 아니라고 한다.
이용자가 공들여 고친 차트와 플레이리스트가 서비스와 함께 사라질 수 있다.
버전 이력은 2026년 10월부터 시작하므로 운영 기간이 짧은 서비스다.
내보내기 기능이 있는지는 읽은 페이지에서 확인하지 못했다.

### 이용자 범위가 좁다

화면과 약관은 일본어로만 되어 있고,
장르와 노래 목록도 J-POP, 보컬로이드, 애니메이션 곡에 치우쳐 있다.
서양 음악과 재즈 장르가 있으나 랭킹 상위는 일본 곡이다.
이 점은 한국어 이용자에게는 접근의 장벽이고,
도수 검색 같은 기능은 언어와 무관하게 쓸 수 있다는 점이 완화 요인이다.

### 편집 공개와 라이선스의 비대칭

이용자의 편집은 공개되고 운영자가 무상으로 이용하도록 허락하는 반면,
서비스의 정보를 영리 목적으로 쓰는 일은 이용자에게 금지된다.
비영리 서비스에서는 흔한 구조이나,
운영 주체나 앞으로의 사업 형태가 바뀌면 이 조항의 의미도 달라진다.

## 인사이트

### 연습 도구로서의 쓰임

도수 검색으로 같은 진행을 쓰는 곡을 모아 해당 구간부터 재생할 수 있다는 점은
작곡과 연주 연습에 쓸모가 있다.
한 진행이 여러 곡에서 어떻게 변주되는지를 귀로 비교하게 해 주기 때문이다.
이 저장소의 [프로그래머를 위한 음악 이론](music-theory-for-programmers.md)과
[기타 연습 습관](guitar-practice-habits.md)이 다루는 연습의 맥락과 이어서 쓸 수
있다.
다만 차트가 틀릴 수 있으므로 참고용으로 두고 귀로 확인해야 한다.

### 음악을 악보로 되돌리는 시도의 한 갈래

이 저장소의 [음악을 악보로 되돌리려 한 시도](audio-decomposition.md)와
[Spleeter](spleeter.md)는 소리에서 구조를 꺼내는 방법을 다룬다.
ChordTube는 같은 방향에서 코드, 키, 박을 AI로 읽어 사람이 고치게 하는
조합을 택한다.
기계의 초안에 사람의 교정을 얹는 구조가 모델 개선 뒤에도 유지되는
방식은 같은 문제에 접근하는 다른 서비스를 볼 때도 비교 기준이 된다.

### 작은 서비스가 정책을 적는 법

모델 버전을 곡마다 밝히고, 재분석이 편집을 건드리지 않는다는 규칙을 적고,
받지 않는 정보와 보관 기간을 항목마다 적는 방식은
운영 규모가 작은 서비스가 이용자의 신뢰를 얻는 방법의 예다.
이 투명성이 실제 동작과 일치하는지는 따로 검증해야 하는 부분이다.

### 확인할 것

차트의 정확도는 여러 곡을 음원과 대조해 확인해야 한다.
멜로디 검색의 방식과 정확도, 내보내기 기능의 유무,
운영자와 서비스 규모, 권리자 대응의 이력은 이 문서가 확인하지 못했다.
