# NES의 두 번째 부흥기

원문: [25 of my favourite modern NES games](https://jordi.inversethought.com/blog/25-of-my-favourite-modern-nes-games/)

HN 토론: <https://news.ycombinator.com/item?id=50503465> (100점, 10개 댓글)

Lobste.rs 토론: <https://lobste.rs/s/w9j7xs/25_my_favourite_modern_nes_games> (1점, 0개 댓글)

## 요약

멕시코의 자유 소프트웨어 애호가이자 수학자라고 자신을 소개한 Jordi가 2026년 11월 15일에 쓴 개인 블로그 글이다.
게임을 직접 해 보지는 않았고, 아래 설명은 모두 필자의 서술을 줄여 옮긴 것이다.

필자는 지금이 NES의 “두 번째 ReNESance”(첫 번째는 북미 비디오 게임 산업을 살린 시기)라고 한다.
NES의 작동 방식에 대한 수십 년의 연구와 지식이 신작의 풍요를 만들었다는 것이다.
25개를 순위 없이 가나다순으로 늘어놓았고, 거의 모두 개발자나 퍼블리셔에게서 디지털로 사며 값이 싸고 대부분 실제 NES용 카트리지도 있다고 한다.

게임마다 짧은 소개가 붙는다. 이 문서는 필자가 특별히 강조한 지점을 모았다.

| 게임                                                    | 필자가 강조한 점                                                                                                                      |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| All Hell Unleashed                                      | 80~90년대 공포 슬래셔 영화에 바치는 플랫포머, 영화별 스테이지와 악당 보스전                                                           |
| Alwa’s Awakening                                        | PC용을 NES로 이식, 메트로배니아, 음악은 FamiTracker로 작곡                                                                            |
| Anguna: Scourge of the Goblin King                      | 2008년 GBA 게임을 NDS, Atari 2600을 거쳐 NES로 옮긴 젤다류, 화면당 적 두 마리 제한이 Atari판에서 이어짐                               |
| Blazing Rangers                                         | 한 화면 협동 소방 액션, 호스 하나를 두 사람이 나눠 쓰는 협동이 핵심                                                                   |
| Changeable Guardian Estique                             | Compile 출신 개발자가 만든 가로 슈팅, 변신하는 로봇, 영문 설명서가 일부러 어색한 번역이고 영어판 컷신은 라이선스 시대처럼 가볍게 검열 |
| The Cowlitz Gamers’ 2nd Adventure                       | 자선 단체를 위해 시작된 한 화면 플랫포머, 스피드런에서 인기, 여러 칩튠 작곡가의 음악                                                  |
| Data Man                                                | 버그에게서 NES의 CPU를 지키는 아레나 슈팅, 플레이어가 죽지 않고 CPU가 망가지면 게임 오버가 글리치로 나타남                            |
| Dungeons and DoomKnights                                | AdventureQuest 세계관의 8비트 외전, 탑뷰와 횡스크롤 혼합, 물리판 구성이 충실                                                          |
| Garbage Pail Kids: Mad Mike and the Quest for Stale Gum | 네 캐릭터를 바꿔 쓰는 탐험 플랫포머, 실제 NES판은 구하기 어렵고 디지털 NES ROM 배포는 없음                                            |
| Gunhawk                                                 | Zapper(광선총)와 게임패드로 조작하는 슈팅, 게임패드만으로도 가능하지만 의도는 Zapper                                                  |
| GunTneR                                                 | 오른쪽에서 왼쪽으로 진행하는 가로 슈팅, 필자의 유머와 팝 앤 트윈비 벨식 파워업 저글링                                                 |
| Haunted: Halloween Trilogy                              | Retrotainment가 2015년부터 해마다 낸 핼러윈 플랫포머 세 편                                                                            |
| Jane Austen’s 8-bit Adventure                           | 제인 오스틴이 8비트 세계에 떨어져 펜으로 싸우는 플랫포머                                                                              |
| Lizard                                                  | 목표와 설명이 없는 개방형 탐험 플랫포머, 개발자 Brad Smith가 소스와 영상 등 보조 자료를 공개                                          |
| MicroMages                                              | 4인 동시 플레이, 죽은 마법사가 유령으로 돕는 협동                                                                                     |
| OverObj                                                 | NES 스프라이트 한계(64개, 가로 줄당 8개)를 화면 중간에 스프라이트 데이터를 바꾸는 방식으로 넘긴 탄막 슈팅                             |
| Project Blue                                            | 사이버펑크 플랫포머, 표지와 설명서와 그래픽 등 연출이 강점                                                                            |
| Sam’s Journey                                           | 원래 Commodore 64용, 의상마다 능력이 다른 다방향 플랫포머, 레벨마다 수집품이 정확히 정해져 있음                                       |
| Slow Mole                                               | 두더지는 느리고 세상은 빠른 정밀 플랫포머, 체크포인트를 시간 제한 안에 통과해야 얻음                                                  |
| The Storied Sword                                       | 벽 점프와 영화식 컷신의 플랫포머, 죽은 뒤 영웅을 바꿀 수 있음                                                                         |
| Super Bat Puncher Demo                                  | Morphcat의 짧은 플랫포머, 확장하겠다는 약속은 포기됨                                                                                  |
| Super Tilt Bro                                          | 카트리지에 와이파이 칩을 넣어 온라인 대전을 하는 NES용 스매시 형 게임, 웹판과 교차 플레이, 내려받기로 캐릭터 추가                     |
| The Trial of Kharzoid                                   | 벽돌 깨기와 능력을 얻는 탐험을 합친 “Arkanoidvania”                                                                                   |
| Twin Dragons                                            | 2017년 작품, 필자가 신작 NES 게임의 존재를 알게 된 계기이자 물리 제작 업체 Homebrew Factory를 있게 한 게임                            |
| Undercover Shot                                         | 두 사람이 하는 Zapper 게임, 한쪽은 NPC처럼 움직이는 잠입자, 한쪽은 총잡이                                                             |

필자는 이 중 어느 것을 권하느냐는 질문(글의 댓글)에 순위를 거부하고 취향에 따라 답했다. 메트로배니아를 좋아하면 Alwa’s Awakening, 빠른 아케이드는 Blazing Rangers, 협동은 Micro Mages이다.

## 분석

### 중심 주장은 제약이 창작을 낳는다는 것이다

필자는 Anguna를 두고 엄격한 하드웨어 제한 속에서 흥미로운 경험을 만드는 것이 신작 NES 게임을 만들고 하는 일의 전부라고 쓴다.
목록의 많은 항목이 이 주장을 뒷받침하는 기술적 비틀기를 담고 있다. 스프라이트 한계를 우회하는 OverObj, 카트리지에 통신 칩을 넣는 Super Tilt Bro, 주변기기를 다시 쓰는 Gunhawk와 Undercover Shot가 그렇다.
글은 이 기법들의 구현 세부를 설명하지 않고 한 줄로 소개한다.

### 부흥을 가능하게 한 것은 도구와 제작 생태계이다

글에서 나오는 기반은 개발 도구(NEXXT 같은 그래픽 도구, FamiTracker)와 소규모 물리 제작(Homebrew Factory 등)이다.
HN의 한 댓글은 도구가 흔히 저평가되지만 더 좋은 도구는 더 적은 노력으로 더 높은 품질을 낳으며, 오늘의 오래된 플랫폼 개발 도구는 과거 개발자가 부러워할 수준이라 NES 게임을 만들기에 지금보다 좋은 때가 없었다고 했다.[^kqr]
다른 댓글은 8·16비트 콘솔 거의 전부와 일부 이후 콘솔에 매우 활발한 홈브류 장면이 있고, 일부 플랫폼에는 코딩 없이 만드는 선택지도 있어 인기를 끌어 맥도날드 홍보 게임까지 GB Studio로 만들어졌다고 했다.[^spicyjpeg]

## 비평

### 목록은 추천이지 평가가 아니다

글은 필자 개인의 취향 목록이고 기준(왜 이 25개인가)은 밝히지 않으며 순위도 거부한다.
필자는 Lizard의 개발자이자 Alwa’s Awakening의 NES 이식을 맡은 Brad Smith와 친구라고 직접 쓴다.
따라서 “이 게임이 좋다”는 서술은 친분이 있는 항목과 없는 항목이 섞인 한 사람의 의견이다.

### 구하기 어려운 게임이 섞여 있다

글은 여러 게임이 실제 카트리지가 매진이거나 중고로만 구할 수 있다고 적는다. OverObj는 다른 구입 방법이 없고, Garbage Pail Kids는 디지털 NES ROM 배포가 없으며, Jane Austen은 카트리지 재제작을 막연히 약속했다.
한 퍼블리셔의 물리판 배송은 요청을 이행한 이력이 들쭉날쭉하다고도 적는다.
독자가 “거의 모두 디지털로 구할 수 있다”는 서두를 항목별로 확인해야 한다.

### 어떻게 즐기는지에 대한 질문은 글이 다루지 않는다

한 댓글은 Mac이나 Linux에서 어떻게 해 볼 수 있는지, 하드웨어가 필요한지 물었고 스레드에 답은 없었다.[^inatreecrown2]
글은 “원본 하드웨어에서의 하이파이 경험”을 말하지만 에뮬레이터 사용 여부나 합법성은 언급하지 않고, 개발자와 퍼블리셔에게서 사는 디지털판의 형식도 적지 않는다.

### 목록 밖의 추천

한 댓글은 Little Sisyphus와 Böbl을 목록에 없지만 추천한다고 했고,[^sandmandp]
답글은 80년대 문화와 코딩을 풍자하는 비디오 게임 에세이 RPG인 What Remains를 더했다.[^thenthenthen]
다른 댓글은 Estique의 영어 설명서가 일부러 어설프게 “번역”되었고 컷신이 1980년대 Nintendo처럼 약간 검열된다는 점이 재미있다고 했다.[^hackbraten]
글의 서술과 맞는다.

## 인사이트

### 신작 레트로 게임을 고르는 법

목록에서 끌어낼 수 있는 선택 기준은 이렇다.
협동이 중요하면 Blazing Rangers나 Micro Mages처럼 필자가 협동에서 빛난다고 한 항목을, 주변기기가 있으면 Zapper 게임(Gunhawk, Undercover Shot)을, 기술 호기심이 있으면 OverObj나 Super Tilt Bro를 고른다.
이는 필자의 서술을 용도별로 다시 묶은 것이다.

### 필자의 목록이 보여 주는 홈브류 생태계의 형태

Twin Dragons가 물리 제작 업체를 낳았고, 그 업체가 다른 게임의 카트리지를 찍어 낸다는 서술은 작은 유통 구조가 창작을 지탱한다는 것을 보여 준다.
반면 퍼블리셔의 이행 문제나 매진된 판의 중고 의존은 이 생태계의 취약한 부분이다.
HN의 한 댓글은 NES 미니에 홈브류를 넣어 즐긴 경험을 전했고,[^3rtb297]
다른 댓글은 이런 게임이 존재하는 것도 몰랐다고 하며 만드는 데 무엇이 드는지 보여 주는 영상을 링크했다.[^dylanz]
이는 목록의 가장 큰 효과가 존재를 알리는 것임을 보여 준다.

### 확인할 관찰

이 목록의 가치를 가를 관찰은 세 가지이다.
항목별 구입처와 형식(디지털, 물리)이 현재도 유효한지,
매진된 판이 재제작되는지,
필자가 예고한 아직 나오지 않은 게임(글에서 언급된 Cronela’s Mansion 등)이 출시되는지이다.
