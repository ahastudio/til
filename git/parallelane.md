# ParalleLane: 사이드바에 저장소와 워크트리를 펼쳐 보여 주는 워크트리 중심 Git GUI

<https://parallelane.com/>

Show GN: [ParalleLane - 워크트리 지원에 중점을 둔 Git 클라이언트](https://news.hada.io/topic?id=36849)

## 소개

ParalleLane은 Git 워크트리(worktree)를 중심에 놓은 데스크톱 Git GUI
클라이언트다.
GeekNews에 2026년 11월 9일 Show GN으로 소개되었고 만든 사람은 yeosu0107이다.
만든 이는 Conductor와 Orca의 UI에서 영감을 받아 좌측 사이드바에 저장소와
워크트리를 펼쳐 보여 주는 구조로 만들었다고 말한다.
이미 있는 Git 클라이언트들은 좋지만 워크트리를 지우면 탭이 사라지지 않고
오류 창이 뜨는 점이 불편했고, 커밋은 되는데 푸시할 때 계정을 바꾸기 번거로운
점이 있어서 직접 만들었다는 것이다.
약 5개월을 개발한 뒤 공개했다고 한다.
이 문서는 홈페이지와 소개 글, 다운로드 페이지, 개인정보 처리방침을 읽고
정리한 것이며 직접 설치하거나 써 보지 않았다.

홈페이지의 문구는 Git 작업을 워크트리로 나누고, 브랜치마다 작업 폴더를 따로
두며, 전환은 클릭 한 번이라는 것이다.
AI 에이전트가 한 워크트리에서 리팩터링하는 동안 옆 워크트리에서 버그를 고치는
식의 사용을 예로 든다.

## 구조와 기능

홈페이지가 설명하는 작업 흐름은 네 단계다.
로컬 저장소를 등록하거나 클론하면 프로젝트마다 워크트리가 트리로 정리된다.
브랜치를 고르고 워크트리를 만들면 새 작업 폴더가 생긴다.
워크트리마다 커밋 그래프와 변경 파일과 diff가 바로 열린다.
마지막으로 저장소에 고정된 계정으로 푸시한다.

제품이 내세우는 기능은 다음과 같다.
홈페이지에서 PRO 표시가 붙은 것은 두 가지뿐이다.

| 기능                 | 설명                                                                  | PRO 표시 |
| -------------------- | --------------------------------------------------------------------- | -------- |
| 스트리밍 커밋 그래프 | 창이 열리면 읽어 들인 커밋부터 그래프에 그린다                        | 없음     |
| 워크트리 대시보드    | 브랜치, 변경, 동기화 상태를 워크트리 단위로 본다                      | 없음     |
| 멀티 계정            | GitHub, GitLab, Bitbucket, self-hosted 서버, SSH 계정을 함께 등록한다 | 없음     |
| 저장소별 계정 고정   | 저장소마다 푸시에 쓸 계정을 정한다                                    | 없음     |
| Stash와 충돌 처리    | 충돌 파일과 스태시를 그래프 옆에서 다룬다                             | 없음     |
| Ref smart groups     | 규칙으로 브랜치와 태그를 자동 분류한다                                | 없음     |
| Self-hosted 연결     | GitHub Enterprise, GitLab Server 같은 사내 서버에 연결한다            | PRO      |
| Commit signing       | 커밋에 서명해 신원을 증명한다                                         | PRO      |

요금은 Basic이 무료이고 Pro는 49.79달러를 한 번 내는 구매라고 홈페이지가
적는다.
Pro는 제한을 해제하고 고급 Git 기능을 제공한다고 하지만, Basic이 어떤 제한을
가지는지는 이 문서가 읽은 페이지에 적혀 있지 않았다.

지원 환경은 macOS(Apple Silicon, 10.15 이상)와 Windows 10 이상(WebView2 필요)이고
Linux는 준비 중이라고 한다.[^download]
macOS에서는 Homebrew cask로도 설치할 수 있다고 안내한다.[^download]

## 개인정보와 데이터

개인정보 처리방침은 앱이 사용자 기기에서 동작하고 계정 없이 쓰이며
저장소의 코드, 변경 내역, 커밋 메시지, 브랜치명, 리모트 URL, 파일 경로를
전달받지 않는다고 밝힌다.[^privacy]
앱에는 사용 분석이나 오류 수집 기능이 없다고 한다.[^privacy]
액세스 토큰과 SSH 키와 라이선스 키는 운영체제의 자격 증명 저장소(macOS는
키체인, Windows는 자격 증명 관리자)에 보관한다고 한다.[^privacy]
macOS와 Linux 앱은 업데이트 확인을 위해 releases.parallelane.com에 주기적으로
묻고 설정에서 끌 수 있으며, Pro 라이선스를 활성화할 때는 키와 컴퓨터의
호스트 이름을 결제 업체 Dodo Payments로 보내고 이후 실행할 때마다 유효성을
확인한다고 한다.[^privacy]
웹사이트에는 Google Analytics와 Cloudflare Web Analytics를 쓰지만 데스크톱
앱에서는 동작하지 않는다고 적는다.[^privacy]
이 서술은 모두 개발자의 설명이며 이 문서는 네트워크 동작을 확인하지 못했다.

## 비평

### 워크트리 중심이라는 차별점이 구체적으로 어떻게 다른지 보이지 않는다

홈페이지의 기능 목록은 Git GUI에 흔한 항목들이고, 워크트리 중심이라는 설명은
워크트리 단위로 상태를 보여 준다는 것이다.
소개 글이 말한 불편, 곧 워크트리를 지울 때 탭이 정리되지 않는 문제를 이
제품이 어떻게 해결하는지는 설명되지 않는다.
워크트리를 만들고 지우는 수명 주기, 한 워크트리에서 브랜치를 바꾸는 경우,
같은 브랜치를 두 곳에서 체크아웃하려 할 때의 동작도 홈페이지에 없다.

### 영감을 준 도구와 비교가 없다

만든 이는 Conductor와 Orca의 UI에서 영감을 받았다고 하지만, 이 두 도구는
에이전트를 병렬로 돌리는 환경이고 ParalleLane은 에이전트 실행 기능이 없는
Git 클라이언트로 보인다.
그렇다면 AI 에이전트가 워크트리에서 일하는 예는 홈페이지의 사용 장면일 뿐
제품이 에이전트를 다루는 기능은 아니다.
이 구분은 글에 명시되어 있지 않고 이 문서가 읽은 페이지에서 에이전트 관련
기능이 나열되지 않았다는 데서 나온 추정이다.

### Pro의 가치를 판단할 정보가 부족하다

Pro의 1회 구매 가격은 밝혀져 있지만 포함된 기능 중 홈페이지에 적힌 것은
self-hosted 연결과 commit signing 둘뿐이다.
이 두 기능만으로는 Pro의 가치를 가늠하기 어렵고, Basic의 제한이 무엇인지가
구매 판단의 핵심이 된다.
한 번 내는 요금이 어느 범위의 업데이트를 포함하는지도 이 문서가 읽은 페이지에
없다.

## 도입 전에 따져볼 것

- 자기 작업이 워크트리를 자주 쓰는 방식인지 확인한다. 그렇지 않으면 일반 Git 클라이언트와 차이가 작다.
- 워크트리를 지울 때 탭과 상태가 정리되는지 직접 시험한다. 만든 이가 겪은 문제가 이것이다.
- 여러 계정을 쓴다면 저장소별 계정 고정이 푸시 때 의도한 계정을 쓰는지 시험한다.
- Basic의 제한을 앱에서 확인한 뒤 Pro가 필요한지 판단한다.
- 출시 직후의 1인 개발 제품이므로 업데이트 지속성과 문제 신고 경로를 확인한다.
