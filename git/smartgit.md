# SmartGit: 시각적 Git 클라이언트

<https://www.smartgit.dev/>

HN 토론: <https://news.ycombinator.com/item?id=999559> (56점, 37개 댓글)

## 소개

SmartGit은 독일 회사 syntevo GmbH가 만드는 Windows, macOS, Linux용 시각적 Git 클라이언트이다.
홈페이지는 Git 여정에서 혼자일 필요가 없다는 문구로 소개한다.
제품을 설치해 써 보지는 않았고 새 기능, 사용 사례 글, 매뉴얼은 열지 않았다.
설명은 모두 회사의 주장이다.

HN 스레드는 이 홈페이지가 아니라 2009년 12월에 옛 주소(`syntevo.com/smartgit`)로 올라온 것이다. 제품 첫 공개 시기의 반응이라서 지금의 평가가 아니다. 이 홈페이지 주소로 올라온 2026년 11월의 SmartGit 26.1 글이 하나 더 있으나 2점에 댓글이 없었다.

홈페이지가 소개하는 내용은 다음과 같다.

- 기능 목록: 세 창 구성 선택, 깔끔한 커밋 이력, 브랜치 관리, 충돌 해결, 사용자 지정 시각 이력, 끌어다 놓기, 실행 취소, 풀 리퀘스트, Git 노트, Feature Flow와 Git Flow, LFS, 체리픽, 상세한 문서, 그리고 유럽 Git 클라이언트라는 정체성이다.
- 대상: 개인, 팀과 워크플로, 조직과 기관의 세 갈래로 나누고 초보자, 개발 팀, 기업, 파워 유저, 무료 오픈소스, 교육 기관, 명령줄 애호가를 든다.
- 흐름: 저장소 연결(복제나 새로 만들기), 시각적 관리(커밋과 브랜치와 병합), 협업(변경 검토, 충돌 해결, 이력 정리), 푸시와 배포의 네 단계로 설명한다.
- 설치: Windows, macOS, Linux용을 내려받아 로컬 저장소를 열거나 GitHub, GitLab, Bitbucket, Azure DevOps에서 복제한다.
- 후기와 사례: 소프트웨어 컨설턴트, C++ 코드 검토, 게임 개발의 서브모듈 사용 사례 글이 소개되고, 사용자 인용 세 개(한 명은 Microsoft 소속으로 표시)가 있다.

요금제 구조는 다음과 같다.

- 개인 비상업 사용(Hobby): 무료 등록이 필요한 무료 라이선스이다.
- 학생과 교육: 공립 교육 기관의 학생과 직원이 교육용 이메일로 무료 라이선스를 받는다.
- 오픈소스와 자선: 자격이 되는 비영리 작업에 무료이고 용도별 확인이 필요하다.
- 상업용: 사용자당 월 5달러부터 또는 영구 라이선스이다. 선택 애드온이 있고, 중앙 라이선스 관리와 대량 가격이 필요하면 SmartGit License Server를 포함한 엔터프라이즈 라이선스를 견적으로 문의한다.
- 라이선스 조건(FAQ): 사용자(사람)당 라이선스이고 한 사용자가 최대 다섯 대의 기기에서 쓸 수 있다. 영구 라이선스는 구매 시점 기준 1년, 2년, 3년 안에 나오는 새 버전을 쓸 수 있고 그 뒤 새 버전은 할인된 갱신 라이선스가 필요하다. 회사 라이선스는 한 달에 한 번 직원과 계약자 사이에서 다시 배정할 수 있다. 구매 주문서는 50개 이상의 라이선스 주문에만 지원한다.

## 분석

### 중심 주장은 모든 Git 워크플로에 맞는 하나의 도구라는 것이다

홈페이지는 초보자부터 기업까지 대상을 넓게 잡고 같은 도구가 맞춰진다고 말한다.
기능 목록은 Git 클라이언트의 기본 기능(커밋 이력, 브랜치, 충돌 해결, 체리픽, LFS)과 Git Flow, Feature Flow, 노트 같은 워크플로 도구로 이루어진다.
이는 홈페이지의 서술을 이 문서가 정리한 것이다.

### 무료 범위가 넓고 상업용에서만 돈을 받는다

개인 비상업, 학생, 오픈소스와 자선 사용은 전체 기능을 무료로 쓰고, 상업 사용에서만 구독이나 영구 라이선스를 받는 구성이다.
이는 이 문서의 관찰이며 다른 제품을 같은 기준으로 비교하지 않았다.

### 오래된 제품의 성숙도가 회사 정체성에 드러난다

2009년에 처음 공개된 제품이고 홈페이지는 유럽 Git 클라이언트, 회사 소재지와 부가세 번호, 개인정보 처리방침과 라이선스 계약서를 전면에 둔다.
독일 회사가 만든다는 점을 강조하는 구성은 데이터 거버넌스에 민감한 사용자를 겨냥한 것으로 읽힌다. 이는 이 문서의 해석이다.

## 비평

### 후기와 수치가 홈페이지의 것이다

사용자 인용과 사례 글은 회사가 고른 것이다.
사용자 수나 점유율 같은 수치는 읽은 범위에 없다.

### 무료 자격 확인이 번거로울 수 있다

개인 비상업 사용도 무료 등록이 필요하고 교육은 교육 기관 이메일, 오픈소스와 자선은 용도별 확인이 필요하다.
상업 사용과 비상업 사용의 경계(예: 개인 프로젝트에서 수입이 생기는 경우)는 홈페이지에서 읽을 수 없고 라이선스 계약서에 있다.
2009년 HN 스레드에서도 같은 질문이 나왔다.
한 사용자는 비상업 사용이 돈을 받는 프로젝트에 쓸 수 없다는 뜻인지 물었다.[^din0bot]
이는 지금의 약관이 아니라 당시 질문이다.

### 구독과 영구 라이선스의 갱신 조건

영구 라이선스는 영구적으로 쓸 수 있지만 새 버전과 새 운영체제 지원은 구매 시점에 포함된 1년에서 3년 안으로 제한되고 그 뒤 갱신이 필요하다.
구매하기 전에 어느 구간을 사는지 확인해야 한다.

### 외부 반응

HN에는 2009년 스레드가 있고, 당시 댓글에는 오픈소스인 Git을 바탕으로 한 상용 제품을 마뜩잖아하는 반응과 광고 같다는 반응, GPL 제한과 자체 구현 여부를 묻는 질문이 있었다.[^dchest][^gstamp]
이들은 십수 년 전의 인상이다.
Lobste.rs에서는 `smartgit` 검색에 걸린 두 건이 Git UI 일반을 다룬 글이라 이 제품의 글이 없었다.
GeekNews에서는 `SmartGit`으로 검색한 결과가 Git 팁 글 하나뿐이어서 이 제품의 토픽이 없었다(대조 쿼리는 정상이었다).

## 인사이트

### 가져갈 것은 라이선스를 사용 목적으로 나누는 요금제 구성이다

개인 비상업, 교육, 오픈소스는 무료이고 상업 사용은 유료인 구분은 사용자에게 명확하고 오용이 적다.
자기 도구의 요금제를 설계할 때 기능으로 가르는 대신 목적으로 가르는 선택지로 참고할 수 있다. 이는 이 문서의 적용이다.

### 영구 라이선스는 갱신 조건까지 비용으로 계산한다

영구 라이선스는 한 번 사면 끝이라는 인상을 주지만, 이 제품처럼 새 버전 사용 기간이 정해져 있으면 장기 비용은 갱신을 포함해 계산해야 한다.
구독과 영구 중 어느 쪽이 맞는지는 팀이 새 버전을 얼마나 오래 쓰는지에 달려 있다.

### 확인할 관찰

이 제품의 주장을 가를 관찰은 세 가지이다.
상업과 비상업의 경계를 정한 라이선스 계약의 실제 조항,
큰 저장소와 복잡한 이력에서의 성능,
같은 영역의 다른 클라이언트와의 기능과 가격 비교이다.
