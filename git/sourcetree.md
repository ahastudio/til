# Sourcetree: Atlassian의 Git 클라이언트

<https://www.sourcetreeapp.com/>

HN 토론: <https://news.ycombinator.com/item?id=35151191> (12점, 5개 댓글)

## 소개

Sourcetree는 Atlassian이 만드는 Windows와 Mac용 무료 Git 클라이언트이다. 홈페이지는 Git과 Mercurial을 모두 다루는 아름다운 Git GUI라고 소개한다.
이 문서는 홈페이지 전문과 Mac과 Windows의 릴리스 노트 최신 항목, HN 글을 읽었다. 직접 설치해 써 보지 않았고 기능 문서와 튜토리얼은 열지 않았다.
설명은 모두 회사의 주장이다.

홈페이지가 소개하는 내용은 다음과 같다.

- 대상: 초보자는 명령줄 없이 분산 버전 관리를 쓰고, 숙련자는 변경 집합을 검토하고 스태시하고 브랜치 사이에서 체리픽한다고 한다.
- 커밋: 파일, 헝크, 줄 단위로 스테이징하고 버린다. 새 Git 상태 화면에서 상태를 한눈에 본다.
- 이력: 브랜치와 커밋 정보를 한 번 클릭으로 보고 브랜치 도식을 시각화한다. 로컬 커밋 검색이 있다.
- Git 도구: Git LFS, 기본 제공 Git-flow, 서브모듈, 대화형 리베이스, 원격 저장소 관리자(검색과 복제)이다.
- 버전 관리 시스템: Git과 Mercurial을 지원한다.
- 기업: Windows용 엔터프라이즈 배포를 대규모로 관리하는 항목이 있다. 베타 프로그램에 가입하는 구글 그룹 링크도 있다.
- 라이선스와 가격: 무료 Git 클라이언트라고만 적혀 있고 라이선스 조건과 유료 요금제는 홈페이지에 없다.
- 플랫폼: Windows와 Mac OS X이다. Mac 릴리스 노트는 macOS 10.15 이상이 필요하다고 적는다.

릴리스 노트의 최신 항목은 Mac 4.2.20(2026년 11월 1일)과 Windows 3.4.33(2026년 10월 31일)이다.
Mac 4.2.20에는 원격 코드 실행(RCE)과 신뢰 확인 창 우회 보안 수정, Bitbucket OAuth 플랫폼 이전이 들어 있다.
Windows 3.4.33에는 Mercurial 신뢰 우회, `.git/config` 신뢰, `sourcetree://` URI를 통한 NTLM, Git-flow 브랜치 이름의 명령 실행 등 취약점 수정이 있다.
홈페이지의 상단 내려받기 단추는 Mac 4.2.19를 가리키고 본문 링크는 4.2.20을 가리켜 일치하지 않는다.

## 분석

### 중심 주장은 초보자와 숙련자에게 모두 맞는 무료 GUI라는 것이다

홈페이지는 같은 도구가 초보자에게는 단순하고 숙련자에게는 강력하다고 말한다.
기능 목록은 Git 클라이언트의 기본 기능에 Git-flow, 서브모듈, LFS를 더한 것이다.
이는 홈페이지의 서술을 이 문서가 정리한 것이다.

### Atlassian 생태계의 입구이다

홈페이지는 Bitbucket으로 생산성을 높이라는 안내와 Bitbucket 튜토리얼, Atlassian 계정 중심의 푸터를 둔다.
무료 클라이언트가 같은 회사의 Git 호스팅과 이어지는 구성으로 읽힌다. 이는 이 문서의 해석이다.

### 최근 릴리스가 보안 수정에 몰려 있다

두 플랫폼의 최신 릴리스 노트는 공통으로 신뢰 확인 우회와 명령 실행 취약점 수정을 담는다.
저장소를 열거나 URI를 따라가는 동작이 위험 표면이라는 점을 보여 주는 항목들이다. 이는 이 문서의 관찰이다.

## 비평

### 홈페이지가 오래되었고 서로 어긋난다

내려받기 단추의 버전이 릴리스 노트와 다르고, 기능 소개는 Mercurial과 Git-flow 같은 오래된 구성을 앞세운다.
현재 개발 방향이나 로드맵은 홈페이지에서 읽을 수 없다. 이 문서는 릴리스 노트의 오래된 항목 전체를 읽지 못했다.

### 성능에 대한 사용자 평가가 부정적이다

HN 2023년 글에서 한 사용자는 직장에서 Bitbucket을 쓰는데도 VS Code의 내장 Git UI로 바꾸고 삶이 나아졌다고 했다. 그는 Sourcetree가 자기 저장소에서 매우 느리고 자주 멈추며 직관적이지 않다고 말했다.[^austizzle]
2022년 Fork 글에서도 여러 사용자가 Sourcetree가 Atlassian 이후 퇴보했고 느리다고 말하고 Fork로 옮겼다고 했다.[^a-chris]
반대로 어떤 사용자는 Fork가 주니어 개발자의 로컬 저장소를 망가뜨리는 일이 반복되어 Sourcetree를 권한다고 했다.[^vanit]
이들은 개인 경험이며 같은 조건의 측정이 아니다.

### 라이선스와 데이터 처리가 보이지 않는다

홈페이지는 무료라고만 말하고 이용 조건과 수집하는 데이터를 말하지 않는다. 약관은 Atlassian 클라우드 서비스 약관으로 연결되는 링크만 있어 이 문서는 읽지 못했다.

### 외부 반응

HN에는 이 홈페이지 주소로 올라온 글이 여럿이고 2012년부터 2017년까지의 글에는 수십에서 수백 댓글이 달렸다. 헤더에는 가장 최근인 2023년 글을 적었다.
Lobste.rs에는 `sourcetreeapp.com` 도메인의 글이 없었다.
GeekNews에서는 `Sourcetree`로 검색해 이 제품의 토픽이 없었다(대조 쿼리는 정상이었다).

## 인사이트

### 도입 전에 쓸 저장소 크기로 시험한다

HN의 평가는 자기 저장소에서의 속도가 갈렸다는 것이다.
대형 저장소에서 느리다는 후기가 반복되므로 도입하기 전에 가장 큰 저장소로 열기와 스테이징 속도를 시험한다. 이는 이 문서의 적용이다.

### 클라이언트의 취약점 이력을 확인한다

신뢰 확인 우회와 URI를 통한 명령 실행 수정은 신뢰할 수 없는 저장소를 여는 사용자에게 직접 영향을 준다.
어떤 Git GUI든 릴리스 노트의 보안 항목과 갱신 주기를 확인하는 습관이 필요하다.

### 확인할 관찰

이 제품의 주장을 가를 관찰은 세 가지이다.
대형 저장소에서의 같은 조건 속도 비교,
홈페이지와 릴리스의 버전 불일치 해소,
라이선스와 데이터 수집 조건이다.
셋 모두 이 문서가 확인하지 못했다.
