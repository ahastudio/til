# GitKraken: Git 클라이언트와 개발 플랫폼

<https://www.gitkraken.com/>

HN 토론: <https://news.ycombinator.com/item?id=11205594> (193점, 175개 댓글)

## 소개

GitKraken은 Axosoft, LLC가 만드는 Git 도구 모음이다.
홈페이지는 이를 코드가 계획에서 main까지 흐르게 하는 도구라고 소개한다.
제품을 설치해 써 보지는 않았고 개별 기능 페이지, 블로그, 릴리스 노트는 열지 않았다.
요금제 페이지의 가격 숫자는 읽은 텍스트에 나오지 않아(자바스크립트로 표시되는 것으로 보인다) 금액은 확인하지 못했다.
모든 서술과 수치는 회사의 주장이다.

홈페이지가 제시하는 구성은 다음과 같다.

- 개발자용: GitKraken Desktop(저장소 수준에서 브랜치, 커밋, 충돌을 한 화면에서 시각적으로 다룬다), GitLens(VS Code, Cursor, Windsurf, Trae, Kiro용 확장으로 코드 맥락과 이력, 작성자를 에디터 안에서 보여 준다), Kepler(AI 에이전트를 여럿 돌릴 때 조율하고 관찰하는 에이전트 개발 환경, ADE), GitKraken MCP(AI 어시스턴트에 Git 이력, 브랜치, 이슈, 풀 리퀘스트 맥락을 연결하는 MCP 서버), GitKraken CLI(`winget install gitkraken.cli`).
- 엔지니어링 리더용: GitKraken Insights(개발과 에이전트 사용량, 비용, 영향을 정량화), Jira용 Git 통합(커밋, 브랜치, 풀 리퀘스트를 Jira 이슈에 연결), 개발 팀 자동화, AI와 보안 통제.
- 팀 협업 서비스: Launchpad(모든 풀 리퀘스트, 이슈, 작업을 한곳에), Code Suggest, Cloud Patches(진행 중인 작업의 이른 검토), Workspaces(여러 저장소를 묶어 동기화), DORA Insights, SSO와 관리.
- 브라우저 확장(Chrome, Firefox, Edge)과 브라우저 안의 GitKraken.dev도 있다.
- 숫자: 개발자 5,000만 명 이상과 조직 10만 곳 이상이 신뢰한다고 하고, GitLens는 4,000만 이상 설치라고 한다.
- 메시지: 개발자가 코드를 전에 없이 빨리 만들 수 있지만 검토, 충돌, 조율이 병목이라서 코드 속도가 진척으로 이어지지 않는다는 문제를 코드 흐름(code flow) 문제라고 부른다.
- 교육: 무료 과정 Foundations of AI for Software Development(비디오 1.5시간, 수료증)를 내세운다. 199달러짜리 과정이 코드 `AIFOUNDATIONS`로 무료이고, 에이전트가 틀린 것을 읽어 내고 출시 전에 잡는 법을 가르친다고 한다. 홈페이지 상단에는 멕시코 지역의 70% 할인 문구도 있다.
- 후기: 에이전트 코딩을 한다면 GitKraken이 꼭 써야 할 도구라는 사용자, 일상 소스 관리 도구이고 AI가 들어간 흐름이 일을 덜어 준다는 소프트웨어 아키텍트, 시각화와 AI 보조와 사용자 경험을 겸비했다는 대표의 인용이 있다.

요금제 구조는 다음과 같다(금액은 읽지 못했다).

- 커뮤니티: 무료. 오픈소스 개발을 위한 기본 GitKraken Desktop, CLI, GitLens. 로컬 저장소와 공개 원격만 쓸 수 있고 클라우드 통합은 GitHub, GitLab, Bitbucket의 비엔터프라이즈를 무제한으로 연결한다. 14일 무료 체험을 고를 수 있다.
- Pro: 개인 개발자용. 비공개 저장소와 개인 호스팅 원격, Jira Cloud와 Trello 같은 이슈 트래커, 충돌 감지, Launchpad, 공유 클라우드 워크스페이스, 좌석 최대 2개이다. GitKraken AI는 사용자당 주 100만 크레딧까지이고 자기 API 키(BYOK)를 쓸 수 있으며, AI 코드 리뷰, AI 커밋 메시지와 충돌 해결, MCP, 에이전트 세션 보기(비공개 저장소)를 포함한다.
- Advanced: Pro에 더해 자체 호스팅 Git 통합과 엔터프라이즈 통합(GitHub Enterprise, Azure DevOps Server, Jira Data Center, Bitbucket Data Center), 단일 도메인 SSO(SAML 2.0), 팀 Launchpad, 자동화 미리 보기, 좌석 최대 10개이다.
- 모든 요금제가 GitKraken DevEx 플랫폼 전체를 포함한다고 한다.

## 분석

### 중심 주장은 Git 클라이언트에서 에이전트 시대의 코드 흐름 관리로 넓어졌다는 것이다

홈페이지의 서사는 AI가 코드 양과 속도를 높였지만 검토와 조율이 따라가지 못한다는 것이다.
이를 풀 제품으로 에이전트 세션을 한눈에 보는 Kepler와 에이전트 세션 보기, AI에 Git 맥락을 주는 MCP, 에이전트 사용 비용을 재는 Insights를 앞세운다.
전통적인 Git 클라이언트였던 제품이 에이전트의 작업을 감독하는 도구로 위치를 옮기는 구성이다. 이는 홈페이지의 서술을 이 문서가 정리한 것이다.

### 세 가지 사용 층을 겨냥한다

저장소 수준의 Desktop, 에디터 안의 GitLens, 에이전트 규모의 Kepler라는 세 층과 리더를 위한 Insights로 나눠 같은 계정과 요금제 안에 묶는다.
무료 층(커뮤니티)이 오픈소스 개발과 로컬 저장소에 한정되고 비공개 저장소부터 유료라는 구분이 수익 구조의 핵심으로 읽힌다. 이는 이 문서의 해석이다.

## 비평

### 수치와 후기가 모두 회사 홈페이지의 것이다

5,000만 명과 10만 조직, GitLens 4,000만 설치는 출처와 집계 방식이 없다.
후기는 짧은 인용이며 일부는 소셜 계정 이름만 있다.
나아가 에이전트 시대의 병목이 검토와 조율이라는 진단은 회사의 마케팅 메시지이며 근거 자료는 홈페이지에 없다.

### 가격과 한도가 첫 화면에서 보이지 않는다

요금제 페이지는 구조는 자세하지만 금액이 읽은 텍스트에 없었다. 좌석 한도(Pro 2개, Advanced 10개)와 AI 크레딧 한도(주 100만)가 도입 비용에 영향을 준다.

### 에이전트 관련 기능의 성숙도를 알 수 없다

Kepler는 별도 다운로드로 안내되고 자동화는 미리 보기라고 표시된다.
에이전트 세션 보기와 관리 기능이 실제 사용에서 얼마나 안정적인지는 홈페이지로 알 수 없다.
같은 영역에서 경쟁하는 다른 도구와의 비교도 홈페이지에 없다.

### 외부 반응

HN에는 이 홈페이지 주소로 올라온 스레드가 있으나 2016년 3월의 첫 공개 때 것(193점, 175개 댓글)이다. 당시 제품은 지금과 달랐으므로 아래 반응은 지금의 제품 평가가 아니라 초기 인상이다.
한 사용자는 오픈소스가 아니라는 점을 지적했고,[^0942v8653] 다른 사용자는 이메일 등록을 강제하는 것이 싫다고 했다.[^alpb]
Electron 앱이라 네이티브 앱처럼 보이거나 동작하지 않는다는 지적도 있었다.[^millstone]
GUI의 쓸모를 묻는 질문에는 저장소 위상(topology)을 보는 일처럼 GUI가 빠른 경우가 있다는 답이 달렸다.[^swisspol]
Lobste.rs에서는 `gitkraken.com` 도메인이 올라온 적이 없고, GeekNews에서는 `GitKraken`과 `깃크라켄`으로 검색한 결과 이 홈페이지의 토픽이 없었다(대조 쿼리는 정상이었다).

## 인사이트

### 가져갈 것은 에이전트가 만든 변경을 사람이 파악하는 도구의 필요이다

에이전트가 저장소를 바꿀 때 무엇이 바뀌는지 한눈에 보고 커밋 단위로 통제하는 일이 도구의 새 요구라는 서사는 GitKraken에 한정되지 않는다.
자기 워크플로에서 에이전트가 만든 브랜치와 변경을 어디서 어떻게 검토하는지 점검하는 질문으로 쓸 수 있다. 이는 이 문서의 적용이다.

### 도입은 무료 층과 체험으로 먼저 시험한다

커뮤니티 요금제와 14일 체험이 있어 오픈소스 저장소와 로컬 저장소로 먼저 써 볼 수 있다.
비공개 저장소와 AI 기능은 유료 구간이므로 필요한 기능이 어느 요금제에 있는지 확인한 뒤 결정한다.

### 확인할 관찰

이 제품의 주장을 가를 관찰은 세 가지이다.
에이전트 감독 기능(Kepler, 에이전트 세션 보기)의 실제 사용 후기,
AI 크레딧과 좌석 한도가 팀 규모에서 어떤 비용이 되는지,
무료 층의 제약이 오픈소스 개발에 충분한지이다.
