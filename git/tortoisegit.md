# TortoiseGit: Windows 탐색기용 Git 클라이언트

<https://tortoisegit.org/>

HN 토론: <https://news.ycombinator.com/item?id=15592097> (2점, 0개 댓글)

## 소개

TortoiseGit은 TortoiseSVN을 바탕으로 한 Windows 셸용 Git 인터페이스이다.
소개 페이지는 IDE 연동이 아니라 Windows 탐색기의 오른쪽 클릭 메뉴로 동작하고 어떤 파일 형식에서도 쓸 수 있다고 설명한다.
직접 설치해 써 보지 않았고 문서, 릴리스 노트, 기부, 기여, 법적 고지 페이지는 열지 못했다.
응용 프로그램의 소스 저장소는 읽은 페이지 어디에도 링크되어 있지 않았다.
설명은 모두 프로젝트의 주장이다.

페이지가 소개하는 내용은 다음과 같다.

- 탐색기 통합: 모든 명령이 탐색기 오른쪽 클릭 메뉴에 있고 선택한 파일이나 폴더에 맞는 명령만 보인다. 상태를 보여 주는 오버레이 아이콘이 있고 오른쪽 끌기로 파일을 옮긴다.
- 커밋 창: 맞춤법 검사, 수정한 파일의 경로와 키워드 자동 완성, 특수 문자 서식이 있다.
- 프로젝트별 설정: 최소 로그 메시지 길이와 맞춤법 언어를 정한다.
- 이슈 추적기 연동: 이슈 번호 입력 칸이나 번호 색 표시, 이슈로 가는 링크, 번호 없는 커밋에 대한 경고를 선택할 수 있다.
- 도구: TortoiseGitMerge(비교, 충돌 해결, 패치 적용), TortoiseGitBlame(줄별 blame과 로그), TortoiseGitIDiff(이미지 비교).
- 품질: 정식 릴리스 전에 미리 보기 릴리스를 내고 충돌 보고 도구를 포함한다.
- 라이선스: GPL로 개발되며 링크가 GPL 2를 가리킨다. 상업 용도를 포함해 무료로 쓸 수 있고 소스가 공개되어 있다고 한다.
- 환경: Windows 10 버전 1607 이상이 필요하고 설치에는 관리자 권한이 필요하다. Visual C++ 재배포 가능 패키지 2015에서 2022, 명령줄 `git.exe`로 Git for Windows 2.24 이상이 필요하다. 32비트, 64비트, ARM64 MSI가 있다. 이전 Windows의 마지막 호환 버전은 Windows 7 SP1이 2.17.0, Vista SP2가 2.4.0, XP가 1.8.16.0이다. Cygwin, MSYS2, WSL의 Git은 공식 지원하지 않는다.
- 언어 팩: 37개 언어의 별도 MSI이며 독일어 100%, 중국어 간체와 프랑스어와 일본어와 러시아어 99%, 한국어 83% 같은 완성도 표시가 있다.

최신 버전은 페이지 사이에서 엇갈린다. 홈페이지 릴리스 칸은 2.19.0(2026년 6월 20일, 여러 보안 수정)을 안정 버전으로 적고 소식 칸은 2.19.1(2026년 6월 27일)이 이슈 4272를 고쳤다고 적는다.
내려받기 페이지는 현재 안정 버전을 2.19.0이라고 하면서 설치 파일 이름은 2.19.1.0이고 경로는 2.19.0.0 폴더이다.

## 분석

### 중심 주장은 탐색기 안에서 Git을 쓰게 한다는 것이다

별도 앱이 아니라 파일 관리자의 확장이라는 위치가 이 도구의 특징이다.
SVN 사용자의 작업 방식을 Git에 옮긴 구성으로 읽힌다. 이는 이 문서의 해석이다.

### 오래 유지되는 프로젝트이다

저작권 표시가 2015년부터 2026년이고 2025년 10월과 12월, 2026년 6월에 릴리스가 있다. 이슈 번호가 4,000대에 이른다.
공동체와 보안 수정에 대한 서술이 소식 칸에 있다.

## 비평

### 버전 표기가 엇갈린다

위에서 본 2.19.0과 2.19.1의 불일치는 사이트의 갱신이 일관되지 않다는 뜻이다.

### 지원 범위가 좁다

Windows 전용이고 Git for Windows만 공식 지원한다.
FAQ는 Cygwin, MSYS2, WSL의 Git이 HOME 디렉터리와 줄 끝 처리, 워크트리와 서브모듈 경로 차이 때문에 지원되지 않는다고 설명한다.

### 근거가 프로젝트 사이트뿐이다

거버넌스나 유지 관리자 정보도 읽은 페이지에 없다.

### 외부 반응

Lobste.rs에는 `tortoisegit.org` 도메인의 글이 없었다.
GeekNews에서는 `TortoiseGit`으로 검색해 이 프로젝트의 토픽이 없었다(대조 쿼리는 정상이었다). 결과는 다른 글이었다.

## 인사이트

### 가져갈 것은 도구를 있는 자리에 두는 설계이다

별도 창으로 옮겨 가지 않고 파일 관리자에서 바로 쓰는 방식은 사용자의 작업 흐름을 덜 끊는다.
다른 개발 도구의 진입점을 정할 때 참고가 된다. 이는 이 문서의 적용이다.

### 환경 요구 조건을 먼저 맞춘다

Git for Windows와 Visual C++ 패키지를 먼저 설치하고, 다른 Git 빌드를 쓰는 팀은 지원 범위를 확인한다.

### 확인할 관찰

이 도구의 주장을 가를 관찰은 세 가지이다.
현재 안정 버전과 릴리스 노트,
큰 저장소에서의 탐색기 응답성,
유지 관리 인력과 거버넌스이다.
