# Git Tower: Mac과 Windows용 Git 클라이언트

<https://www.git-tower.com/>

HN 토론: <https://news.ycombinator.com/item?id=12883084> (10점, 17개 댓글)

## 소개

Tower는 Mac과 Windows에서 쓰는 상용 Git 그래픽 클라이언트이다.
홈페이지 제목은 가장 강력한 Git 클라이언트라고 말한다.
제품을 설치해 써 보지는 않았고 기능 페이지, 릴리스 노트, 블로그는 열지 않았다.
모든 서술과 수치는 회사의 주장이다.

홈페이지가 내세우는 내용은 다음과 같다.

- 버전: 2026년 10월 6일에 Mac용 Tower 18(더 나은 명령줄 경험을 내세운다)이, 2026년 11월 2일에 Windows용 Tower 15(구문 강조)가 나왔다고 안내한다.
- 규모와 후기: 10만 명 이상의 개발자와 디자이너가 쓴다고 한다. SoundCloud 엔지니어, GoDaddy 디자이너, Amnesty International 담당자, CodePen 공동 창업자, Framer 대표의 짧은 인용이 있다.
- 쉬운 Git: 끌어다 놓기, 무엇이든 되돌리기(Cmd+Z), 스택드 브랜치(Stacked Branches) 지원, AI 커밋, 자동 브랜치 관리.
- Git의 모든 기능: 풀 리퀘스트, 한 줄 스테이징, 대화형 리베이스, 충돌 마법사, 서브모듈, Git LFS, Git-Flow, 파일 이력, blame, 체리픽.
- 생산성: 빠른 작업, 한 번 클릭 복제, 빠른 열기, 워크트리, 워크플로, 자동 스태시와 가져오기.
- Pro 기능: 스택드 브랜치, 사용자 정의 워크플로, Graphite 지원, 브랜치 정리, 자체 호스팅 저장소 연결, PR 기반 병합 감지.
- 학습 자료와 무료 도구: 24편의 비디오 과정, 온라인 책, 치트 시트, 웨비나, 복구 키트(First Aid Kit)와 고급 Git 키트, 코드 diff 도구, `.gitignore` 생성기, Git 설정 생성기, 훅 라이브러리, 커밋 템플릿 라이브러리.
- 체험: 30일 동안 제한 없이 Pro를 써 볼 수 있고 카드는 필요 없다고 한다. 체험을 받으면 이메일로 이어지는 무료 과정 구독을 권한다.

요금제 페이지는 다음과 같이 안내한다(사용자당 연 결제, 달러).

- 무료 요금제는 없고 모든 요금제가 30일 체험으로 시작한다. 이유는 줄인 무료판 대신 전체 기능으로 평가하게 하려는 것이라고 설명한다.
- 구독이 끝나면 접근이 끝난다. 구매 뒤 30일 안 환불, 구버전(Mac v1과 v2, Windows v1) 영구 사용 가능, 구버전 라이선스 소유자의 첫 해 50% 할인, 라이선스는 macOS와 Windows 모두에서 작동한다고 한다.
- 교육: 재학생은 Pro를 6개월 무료로, 이후 70% 할인으로 쓰고, 인가된 대학은 다수 좌석 무료 라이선스를 요청할 수 있다.

## 분석

### 중심 주장은 CLI의 힘을 숨기지 않는 시각적 클라이언트라는 것이다

후기 인용 중 CodePen 공동 창업자의 문장은 명령줄 Git에서 적당히 떨어진 추상화 수준이라고 하고, 홈페이지 본문은 Git의 모든 힘과 고통 없음이라는 문구를 쓴다.
목록의 구성도 쉬운 조작(끌어다 놓기, 되돌리기)과 고급 Git 기능(리베이스, 서브모듈, 체리픽)을 한 제품에 모았다.
이는 홈페이지의 서술을 이 문서가 정리한 것이다.

### 상용 구독 모델이 분명하다

무료 요금제가 없고 체험 뒤 구독이다. 에이전트나 AI 보조는 AI 커밋 정도가 보이고, 홈페이지의 중심 서사는 기능의 폭과 워크플로(스택드 브랜치, 사용자 정의 워크플로)에 있다.
같은 영역의 다른 클라이언트인 GitKraken이 에이전트 감독을 전면에 내세우는 것과 대조된다는 것은 이 문서의 관찰이며, 두 제품을 같은 기준으로 비교하지는 않았다.

## 비평

### 수치와 후기가 모두 회사의 것이다

10만 명 이상이라는 사용자 수와 후기 인용은 출처가 없다.

### 요금과 구독 조건

요금제는 연 결제이고 구독이 끝나면 접근이 끝난다. 월 환산 금액이 표시되지만 실제 결제는 연 단위이다.
체험 때 이메일 과정 구독이 안내되는 점은 선택이지만 홈페이지 곳곳에 같은 권유가 반복된다.

### 오래된 HN 스레드의 반응은 현재와 다를 수 있다

이 주소로 올라온 HN 스레드는 2016년 11월의 것(10점, 17개 댓글)이고 당시 제품은 지금과 다르다.
한 사용자는 SourceTree보다 나은지 물었고,[^selestify] 한 사용자는 이 상용 제품이 HN 첫 화면에 광고되는 것이 두세 번째라고 했고,[^bitmapbrother] 다른 사용자는 뉴스를 보러 왔다며 광고성 글이라고 했다.[^whatev]
GUI가 필요하냐는 관점도 있었고 emacs의 magit을 대안으로 든 사용자도 있었다.[^gpderetta]
이는 개인의 인상이며 지금의 제품 평가가 아니다.

### 외부 반응

Lobste.rs에서는 `git-tower.com` 도메인에 이 주소의 글이 없다(Jujutsu 글 하나와 12년 전 Tower 2 글이 있다).
GeekNews에서는 `Git Tower`로 검색한 결과 이 홈페이지의 토픽이 없었다(대조 쿼리는 정상이었다).

## 인사이트

### 가져갈 것은 Git 클라이언트를 고를 때 기능 목록이 아니라 되돌리기와 충돌 처리를 시험하는 일이다

홈페이지가 가장 앞세우는 되돌리기와 충돌 마법사, 대화형 리베이스는 클라이언트를 비교할 때 직접 시험하기 좋은 항목이다.
무료 체험(30일, 카드 없음)이 있으므로 자기 저장소의 어려운 상황(충돌, 이력 정리)을 시험해 보는 방식이 광고 문구를 읽는 것보다 믿을 만하다. 이는 이 문서의 적용이다.

### 구독형 도구는 구독이 끝났을 때의 접근을 확인한다

구독이 끝나면 접근이 끝난다는 조건은 작업 방식이 도구에 묶일 때 부담이 된다.
Git 자체의 데이터는 클라이언트와 무관하게 남지만, 워크플로 설정과 단축은 도구 안에 있다는 점을 도입 전에 생각한다.

### 확인할 관찰

이 제품의 주장을 가를 관찰은 세 가지이다.
Pro 전용 기능(스택드 브랜치, Graphite 지원)의 실제 사용 후기,
Mac 18과 Windows 15의 기능 차이와 업데이트 속도,
같은 영역의 다른 클라이언트와의 직접 비교이다.
