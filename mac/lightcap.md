# Lightcap: 맥용 화면 녹화 앱

<https://getlightcap.com/>

Show GN: [Show GN: Lightcap - 가볍고 빠른 맥용 화면 녹화/스크린샷 앱](https://news.hada.io/topic?id=37384)

## 소개

메뉴 막대에 사는 macOS용 스크린샷과 화면 녹화 앱이다.
이 문서는 제품 홈페이지(`getlightcap.com`) 전문과 자주 묻는 질문, GeekNews의 Show GN 토픽과 댓글을 읽었다.
앱을 설치해 써 보지는 않았다. 속도와 용량 수치, 기능 설명은 모두 제작자의 주장이다.
홈페이지 하단에는 판매자의 사업자 정보가 있으나 이 문서는 개인 연락처와 주소를 옮기지 않았다.

제작자는 한국 사업자 tigrim이고, 홈페이지는 영어, 일본어, 중국어(간체와 번체), 스페인어, 프랑스어, 독일어, 포르투갈어를 지원한다. 앱은 영어, 한국어 등 아홉 개 언어라고 한다.
macOS 15 이상이 필요하다.

기능은 홈페이지의 설명을 정리하면 다음과 같다.

- 스크린샷: 영역, 창, 전체 화면을 찍고 클립보드에 바로 복사한다. 스크롤 캡처, 찍은 뒤 기다리는 카드(다른 앱으로 끌어 놓기), 화살표와 상자, 텍스트, 번호, 모자이크 주석, 화면 위에 고정(Pin)하기가 있다. 단축키 하나로 막대를 열고 숫자 키로 고른다.
- 녹화: 영역, 창, 전체 화면을 60fps로 마이크 오디오와 함께 녹화해 녹화 중에 바로 MP4로 쓴다. 중지하면 파일이 끝나 있다고 한다. 스튜디오 모드는 커서와 모든 클릭을 데이터로 저장해 나중에 스타일을 바꿀 수 있다. MP4 또는 GIF(폭 640, 960, 1280)로 내보낸다. 자르기와 확대를 앱 안에서 하고 원본은 그대로 두며, 자르기만 했다면 다시 렌더링하지 않고 이어 붙인다.
- 화면의 글자: 이미지 속 글자, 영상 자막, 선택할 수 없는 페이지의 글자를 드래그해 복사한다. 인식은 맥에서 수행하고 한국어, 영어, 일본어, 중국어 등을 지원한다. 새 기능으로 드래그한 외국어 텍스트의 번역(문단 구조 유지, 번역 결과 복사)이 있다.
- 개인정보 가리기(새 기능): 한 번 눌러 스크린샷에서 이메일, 전화번호, 카드 번호, IP 주소, API 키와 비밀번호를 찾아 옮기거나 지울 수 있는 모자이크로 덮는다. 인식 가능한 모양이 있는 것만 찾고 이름과 주소는 사용자가 직접 가려야 하며 그때마다 그렇게 알린다고 한다.
- 개인정보와 네트워크: 계정과 분석이 없고, 캡처는 업로드하지 않으며, 글자 인식과 번역도 맥에서 한다고 한다. 네트워크는 라이선스 확인과 업데이트 확인에만 쓰고 연결되지 않아도 최대 30일 동작한다. 스튜디오 녹화에서 클릭과 단축키를 기록하려면 선택 권한인 입력 모니터링이 필요하다.
- 가격: 7일 체험(계정과 카드 불필요) 뒤 라이선스가 필요하다. 1대 15달러와 3대 35달러이고 출시 가격은 2026년 12월 31일까지 10달러와 25달러이다. 구독 없이 이후 업데이트가 모두 포함된다고 한다. 결제는 Polar가 처리하고 7일 안에 전액 환불할 수 있다. 체험 종료 뒤에는 새 스크린샷과 녹화를 할 수 없지만 이미 찍은 것은 열고 편집하고 내보낼 수 있다.
- 홈페이지가 내세운 수치: 다운로드 3.8MB, 유휴 메모리 22MB, 유휴 CPU 0%, 영역 캡처 0.03초이다. 각주는 이 수치를 2026년 11월 Lightcap 0.1 빌드로 MacBook Pro(M3 Max)의 macOS 27.2에서 직접 측정한 것이라고 밝힌다. 0.03초는 800×500 영역을 선택한 뒤 잡는 시간이며 파일 저장과 실행 뒤 첫 캡처는 뺐다고 한다.
- 비교 문구: 홈페이지 하단에 Screen Studio 대안, CleanShot X 대안이라는 문구가 있다.

## 분석

### 중심 주장은 느리지 않은 캡처 앱이라는 것이다

첫 문구는 느린 캡처 앱이 있고 Lightcap이 있다는 것이다.
수치(작은 설치 용량, 낮은 유휴 자원, 짧은 캡처 시간)와 녹화 시 바로 MP4를 쓰는 방식이 이 주장을 받친다.
이는 홈페이지의 서술을 이 문서가 정리한 것이다.

### 한 앱에 스크린샷, 녹화, 글자 복사, 번역, 가리기를 모았다

기능 목록이 스크린샷 도구와 화면 녹화 도구를 하나의 메뉴 막대 앱에 합치는 구성이다.
홈페이지는 경쟁 제품 이름을 대안 페이지 문구로 직접 쓰므로, Screen Studio(녹화 후 연출)와 CleanShot X(스크린샷 도구)의 사용자를 모두 겨냥한다는 것이 읽힌다.
GeekNews의 한 사용자는 이전에 Screen Studio를 썼고 이 앱이 좋다고 했고,[^hmmhmmhm] 제작자는 Screen Studio의 대체재도 목표라서 아쉬웠던 점을 알려 주면 빠르게 반영하겠다고 답했다.[^devdha]
다른 사용자는 AI 느낌이 나지 않는 랜딩 페이지가 좋다고 했다.[^roxie]
이는 개인의 인상이다.

## 비평

### 성능 수치는 제작자가 한 환경에서 잰 값이다

3.8MB, 22MB, 0%, 0.03초는 제작자가 M3 Max 한 대에서 0.1 빌드로 잰 값이고 각주도 사용자 환경에서는 다를 것이라고 적는다.
0.03초는 영역을 선택한 뒤의 시간이며 저장과 실행 뒤 첫 캡처를 뺐다. 이 조건에서 느리지 않다는 주장이 어디까지 일반화되는지는 이 문서가 확인하지 못했다.
또 이 문서는 앱을 실행해 보지 않았다.

### 출시 초기의 앱이다

측정에 쓴 빌드가 0.1이고 번역과 개인정보 가리기는 새 기능으로 표시되어 있다.
개인정보 가리기는 모양이 있는 것만 찾는다고 스스로 한계를 밝히지만, 실제 검출률과 오검출은 홈페이지에 없다.
GeekNews 토픽에는 사용 후기 댓글이 네 개뿐이고 모두 인사와 제작자의 답변이다. 독립된 사용 후기는 읽지 못했다.

### 구매와 라이선스 조건

체험은 7일이고 끝나면 새 캡처를 못 한다. 라이선스 확인이 주기적으로 필요하고 연결이 끊기면 최대 30일 동작한다고 한다.
영구 라이선스지만 앱의 장기 유지가 제작자 한 사업자에 달려 있다는 점은 홈페이지가 다루지 않는다.
출시 가격 할인 기한(2026년 12월 31일)이 정해져 있다.

### 외부 반응

HN에서는 이 제품의 글이 검색되지 않았다(도메인 URL 검색 0건).
Lobste.rs에서는 `getlightcap.com` 도메인이 올라온 적이 없다.
GeekNews의 Show GN 토픽에는 댓글 네 개가 있고 위에서 반영했다.

## 인사이트

### 가져갈 것은 캡처 앱을 고를 때 지연과 상주 자원, 데이터 처리 위치를 보는 기준이다

홈페이지가 내세우는 기준(캡처 시간, 유휴 메모리와 CPU, 업로드 여부, 오프라인 동작, 계정 유무)은 화면 캡처 도구를 비교할 때 그대로 쓸 수 있는 항목이다.
특히 인식과 번역을 기기 안에서 하는지, 네트워크로 무엇을 보내는지는 화면에 비밀 정보가 비치는 도구에서 먼저 확인할 일이다. 이는 이 문서의 적용이다.

### 자동 가리기는 보조 수단으로만 쓴다

이메일, 전화번호, 카드 번호, API 키처럼 모양이 있는 것을 자동으로 덮는 기능은 공유 전 점검에 도움이 되지만, 앱 스스로 이름과 주소는 사용자가 가려야 한다고 밝힌다.
공유 전에 결과를 눈으로 확인하는 절차는 그대로 필요하다.

### 확인할 관찰

이 제품의 주장을 가를 관찰은 세 가지이다.
다른 기기와 macOS 버전, 긴 녹화에서의 속도와 자원 사용,
개인정보 가리기의 검출률과 오검출,
출시 가격이 끝난 뒤의 판매와 업데이트가 이어지는지이다.
셋 모두 이 문서가 확인하지 못했다.
