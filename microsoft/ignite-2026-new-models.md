# Microsoft AI 모델 7종 발표

원문: [Seven new world-class models at scalable price-performance](https://microsoft.ai/news/microsoft-ignite-2026/)

HN 토론: <https://news.ycombinator.com/item?id=50548021> (532점, 345개 댓글)

GN 토론: <https://news.hada.io/topic?id=37419>

## 요약

2026년 11월 17일 Microsoft Ignite 2026에 맞춰 Microsoft AI가 낸 발표
글이다.
글쓴이는 명시되어 있지 않고 Microsoft AI 조직의 공식 발표문 형식을
취한다.
글은 토큰 소비가 급증하는 상황에서 에이전트를 하루 종일 돌릴 수
있는 가격대의 모델이 필요하다는 전제를 내세우며 가격 대비 성능이
뛰어난 모델 7종을 함께 공개한다고 밝힌다.

발표된 모델과 그 수치는 다음과 같다.

- MAI Cyber 2 Flash: CyberGym-E2E 벤치마크에서 GPT-6 Astra의 품질을
  넘어서면서 작업당 비용은 2% 미만이라고 한다.
  MAI Cyber 계열은 이미 MDASH 스캔의 약 40%를 차지하고, MAI로 시작한
  스캔의 90%가 계속 MAI를 쓴다고 한다.
  새 모델은 출력 토큰 가격이 이전 MAI Cyber 1.1 Flash보다 86% 낮다고
  적는다.
- MAI Code 2: DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas, FrontierCode
  v1.1 네 가지 벤치마크 평균에서 GPT-6.1 Sol 성능의 98%를 그
  가격의 40%로, Opus 5.5 성능의 96%를 그 가격의 5%로 낸다고 한다.
  프런트엔드 작업의 블라인드 비교 평가에서 개발자들이 GPT-6 Sol보다
  MAI Code 2를 64% 더 선호했다고 적는다.
  글은 이 모델이 일상적인 기업 코딩 작업에 맞춰졌고 기초 과학
  연구나 매우 긴 호흡의 에이전트 작업에는 아직 맞춰져 있지 않다고
  밝힌다.
- MAI Code 2 Flash: GPT-6 Luna와 비슷한 성능을 그 가격의 65%로,
  Haiku 5.5와 비슷한 성능을 그 가격의 20%로 낸다고 한다.
- MAI Image 2.7: Artificial Analysis의 이미지 편집 부문 1위이며
  GPT Image 2.6 Sunburst(max)를 가격의 5분의 1로 능가한다고 한다.
  텍스트-이미지 생성 부문에서는 4위라고 적는다.
  경량판인 MAI Image 2.7 Flash는 이미지 1,000장당 약 10달러로
  대량 작업에 적합하다고 한다.
- MAI Realtime 1: Microsoft의 첫 실시간 음성 대 음성 모델로, 외부
  평가와 Dynamics 365 평가 모두에서 GPT-Realtime 2.1을 능가했다고
  하며 오디오 1분당 0.01달러부터 시작한다고 한다.
- Dragon Copilot Transcribe: MAI Transcribe 2를 기반으로 하며 현재
  Dragon Copilot에서 의사-환자 대화 전사의 100%를 처리하고, 월
  1,000만 건의 진료를 처리하며, 다국어 작업의 오류율을 절반으로
  줄였고, 미국 의사의 3분의 1이 쓰고 있다고 한다.
- Decision 1.1: Artificial Analysis의 Decision Index에서 Jev,
  Google, OpenAI를 앞서면서 더 빠르고 저렴하다고 하며, 4,000개
  고객사가 쓰고 있고 GPT-6.1 Sol보다 50배 빠르고 79배 저렴하다고
  한다.
- Maia 200: Microsoft의 2세대 AI 가속기로 이미 가장 큰 모델들을
  운영하는 데 실제 투입되었으며 와트당 토큰 처리량이 1.7배
  늘었다고 한다.

글은 또한 MAI Licensed Weights라는 새 제품을 소개하는데, 기업이
자체 데이터로 MAI 모델을 맞춤화한 뒤 자신의 Azure 환경에서 직접
운영하고 접근 권한도 스스로 통제할 수 있게 하는 방식이라고 한다.
사례로 AT&T가 5G 네트워크 운영 분석용 맞춤 모델을 만들어
GPT-6.1 Sol보다 50분의 1의 비용으로 더 나은 성능을 냈다고 적는다.

## 분석

### 모든 비교가 상대 모델의 이름을 특정해 수치로 제시된다

이 글의 가장 눈에 띄는 특징은 추상적인 「뛰어난 성능」 대신 GPT-6
Astra, GPT-6.1 Sol, Opus 5.5, GPT-6 Luna, Haiku 5.5, GPT Image 2.6
Sunburst, GPT-Realtime 2.1처럼 경쟁사의 구체적인 모델명을 지목하고
그 대비 가격과 성능 비율을 수치로 제시하는 방식이다.
이런 서술은 추상적인 벤치마크 순위표보다 구매 결정권자가 바로
쓸 수 있는 형태의 근거를 제공하지만, 동시에 그 비교가 어떤
조건에서 측정되었는지는 벤치마크 이름(DeepSWE 1.1, Terminal
Bench 2.1 등) 외에는 거의 설명하지 않는다.

### 가격이 아니라 가격 대 성능 비율을 전면에 내세운다

글 전체에서 반복되는 패턴은 절대 가격보다 「몇 %의 가격으로 몇
%의 성능」이라는 비율 서술이다.
MAI Code 2는 40%의 가격에 98%의 성능, MAI Cyber 2 Flash는 2%
미만의 비용에 더 높은 품질이라는 식이다.
이 방식은 토큰 소비가 급증한다는 글의 도입부 문제의식과 맞물려,
절대적인 최고 성능 경쟁에서 가격 대비 효율 경쟁으로 AI 모델
시장의 축이 옮겨가고 있다는 틀을 세운다.

### 보안과 의료 영역에서 이미 쓰이고 있다는 실사용 수치를 제시한다

다른 모델 소개가 벤치마크 중심인 것과 달리 MAI Cyber와 Dragon
Copilot Transcribe 항목에는 실제 사용 비중(MDASH 스캔의 40%, 진료
전사 100%, 월 1,000만 건, 미국 의사 3분의 1)이 함께 제시된다.
이는 이 두 제품이 이미 상용 서비스에 배포되어 있다는 근거이기도
하지만, 같은 수준의 실사용 수치가 MAI Code나 MAI Image에는
없다는 차이도 동시에 드러낸다.

## 비평

### 벤치마크 선택의 기준이 설명되지 않는다

MAI Code 2의 성능 수치는 「널리 쓰이는 네 가지 벤치마크의 평균」이라고
적혀 있지만, 그 네 가지가 왜 선택되었는지, 다른 벤치마크에서는
어떤 결과가 나오는지는 글에 없다.
Artificial Analysis 같은 제3자 지수를 인용하는 항목(MAI Image,
Decision 1.1)과 자체 평가로 보이는 항목(MAI Code, MAI Cyber, MAI
Realtime)이 섞여 있는데, 글은 이 구분을 분명히 하지 않은 채 모든
수치를 같은 신뢰도로 나열한다.
독자가 어떤 수치가 독립 검증을 거쳤고 어떤 수치가 자체 측정인지
구분하려면 각 벤치마크를 따로 찾아봐야 한다.

### 경쟁사 모델명을 지목하는 비교가 그 모델들의 최신성을 전제한다

글은 GPT-6, GPT-6.1, Opus 5.5 같은 구체적인 버전을 비교 대상으로
삼는데, 이런 비교는 발표 시점의 경쟁 모델 스냅숏에 의존한다.
경쟁사가 다음 버전을 내놓는 순간 이 비교의 유효 기간은 끝나며,
글 자체도 가격 대 성능 비율이 영구적인 우위가 아니라 특정 시점의
우위라는 점을 명시하지 않는다.
이는 AI 모델 발표 글 전반에 공통된 한계이지만, 이 글처럼 비교
대상을 다섯 개 넘게 구체적으로 지목할수록 그 스냅숏의 유효 기간
문제가 더 크게 걸린다.

### 자사 하네스에서 측정된 성능과 실제 작업 환경의 성능 사이에 거리가 있다

MAI Code 2가 「일상적인 기업 코딩 작업」에 맞춰졌고 장기 호흡의
에이전트 작업에는 아직 맞춰지지 않았다는 문장은 이 모델의 적용
범위를 스스로 제한하는 드문 솔직함이지만, 정확히 어떤 작업이
「일상적」이고 어떤 작업이 「장기 호흡」에 해당하는지는 설명하지
않는다.
결국 독자는 자신의 실제 작업이 어느 쪽에 속하는지 직접 시험해
봐야 하는데, 글이 제시하는 벤치마크 수치만으로는 그 경계를 가늠할
수 없다.

## 인사이트

### 가격 대 성능 경쟁은 모델 공급자의 수익 구조 자체를 바꾼다

경쟁자 대비 5%, 20%, 40%의 가격이라는 숫자가 반복되는 것은 단순한
마케팅 문구가 아니라, 토큰당 마진이 얇아지는 시장에서 Microsoft가
택한 전략적 베팅으로 읽을 수 있다.
HN 댓글에서도 MAI Code 2 Flash가 코딩 외 다른 용도로도 쓸 수
있다고 알려졌다면 GPT-6 Luna의 65% 가격이라는 점 때문에 더 좋은
반응을 얻었을 것이라는 지적이 있었는데,[^nickandbro] 이는 가격
경쟁이 치열해질수록 모델의 쓰임새를 좁게 포지셔닝하는 것 자체가
기회비용이 된다는 뜻이다.
결국 저가 모델 경쟁은 공급자가 쓰임새를 최대한 넓게 열어 둬야
수익을 극대화할 수 있는 구조로 이어지며, 이는 기존의 고가-소수
독점 모델 전략과는 다른 영업 논리를 요구한다.

### 엔터프라이즈 판매 구조가 모델 채택의 실제 병목이 될 수 있다

HN 댓글에서는 Microsoft의 강점이 현장 실무자가 아니라 경영진을
대상으로 한 판매에 있으며, 이는 「IBM을 사서 해고된 사람은 없다」는
격언의 현대판이라는 지적이 나왔다.[^walrus01]
이 관찰은 글이 제시하는 가격 대 성능 수치가 아무리 뛰어나도, 실제
채택 여부는 기술적 우위가 아니라 각 조직의 구매 의사결정 구조에
달려 있다는 점을 보여준다.
벤치마크에서 이기는 것과 엔터프라이즈 계약을 따내는 것이 별개의
경쟁이라는 사실은, 이 글이 담은 수치만으로는 Microsoft의 시장
점유율 변화를 예측할 수 없다는 뜻이기도 하다.

### 오픈소스 대안의 부재가 소수 공급자 종속을 고착시킨다

MAI Licensed Weights는 기업이 자체 환경에서 모델을 통제할 수
있게 한다고 홍보하지만, 모델 자체의 가중치나 학습 데이터는 여전히
Microsoft의 것이다.
HN 댓글에서는 세계 수준의 오픈 가중치 모델을 만들기 위한 자금을
모으는 비영리 단체가 실질적으로 존재하지 않는다는 점, 그리고
소규모 오픈소스 프로젝트들조차 기존 모델을 재학습할 자금조차
충분히 모으지 못하고 있다는 점이 지적되었다.[^dofm]
다른 사용자는 지금이 운영체제 역사의 1980년대와 비슷한 단계이며,
가격 경쟁이 바닥을 치고 손해를 보는 프로젝트가 늘어나야 기업들이
각자 모델을 만드는 대신 협력하는 쪽으로 돌아설 것이라고
전망했다.[^pianopatrick]
이 두 관찰을 겹쳐 보면, Microsoft를 포함한 소수 공급자들이 가격을
공격적으로 낮추는 현재의 경쟁 방식 자체가 역설적으로 독립적인
오픈 가중치 생태계의 성장을 늦추는 효과를 낼 수 있다는 점이
드러난다.
가격 대 성능 경쟁에서 이기는 공급자가 많아질수록, 그 가격을 따라올
수 없는 오픈소스 대안은 설 자리를 잃기 쉽다.
