# Artificial Analysis: 모델의 지능, 속도, 가격을 한 화면에 놓는 독립 순위표

<https://artificialanalysis.ai/>

HN 토론: <https://news.ycombinator.com/item?id=39014985> (152점, 70개 댓글)

## 소개

Artificial Analysis는 AI 모델과 API 제공자를 독립적으로 분석한다고 스스로를
소개하는 사이트다.
첫 화면의 문구는 AI 지형을 이해해 용도에 맞는 모델과 제공자를 고르게 한다는
것이다.
다루는 대상은 언어 모델, 이미지, 영상, 음성이다.
2026년 11월 10일에 본 첫 화면은 733개 언어 모델을 추적하고,
44개 평가를 싣고, 11월 2일부터 9일까지의 변경 기록을 맨 위에 둔다.

변경 기록에는 Claude Fable 5.2의 다섯 가지 노력 수준
(Low, Medium, High, Xhigh, Max)이 11월 9일에 한꺼번에 평가로 올라온 것,
Meta의 Muse Ember 두 설정이 같은 날 올라온 것,
11월 8일에 의사결정 지수(Decision Index) v2가 소개된 것이 보인다.
방법론 갱신 항목도 있어서, 11월 3일에 지능 지수 v5.0.1과
성능 측정 v3.0.0이 바뀌었고 11월 5일에는 엔드포인트 정확도 지수 v1.1이
바뀌었다.

## 구성

### 지수 가족

첫 화면은 단일 점수가 아니라 여러 지수를 늘어놓는다.

| 지수                    | 구성                                                                                                                  |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 지능 지수 v5.0.1        | 아홉 개 평가(AA-Briefcase, Terminal-Bench 4.0, FrontierCode 2.0, HLE-Diamond 등)                                      |
| 코딩 에이전트 지수 v2.0 | FrontierCode v1.1, Terminal-Bench 4.0, SWE-Atlas-QnA-AA                                                               |
| 사이버 지수 v1          | CWE-Bench-AA, DeepsecBench-AA, CyberGym-E2E-AA                                                                        |
| 의사결정 지수           | AA-Paperclip, EvalSafe-O*NET-AA, When2Call 등의 가중 평균. 정확도에서 선택한 답의 확률의 브라이어(Brier) 점수를 뺀 값 |
| 진행 지수 v1            | 여러 평가를 문항 반응 이론(item response theory)으로 추정한 일반 능력                                                 |

사이버 지수의 그래프는 성공 횟수와 안전 차단(Safety blocks)을 따로 보여 주고,
공개 API가 없는 신뢰 접근(trusted-access) 모델에는 별도 표시를 둔다.
이 구분은 안전장치가 모델 점수에 영향을 주는 세상을 반영한다.

### 분야별 비교표

첫 화면에는 금융·회계, 전략·운영, 법률, 의료, 공학, 경제의 여섯 분야별
능력 지수를 순위로 비교하는 표가 있다.
이날의 표에서 Claude Fable 5.2(Max)는 여섯 분야 모두 1위(65, 67, 63, 65,
73, 67)였고 Claude Opus 5.5(Max)가 모두 2위였다.
GPT-6 Astra(Max)는 금융·회계 3위(57)였고,
Muse Ember(Max)는 13위 안팎(45 부근)이었다.

### 도구와 다른 매체

사이트는 모델 추천기와, 사용자가 자기 벤치마크를 만드는 Optima를 둔다.
이미지와 영상, 음성은 블라인드 투표로 매긴 Elo(Arena)로 순위를 낸다.
AA-3D는 모집한 심사단의 블라인드 투표로 3D 경험 제작을 재고,
AA-Robotics는 로봇 팔을 제어하게 해 물리 세계의 이해와 계획을 잰다고 한다.

## 분석

### 비교의 단위가 모델이 아니라 설정이다

이 사이트에서 하나의 점은 모델이 아니라 모델과 노력 수준과 대체 모델 설정의
조합이다.
첫 화면에는 노력(Effort) 선택으로 Max와 API 기본값을 고르는 스위치가 있고,
변경 기록은 같은 모델의 다섯 노력 수준을 따로 올린다.
이는 모델의 점수가 하나의 숫자가 아니라 비용과 시간을 함께 바꾸는 곡선이라는
점을 사이트가 받아들였다는 뜻이다.
이 사이트의 순위표를 읽을 때는 그 점이 어느 노력 수준인지가 먼저다.

### 한 번의 점수에서 지수 가족으로

초기에 이 사이트는 품질, 가격, 처리량, 지연이라는 소수의 축으로 시작했다.
2024년 1월 HN에 올린 제작자는 목표가 모델과 API 제공자를 비교하는 객관적
벤치마크라고 밝혔다.[^gcam]
2026년에는 사이트가 코딩, 사이버, 의사결정, 진행의 지수를 각각 둔다.
점수 하나가 모든 용도를 대표하지 못한다는 비판에 대한 답으로 읽을 수 있고,
사이트가 지수를 늘리는 방향으로 간 것은 이 문서의 해석이다.

### 평가를 스스로 만들고 소유한다

지수를 이루는 평가의 상당수가 이름에 AA가 붙은 자체 개발품이다
(AA-Briefcase, AA-Omniscience, AutomationBench-AA 등).
측정 기관이 문제를 직접 정하면 외부에서 구하기 어려운 과제를 측정할 수 있고,
모델이 시험 문제를 학습할 위험도 줄어든다.
반대로 문제와 채점의 설계 자체가 제3자의 검증을 받기 어려운 구조가 된다.

## 비평

### 독립 분석이라는 이름은 평가 설계의 중립성을 보장하지 않는다

첫 화면의 첫 줄이 독립적 분석이다.
독립이라는 말은 모델 제작사와 재무적으로 분리되었다는 뜻이지,
무엇을 어떻게 재는지의 선택이 중립이라는 뜻은 아니다.
비교 대상에 맞는 가중치, 평가 목록, 노력 수준 기본값은 모두 사이트가 정한다.
이번에 읽은 텍스트에서는 가중치와 문제 구성을 확인하지 못했다.

### 평균 지연은 이상치에 약하다

2024년 HN에서 한 사용자는 GPT-4 Turbo의 평균 지연이 12월 28일의 큰 급등
때문에 높게 나온다며, 상하위 10%를 버리거나 중앙값에 분산을 더하라고
제안했다.[^badFEengineer]
다른 사용자는 첫 토큰까지의 시간(TTFT)을 보여 주는 벤치마크가 드물다고
아쉬워했는데, 제작자는 이미 모델 페이지의 지연 항목에 있다고 답했다.[^com2kid]
2026년의 페이지는 첫 답변 토큰까지의 시간과 초당 출력 토큰을 모두 싣는다.
다만 사고 시간이 긴 추론 모델의 시간은 이 두 값의 의미를 다르게 만든다.

### 순위의 분모가 지표마다 다르다

한 모델 페이지에서 지능은 74개 중, 비용은 73개 중, 속도는 72개 중으로
순위가 매겨진다.
첫 화면도 28개 모델만 그래프에 올리고 “733개 중 28개”라고 쓴다.
무엇을 분모로 삼았는지는 모델 종류별 비교 집단 규칙을 이해해야 알 수 있다.
순위를 인용하는 사람은 이 분모를 함께 적어야 한다.

## 인사이트

### 순위표는 측정이 아니라 제품 선택의 형식이 되었다

변경 기록이 모델 공개 당일에 모든 노력 수준의 평가를 올리는 것은,
순위표가 사후 분석이 아니라 출시 사건의 일부라는 뜻이다.
모델 제작사가 공개와 함께 이 사이트의 점수를 인용하고 사용자가 그 점수로
모델을 고르면, 사이트의 평가 설계가 모델 개발의 목표 함수가 될 수 있다.
이것은 이 문서의 추정이며, 측정이 목표가 되면 측정으로서의 가치가 줄어든다는
일반적 우려를 이 사이트에 적용한 것이다.

### 비용 축이 지능 축만큼 큰 비중을 갖는다

첫 화면의 세 그래프는 지능, 과제당 시간, 과제당 비용이다.
단가가 아니라 과제당 값을 쓰는 방식은 같은 지능을 얼마에 사는지를 직접
비교하게 한다.
이 방식은 토큰을 많이 쓰는 모델이 단가가 같아도 훨씬 비싸다는 사실을 드러낸다.
이 사이트가 퍼뜨린 가장 중요한 사고방식은 이 비용 비교일 것이다.

### 안전 차단이 성능표의 새 항목이 된다

사이버 지수의 그래프에 성공과 안전 차단이 나란히 나오는 것은,
모델의 유용성이 능력뿐 아니라 거부 정책에 달려 있다는 점을 평가가 반영한다는
뜻이다.
같은 기반 모델이 안전장치 유무에 따라 다르게 팔리는 시대에는
점수표가 모델 한 줄이 아니라 정책을 포함한 제품 한 줄이 된다.
이 변화가 평가의 정직성에 어떤 압력이 될지는 아직 관찰할 사례가 적다.
