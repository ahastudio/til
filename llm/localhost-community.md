# 로컬호스트 커뮤니티

<https://local.dropthe.codes/>

## 소개

로컬호스트는 코드, 서버, 로컬 AI 모델, 게임을 다루는 사람들을 위한 한국어 게시판형 커뮤니티 사이트이다. 첫 화면의 문구는 「코드 던지고, 서버 올리고, AI 돌리고, 게임 깨는 부캐들의 아지트」이다.
이 문서는 첫 화면과 로그인 없이 열리는 게시판 목록 페이지를 읽었다. 첫 화면의 본문은 환영 문구와 두 개의 버튼(시작하기, 게시판 둘러보기)뿐이고, 운영자, 가입 조건, 규칙, 라이선스, 가격에 대한 설명은 없다. 글 본문과 로그인 이후 화면은 열어 보지 않았다.
웹 요청으로는 첫 화면이 거의 비어 있어(위쪽 막대의 Loading... 표시만 있음) 브라우저에서 렌더링한 화면을 읽었다.

게시판은 다음 여덟 개이다. 글 수는 목록 페이지에 표시된 값이다.

| 게시판    | 설명                                                | 글 수 |
| --------- | --------------------------------------------------- | ----- |
| 공지      | 운영 공지와 게시판 규칙                             | 0     |
| 자유      | 잡담과 가벼운 이야기                                | 5     |
| 소식      | 새 모델 출시, 도구 릴리스, 논문 소식                | 6     |
| 모델      | 모델 사용 후기, 비교, 추천, 양자화 선택             | 17    |
| 하드웨어  | GPU, Mac, 미니PC, 다중 GPU 구성과 견적              | 2     |
| 실행 환경 | llama.cpp, Ollama, vLLM, MLX, LM Studio 설치와 설정 | 7     |
| 질문      | 모든 주제의 질문과 답변                             | 0     |
| 만든 것   | 직접 만든 프로젝트, 워크플로, 설정 공유             | 0     |

메뉴에는 이 여덟 개 앞에 「광장」이라는 항목도 있으나 이 문서는 그 성격을 확인하지 못했다.
목록에서 읽은 글은 모두 같은 작성자(햄찌) 이름으로 올라와 있었다(목록이 길게 이어지는 게시판은 앞부분만 읽었다). 제목은 새 모델과 양자화 연구, 모델 비교, 보안 취약점 소식, 하드웨어 리버싱, 로컬 실행 설정 같은 주제이다. 일부 제목은 다른 사이트의 소식을 옮긴 형식이다(예: Show HN 글을 소개하는 제목).

로그인은 첫 화면의 시작하기 버튼이 가리키는 `/login` 페이지로 한다. 이 문서는 로그인하지 않았다.

## 분석

### 게시판 구조가 로컬 AI 사용자의 질문에 맞춰져 있다

게시판 이름이 모델, 하드웨어, 실행 환경으로 나뉘어 있는 것은 로컬에서 모델을 돌릴 때 부딪히는 세 가지 질문(어떤 모델, 어떤 장비, 어떤 실행 도구)과 대응한다. 질문과 만든 것 게시판이 따로 있어 후기, 질문, 자랑을 구분한다.
이는 목록 페이지의 구성을 이 문서가 읽은 것이다.

### 현재는 한 작성자의 소식 게시판에 가깝다

공개된 글은 총 37개로 표시되고(공지 0, 질문 0, 만든 것 0 포함 합계), 읽은 목록의 작성자는 한 이름이었다. 글의 종류도 다른 곳의 소식과 연구를 정리한 형식이 많아 보였다.
사이트가 막 열린 단계인지 한 사람이 채우고 있는지는 첫 화면과 목록만으로는 알 수 없다.

## 비평

### 사이트에 대한 설명이 거의 없다

운영 주체, 가입 방법, 규칙, 데이터 처리 방침이 첫 화면에 없다. 공지 게시판의 규칙 글도 0개이다. 참여를 고려하는 사람이 확인할 정보가 부족하다.

### 확인 범위가 얕다

글 본문의 품질, 출처 표기, 정확성은 이 문서가 읽지 않았다. 목록 제목만으로 글의 내용을 평가할 수 없고, 글 수는 읽은 시점의 값이다.

### 외부 반응

HN에서는 `local.dropthe.codes`와 `dropthe.codes`를 주소로 검색했고 대조 쿼리는 정상이었으나 올라온 글이 없었다.
GeekNews에서는 `로컬호스트 코드 던지고 서버 올리고`, `dropthe.codes`, `로컬호스트 AI 커뮤니티 게시판`으로 검색했고 대조 쿼리는 정상이었으나 이 사이트의 토픽이 없었다. 결과는 모두 다른 주제였다.
Lobste.rs에서는 검색과 도메인 조회가 막혀 있어 확인하지 못했다.
그래서 이 사이트에 대한 외부 토론은 읽지 못했다.

## 인사이트

### 가져갈 것은 로컬 AI의 질문을 모델, 장비, 실행 환경으로 나누는 분류이다

자료를 모을 때 같은 세 축으로 나누면 후기와 설정을 찾기 쉽다. 이는 이 문서의 적용이다.

### 확인할 관찰

이 사이트의 성격을 가를 관찰은 세 가지이다.
작성자가 몇 명으로 늘어나는지,
질문과 만든 것 게시판에 글이 쌓이는지,
글의 출처 표기와 정확성이다.
셋 모두 이 문서가 확인하지 못했다.
