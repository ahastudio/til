# Diy-LLM: Stanford CS336을 중국어 학습자에 맞춰 다시 쓴 LLM 전 과정 교재

<https://datawhalechina.github.io/diy-llm/en/>

<https://github.com/datawhalechina/diy-llm>

## 소개

Diy-LLM은 중국의 오픈소스 학습 커뮤니티 Datawhale이 만든, 대형 언어 모델을 만드는
전 과정을 다루는 교재다.
토크나이저, 데이터, 학습에서 시스템 최적화, 추론, 정렬, 평가, 멀티모달까지
LLM을 만드는 사슬 전체를 하나의 지식 체계로 잇는다고 소개한다.
중국어가 기본이고 영어판이 따로 있으며 사용자가 준 주소는 영어판 사이트다.
이 문서는 영어판 사이트의 첫 쪽과 GitHub의 README, 저장소 정보를 읽고 정리한
것이며 장 본문이나 과제 코드는 읽지 않았다.
모든 설명은 만든 이들의 주장이다.

만든 이들은 2025년 봄에 Stanford CS336: Language Modeling from Scratch가
개설되었을 때 학습자들이 영어 강의 노트와 전제 지식, 과제 환경이 장벽이라고
말해서 중국어판을 만들었다고 한다.
반년 넘게 집필, 내부 시험, 공개 시험, 장별 다듬기를 거쳤고,
단순 번역이 아니라 중국어 학습자의 학습 방식에 맞춰 지식 체계를 다시 짰다고
한다.
GitHub API가 보고한 저장소는 2025년 11월 24일에 만들어졌고 별 2,853개,
포크 276개, 열린 이슈 10개이며 마지막 푸시는 2026년 11월 8일이다.
주 언어는 Jupyter Notebook이다.

## 구성

현재 본문 16장과 보조 과제 6개로 이루어지고 프로젝트 책임자 세 명과 여러
기여자가 맡았다고 한다.
README의 목차와 상태 표시를 정리하면 다음과 같다.

| 장  | 내용                                                 | 과제 | 상태      |
| --- | ---------------------------------------------------- | ---- | --------- |
| 1   | 도구 사용(W&B 실험 추적, 하이퍼파라미터 탐색)        | 없음 | 보강 예정 |
| 2   | 토크나이저(BPE, 유니코드 정규화)                     | 1    | 완료      |
| 3   | PyTorch와 자원 계산(혼합 정밀도, FLOPs와 메모리)     | 없음 | 완료      |
| 4   | 모델 구조와 학습 세부(RoPE, RMSNorm, SwiGLU, AdamW)  | 1    | 완료      |
| 5   | 전문가 혼합(MoE, 부하 균형, DeepSeekMoE)             | 없음 | 완료      |
| 6   | GPU와 최적화(Flash Attention, 커널 융합)             | 2    | 완료      |
| 7   | GPU 고성능 프로그래밍(CUDA, Triton 입문)             | 2    | 완료      |
| 8   | 분산 학습(데이터, 모델, 파이프라인 병렬, ZeRO, FSDP) | 2    | 완료      |
| 9   | 스케일링 법칙(Chinchilla, 계산 최적 설정)            | 3    | 완료      |
| 10  | 추론(KV Cache, 추측 디코딩, 양자화, PagedAttention)  | 6    | 완료      |
| 11  | 데이터 공학(품질 필터, MinHash 중복 제거, PII 제거)  | 4    | 완료      |

| 14  | 검증 가능한 보상의 강화학습(GRPO, RLVR, R1)          | 5    | 완료      |
| 15  | 멀티모달(CLIP, SigLIP, LLaVA, Qwen-VL)               | 없음 | 완료      |
| 16  | 확장 내용(LLM 추론이란 무엇인가, LeCun의 LLM 미래)   | 없음 | 갱신 중   |

과제 여섯 개는 다음과 같다.
기초 모델 구현(토크나이저, 구조, 옵티마이저로 작은 언어 모델 학습),
시스템 최적화(성능 분석, Triton으로 FlashAttention-2, 분산 학습),
스케일링 법칙, 데이터 처리(Common Crawl을 사전학습 데이터로 변환),
정렬(SFT와 GRPO 같은 강화학습으로 수학 문제 풀이),
모델 평가(lm-evaluation-harness와 evalscope)다.
여섯 번째 평가 과제는 중국어판이 새로 더한 것이라고 한다.

## 원본과의 관계

README는 원본 CS336과의 차이를 표로 정리한다.
원본이 강의 순서대로 가고 수학, PyTorch, 시스템 지식을 전제로 하는 데 비해
중국어판은 LLM을 만드는 공학 흐름으로 장을 다시 배열하고 전제 지식을 먼저
따로 설명한다고 한다.
과제는 원본이 설명과 시험을 제공하는 데 비해 실행 가능한 구현과 코드를 쓸 때의
사고 과정을 해설로 제공하고, CPU 디버깅과 MacBook MPS 지원을 더했다고 한다.
모델 사례는 Qwen, DeepSeek, Qwen-VL, DeepSeekMoE, R1과 GRPO 같은 중국 모델을
추가했고, 평가에는 C-EVAL 같은 중국어 벤치마크를 넣었다고 한다.
장 번호가 원본의 강의 번호와 일대일로 대응하지 않으니 이 프로젝트의 장 순서를
따르라고 안내한다.

버전은 처음에 CS336 2025년 봄판을 바탕으로 했고 원본의 과제 1~5에 대응한다.
2026년에는 새 판을 반영해 갱신했고, 새 일정의 RLVR과 멀티모달 주제가 14장과
15장에 대응한다고 한다.
Stanford와는 공식 관계가 없는 커뮤니티 프로젝트라고 밝힌다.

집필 방식으로는 AI를 번역과 자료 정리 보조로 썼지만 모든 장을 기여자가 직접 쓰고
확정했으며 교차 검토를 거쳤고 AI로 대량 생성한 것이 아니라고 설명한다.
PDF 강의 노트는 상업적 재판매를 막으려고 Datawhale 로고 워터마크를 넣었다고
한다.
라이선스는 README가 CC BY-NC-SA 4.0(저작자 표시, 비영리, 동일 조건 변경 허락)으로
적는다.

## 비평

### 원본의 서약 규정과 과제 해설이 부딪힐 수 있다

기존 문서에 정리한 CS336 강의 페이지는 학생이 구현을 직접 해야 하고, 온라인의
기존 구현은 과제 안내서가 따로 지정하지 않는 한 보지 말라고 한다.
Diy-LLM은 과제마다 실행 가능한 구현과 사고 과정의 해설을 제공한다고 한다.
독학자에게 이 해설은 막힌 곳을 푸는 도움이 되지만, 먼저 직접 풀어 보고 싶은
사람이 해설을 처음부터 열어 보면 과제가 노리는 학습을 건너뛰게 된다.
이 둘이 어떻게 맞물리는지는 README에 적혀 있지 않았다.
원본 과목의 규정이 자습자에게도 적용되는지는 강의 페이지에서 확인되지 않아
이 문서는 판단하지 못했다.

### 사람이 썼다는 주장은 확인할 수 없다

README는 AI를 번역과 정리 보조에만 썼고 대량 생성이 아니며 장마다 저자가 있다고
강조한다.
장별 담당 기여자 목록은 README에 있지만 AI 보조의 범위와 검토의 기준은 이
문서가 읽은 자료에 없다.
이 주장은 독자가 본문을 읽고 판단할 일이며, 이 문서는 본문을 읽지 못했다.

### 갱신 범위가 장마다 다르다

2026년판을 반영했다고 하지만 1장은 보강 예정이고 16장은 갱신 중이다.
원본 2026년 일정의 강의 19개 중 어떤 강의가 어느 장에 대응하는지 표는 없고,
14장과 15장만 RLVR과 멀티모달에 대응한다고 밝힌다.
원본 CS336 2026년판 1강에서 Percy는 올해 전문가 혼합에 더 많은 시간을 쓰고,
에이전트가 인기를 끄는 만큼 긴 문맥을 다루는 것이 중요하다고 말했다.[^lecture1]
README 목차에서 5장은 전문가 혼합을 다루지만 긴 문맥을 다루는 장은 찾지 못했다.
이는 목차만 읽고 한 판단이어서 본문에 있을 수도 있다.

### 라이선스의 적용 범위가 불분명하다

README의 라이선스 항목은 이 작품 전체에 CC BY-NC-SA 4.0을 적용한다고 적는다.
GitHub API는 저장소의 라이선스 파일을 인식하지 못하고, 저장소 루트에도 LICENSE
파일이 보이지 않는다.
코드에 비영리 조건이 있는 라이선스를 쓰는 것은 흔치 않아서, 과제 코드를 회사에서
참고하려는 사람은 적용 범위를 따로 물어야 한다.

## 도입 전에 따져볼 것

- 원본 CS336 과제를 직접 풀 계획이면 해설을 먼저 읽지 않는다. 막힌 뒤에 필요한 부분만 본다.
- 장 번호가 원본 강의 번호와 다르니 CS336 강의 영상과 함께 볼 때 대응표를 직접 만든다.
- 2026년 새 주제인 전문가 혼합, 장문맥, 에이전트 관련 내용이 어느 장에 있는지 목차에서 확인한다.
- 영어판이 중국어판과 같은 범위인지, 번역 장이 남아 있는지 본문에서 확인한다.
- 코드를 업무에 재사용하기 전에 CC BY-NC-SA 4.0의 비영리 조건을 확인한다.
- GPU가 없으면 README 안내대로 CPU 디버깅으로 시작하고 완전한 학습은 클라우드 GPU로 돌린다.
