# Solar Human Proofreader: 주소를 옮긴 한국어 윤문 MCP 서버

트윗: [사람 편집자가 손본 것처럼 한국어 글을 다듬어 주는 Solar Human Proofreader MCP, 주소를 옮겼습니다.](https://twitter.com/sungkimup/status/2114886177111281788)

## 소개

Twitter 사용자 @SungKimUp이 2026년 10월 27일에 올린 이전 공지다.
Solar Human Proofreader MCP의 주소를 Vercel에서 Upstage 서버로 옮겼다고 알린다.
공지에 따르면 그동안 하루 평균 3만 건이 넘는 요청이 들어왔고,
많은 날은 5만 건을 넘었다.
하루 100콜은 무료이고, Upstage 키를 넣으면 제한 없이 쓸 수 있다.
기존 `vercel.app` 주소도 그대로 동작하므로 설정을 바꾸지 않아도 된다.
새로 연결하는 사람은 새 주소를 쓰면 된다.

이 서버는 한국어 원고를 사람 편집자가 손본 것처럼 교정하는 MCP 서버다.
문장은 Upstage Solar Pro 4가 손보고,
사실, 인용, 말투가 그대로인지는 코드가 판정한다.
내용은 더하지도 빼지도 않는다고 안내한다.[^proofreader]
새 주소는 `https://human-proofreader-mcp.toy.x.upstage.ai/api/mcp`이고,
전송 방식은 streamable HTTP다.[^proofreader]

## 동작 방식

서버는 편집자의 작업 순서를 다섯 단계로 나누어 따른다.
통독과 대조는 코드가 맡고, 소견과 교정과 보정은 Solar가 맡는다.[^proofreader]

| 단계 | 담당  | 하는 일                                                                          |
| ---- | ----- | -------------------------------------------------------------------------------- |
| 통독 | 코드  | 문장 길이 분포, 만연체, 번역투, 피동, 상투구를 센다[^proofreader]                |
| 소견 | Solar | 끊긴 논지, 겹치는 문단, 죽은 리듬처럼 수치가 못 보는 것을 읽는다[^proofreader]   |
| 교정 | Solar | 소견에서 짚은 자리만 손본다[^proofreader]                                        |
| 대조 | 코드  | 원본과 맞춰 보고 없던 수치나 문장, 바뀐 인용, 뒤집힌 말투를 잡는다[^proofreader] |
| 보정 | Solar | 대조에서 걸린 자리만 국소적으로 고친다[^proofreader]                             |

이 구조에서 눈여겨볼 점은 채점을 모델에게 맡기지 않는다는 것이다.
페이지는 자기가 쓴 글을 자기가 채점하면 언제나 후하다는 이유를 든다.
그래서 변경률, 수치 보존, 인용 대조, 말투 판정은 코드가 센다.
원본에 없던 문장이 하나라도 생긴 교정본은 채택하지 않는다.[^proofreader]

노출되는 도구는 여섯 개다.

| 도구           | 하는 일                                                        | 비용        |
| -------------- | -------------------------------------------------------------- | ----------- |
| `proofread`    | 원고를 통독하고 교정본을 돌려준다[^proofreader]                | Solar 1~3콜 |
| `read_through` | 고치지 않고 왜 안 읽히는지 소견만 준다[^proofreader]           | Solar 1콜   |
| `readability`  | 문장 길이, 번역투, 피동, 리듬을 0~100점으로 잰다[^proofreader] | 무료        |
| `compare`      | 원본과 교정본을 대조해 훼손을 잡는다[^proofreader]             | 무료        |
| `suggest`      | 한 대목을 결이 다른 여러 안으로 다시 써 준다[^proofreader]     | Solar 1콜   |
| `usage`        | 오늘 남은 무료 한도를 확인한다[^proofreader]                   | 무료        |

## 연결하기

가입이나 카드 등록 없이 URL 한 줄만 넣으면 된다.[^proofreader]
Claude Code에서는 한 줄 명령으로 추가한다.

```bash
claude mcp add --transport http human-proofreader \
  https://human-proofreader-mcp.toy.x.upstage.ai/api/mcp
```

JSON 설정 파일을 직접 고치는 클라이언트는 같은 주소를 `url`에 넣는다.

```json
{
  "mcpServers": {
    "human-proofreader": {
      "url": "https://human-proofreader-mcp.toy.x.upstage.ai/api/mcp"
    }
  }
}
```

stdio만 지원하는 클라이언트는 `npx -y mcp-remote <주소>`로 이어 붙인다.[^proofreader]
연결한 뒤에는 도구 이름을 외울 필요 없이 다듬어 달라고 말하면 된다.
고치지 말고 문제만 짚어 달라고 하면 `read_through`가 불린다.[^proofreader]

## 한도 정하기

무료 한도는 Solar 호출 1회를 단위로 세고, KST 자정에 초기화된다.
통독 1회와 교정 1회를 쓰면 2회가 차감된다.
`readability`와 `compare`는 Solar를 부르지 않으므로 차감되지 않는다.[^proofreader]

| 상황                     | 선택                               | 이유                                                              |
| ------------------------ | ---------------------------------- | ----------------------------------------------------------------- |
| 하루 몇 편 정도 다듬는다 | 키 없이 쓴다                       | `proofread` 한 번이 최대 3콜이므로 100콜이면 최소 33편은 처리된다 |
| 원고를 길게 자주 돌린다  | 헤더로 본인 키를 단다              | 한도가 없어지고, 비용은 본인 키의 계정으로 청구된다               |
| 먼저 상태만 보고 싶다    | `readability`와 `compare`부터 쓴다 | Solar를 부르지 않아 한도를 쓰지 않는다                            |

본인 키는 도구 인자가 아니라 헤더(`X-Upstage-Api-Key` 또는 `X-OpenRouter-Api-Key`)로 보낸다.
페이지가 밝힌 이유는, 인자로 받으면 키가 대화 기록에 평문으로 남기 때문이다.[^proofreader]

## 트레이드오프

### 설치 없이 쓰는 대신 원고가 서버로 간다

이 서버가 하는 일은 원고를 받아 교정본을 돌려주는 것이다.
따라서 클라이언트가 이 서버를 호출하는 순간 원고 전문이 외부 서버로 나간다.
페이지는 원고를 어디에 저장하는지, 보관 기간이 얼마인지는 적지 않았다.
이 점은 페이지에서 확인하지 못한 부분이므로, 사내 문서나 미공개 원고는 확인 전에는 보내지 않는 편이 안전하다.

### 변경을 코드가 감시하지만 문체 판단까지 보증하지는 않는다

대조 단계는 수치, 인용, 말투 같은 기계적으로 비교할 수 있는 것을 잡는다.
반대로 문장 하나를 바꾼 것이 글의 논지를 약하게 만들었는지는 코드가 알 수 없다.
페이지가 보여 주는 사례의 변경률은 18%에서 24% 사이다.
그 정도 분량이 바뀐 글은 읽는 사람이 훑어 확인해야 한다.

### 무료 한도가 낮은 서버는 공지 한 줄에 흔들린다

공지는 하루 3만에서 5만 건의 요청이 들어온다고 했고, 그래서 더 빠른 서버로 옮겼다고 했다.
무료 서버가 인기를 얻으면 용량이 먼저 한계에 닿는다.
기존 주소가 계속 동작한다는 말은 약속이 아니라 현재 상태다.
언제까지 유지되는지는 공지에 없으므로, 오래 쓸 설정은 새 주소로 바꾸는 편이 낫다.

## 함정

헤더에 본인 키를 넣으면 그 키는 클라이언트 설정 파일에 평문으로 남는다.
Claude Code라면 `~/.claude.json`이 해당하고, 페이지가 이 경로를 설정 위치로 안내한다.[^proofreader]
설정 파일을 저장소에 넣거나 공유하면 키가 같이 나간다.

구 주소를 쓰던 설정에 새 주소를 추가로 등록하면 같은 서버가 두 번 붙을 수 있다.
이 글에서는 그 동작을 시험하지 않았다.
`claude mcp list`로 현재 어느 주소가 붙어 있는지 확인한 뒤 하나만 남기는 것이 확실하다.

`proofread`를 한 번 부르면 최대 3콜이 차감된다.
긴 원고를 여러 번 반복해서 돌리면 하루 100콜이 생각보다 빨리 소진된다.

## 확인하기

주소가 살아 있는지는 원고를 보내지 않고도 확인할 수 있다.
`/api/mcp`에 GET을 보내면 MCP 서버는 POST만 받기 때문에 405를 돌려준다.
이 글을 쓰며 실제로 해 보니 405와 함께 JSON-RPC 오류 본문이 돌아왔다.

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
  https://human-proofreader-mcp.toy.x.upstage.ai/api/mcp
```

405가 나오면 서버는 응답하는 상태다.
연결이 안 되거나 404가 나오면 주소를 확인한다.
등록은 `claude mcp list`로 확인하고, 남은 한도는 대화에서 `usage`를 불러 확인한다.

## 체크리스트

- 구 주소와 새 주소 중 어느 것을 쓰고 있는지 `claude mcp list`로 확인했다.
- 보내려는 원고가 외부 서버로 나가도 되는 글이다.
- 본인 키를 쓴다면 설정 파일이 저장소나 공유 폴더에 들어가지 않는다.
- 교정본의 변경률을 보고 의도한 만큼만 바뀌었는지 훑었다.
- 하루 100콜 한도에서 `proofread` 한 번이 최대 3콜임을 감안했다.

## 기억할 원칙

### 모델에게 자기 결과를 채점시키지 않는다

이 서버의 설계에서 옮겨 둘 만한 부분은 검증을 모델 밖으로 뺀 것이다.
변경률, 수치 보존, 인용 대조처럼 코드로 셀 수 있는 것은 코드가 세고,
모델은 코드가 셀 수 없는 문장 감각만 맡는다.
다른 LLM 작업에도 같은 분업을 적용할 수 있다.
검증할 수 있는 성질은 결정적인 코드로, 판단이 필요한 부분만 모델에게 맡긴다.
