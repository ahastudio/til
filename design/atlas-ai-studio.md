# Atlas AI Studio

<https://atlas.design/>

## 소개

Atlas AI Studio는 오스트리아 빈에 본사를 둔 Atlas가 만든
AI 창작 작업 도구이다.
회사는 이를 하나의 통제된 캔버스에서 100개가 넘는 모델을 제어 가능한 파이프라인으로 바꾸는
거버넌스와 문맥 계층이라고 소개한다.
문서와 사례 연구, 개별 워크플로우 페이지는 열지 않았다.

회사가 밝히는 구성은 다음과 같다.

- 작업 방식: 노드 기반 그래프 캔버스에서 입력, 텍스트 생성(LLM), 텍스트에서 이미지,
  이미지에서 3D 같은 단계를 이어 붙인다.
  사이트의 예시는 고양이용 증기기관풍 헬멧 설명문에서 이미지를 만들고 3D 메시로 바꾸는 흐름이다.
  사용자가 요청을 입력하면 에이전트가 초안 그래프를 만들어 준다고 한다.
- 실행 환경: Blender, Unreal, Unity, Maya, Houdini 안에서 돈다고 한다.
- 모델 라이브러리: 회사가 품질과 지식재산 안전성을 기준으로 시험한 모델 234개를 둔다.
  이미지, 3D 메시(Atlas 자체 Titan v1 포함), 비디오, 오디오, 유틸리티와 LLM 항목에
  Google, OpenAI, Anthropic, ByteDance 계열을 비롯한 모델 이름이 올라 있다.
- 3D 산출물: 사이트는 리토폴로지, UV, PBR 텍스처, 리그가 있는 밀폐 메시를 만든다고 한다.
  게임용 예시 워크플로우로 컨셉에서 게임 메시, 아트 바이블에서 스타일에 맞는 에셋,
  캐릭터 리깅과 애니메이션, 스틸에서 스토리보드와 프리비즈, 환경의 타일링 PBR을 든다.
  컨셉에서 게임 메시 워크플로우는 Tripo3D, Meshy, Hunyuan3D 사이를 대체 경로로 두고
  예산에 맞게 최적화한다고 설명한다.
- 투명성: 에셋마다 프롬프트, 모델과 라이선스 상태, 시드, 종횡비, 해상도,
  결재 서명, 크레딧을 담은 이력이 따라간다고 한다.
  같은 조건으로 다시 실행하거나 캔버스에 추가할 수 있다.
- 기억(Memory): 스타일, 사양, 규칙을 담은 시각 문맥 계층이다.
  아트 디렉션 요약, 스타일 프롬프트 파일, 금지할 방향 규칙(어기면 검토에서 실패 처리),
  참조 이미지 묶음, 영향 점수, 개선 제안을 관리하고
  실행마다 필요한 문맥만 에이전트가 꺼내 쓴다고 한다.
- API: 그래프의 일부를 묶어 입력과 출력을 정하고 게시하면
  버전이 붙은 API로 도구가 호출한다.
- 고객: 사이트는 Square Enix, Google Cloud, Krafton, miHoYo 등의 이름을 올리고
  Square Enix, Directive Games, Google Cloud 임원 등의 추천 문구를 싣는다.

## 가격

사이트의 요금 안내는 좌석당이 아니라 스튜디오 전체가 공유하는 예산 방식이다.
모든 요금제에서 사용자는 무제한이고 가격에는 부가세가 포함되며,
초과 사용은 크레딧당 0.01유로이다. 연간 결제는 요청 시 가능하다.

| 요금제     | 가격                  | 크레딧과 환산                                                 |
| ---------- | --------------------- | ------------------------------------------------------------- |
| 종량제     | 1,000 크레딧당 15유로 | 1,000 크레딧이 이미지에서 3D 약 13개 또는 고화질 이미지 140장 |
| Pro        | 월 200유로            | 월 21,510 크레딧 풀, 3D 약 290개 또는 고화질 이미지 3,100장   |
| Enterprise | 협의                  | 사용자 지정 크레딧 풀, VPC, SLA 99.9%, 사용자 지정 조건       |

종량제는 시작할 때 500 크레딧을 카드 없이 주고, 모든 기능과 모델을 같게 쓰며
월 100유로까지 쓴 뒤에는 요금제로 옮기라고 안내한다.
Pro는 API, Unreal과 Unity 플러그인, 고급 Memory Core와 아트 디렉터 통제,
버전 관리와 감사 로그, 우선 지원을 포함한다고 한다.
Enterprise는 사용자 지정 3D 파운데이션 모델 훈련, 조직 단위 Memory Core,
VPC나 온프레미스, 구글 클라우드 약정 소진을 내건다.
사이트의 계산으로 Pro는 같은 크레딧 21,510개를 종량제로 쓸 때의 322유로보다
월 122유로, 38% 싸다.

## 분석

### 무엇을 파는가

이 제품이 파는 것은 새 생성 모델이 아니라 여러 모델 앞의 조율 계층이다.
모델은 외부의 것을 쓰고, 회사는 파이프라인(그래프), 이력, 문맥, 승인 절차, API를 얹는다.
사이트가 거버넌스와 문맥 관리를 가장 큰 가치로 앞세우는 이유가 여기 있다.
회사의 문구로 AAA 스튜디오에 들어가게 한 것은 깊이와 거버넌스이고,
남게 하는 것은 문맥 관리라고 한다.

### 작동 단위

한 작업의 결과를 에셋 이력으로 묶고 같은 조건으로 재실행할 수 있다는 점이 중심이다.
프롬프트, 모델, 시드를 고정해 기록하는 방식은 결과의 재현과 승인 기록을 같은 구조에 담는다.
금지할 방향 규칙이 어기면 검토에서 실패하도록 강제된다는 점도
스타일 일관성을 사람의 기억이 아니라 규칙으로 옮기려는 설계이다.

### 가격 구조

좌석 대신 크레딧 풀로 과금하므로 비용이 사용한 생성 횟수에 비례한다.
Pro의 이점은 종량제 대비 할인이고, 이 구간에서 사용자 수는 비용에 영향을 주지 않는다.
크레딧을 3D와 이미지로 환산한 값은 회사의 예시이며 작업 종류와 모델에 따라 달라질 수 있다.

## 비평

### 주장과 증거

사이트의 증거는 추천 문구, 고객 로고, 예시 그래프, 가격 계산이다.
작업 시간이나 비용을 얼마나 줄였는지, 3D 결과가 실제 엔진 파이프라인을 얼마나 통과하는지
같은 수치는 이 사이트에서 읽지 못했다.
추천 문구는 회사가 고른 것이며 고객 목록의 로고가 모두 실제 계약인지는 확인되지 않는다.

### 모델 안전성 주장

회사는 모든 모델을 품질과 지식재산 안전성으로 시험한다고 한다.
시험 기준과 결과, 어떤 모델이 안전하다고 표시되는지는 사이트 첫 화면에 없다.
에셋 이력에 라이선스 상태가 기록된다는 서술도 어느 수준의 법적 보증인지 알 수 없다.

### 외부 모델에 대한 의존

모델 라이브러리는 대부분 외부 제공자의 모델이다.
가격과 가용성, 약관은 제공자에 따라 바뀔 수 있다.
사이트는 구글 모델을 구글이 청구하게 하고 사용자 자신의 클라우드에서 돌리는 선택을 Enterprise에 둔다.
다른 제공자의 변동이 요금에 어떻게 반영되는지는 사이트에 나와 있지 않다.

### 외부 반응

그래서 독립적인 사용 후기나 비교는 이 문서에 없다.

## 인사이트

### 실패 조건

3D 산출물이 엔진 요건을 맞추지 못하거나,
크레딧 소모가 예시보다 훨씬 크거나,
이력 기록을 법무 검토가 받아들이지 않으면
조율 계층이라는 가치는 크게 줄어든다.
